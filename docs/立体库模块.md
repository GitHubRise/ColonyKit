## 简介

立体库是一栋 **2×2** 的电力建筑：物品存在建筑内部的 `WarehouseThingOwner` 里，不占地图格；检视面板可检索/逐堆取出，原版 Storage 页管过滤与优先级；另有自动入库/出库 Job、250W 制冷、实时温度浮字和底部管理页。

**存储内核选择**：采用方案 A（纯 `ThingOwner` + 自定义存取/Job），没有 `CompWarehouse`，也没有 `ListerThings` 注入。因此原版账单/工作台**看不见**库内物品；底部资源列表通过 `ResourceCounter` Postfix 单独计入。这是当前最重要的限制，见 [2005](2005-立体库-账单电力与拆除.md)。

## 描述

### 建筑与数据

- `CK_VerticalWarehouse`（2×2，Furniture，二级研究解锁）：
  - 150 钢 + 8 零部件；400 HP；250W 电力；`CompTempControl` 默认 4°C。
  - `Container` = `WarehouseThingOwner`（`ThingOwner<Thing>`），存档 `Scribe_Deep`。
  - `storeSettings` = 原版 `RimWorld.StorageSettings`，实现 `IStoreSettingsParent`，默认 Normal + 食物/草药/干草/木头/植物类/麦芽，禁止腐烂。
  - `settingsVersion` 处理旧档：v<4 迁移 Low→Normal、21°C→4°C、默认过滤；v4→v5 追加木头/植物类/麦芽。
- 容量：默认 **12 堆**，设置页 1–200；`MaxStacks` 即时读取，调低不丢物品。
- 堆叠：全局 T1 ×10；库内 T2 ×3、T3 ×2（合计 ×6）；库内可超全局 `stackLimit`，取出按全局上限分块。
- 温控：`energyPerSecond=-21`，只制冷；未 T3 目标强制 4°C，T3 后 clamp -20～30°C；只对封闭/有顶房间生效。
- 实时温度浮字：`DrawGUIOverlay` 在圆环下方 -0.27 格显示 `F1` 温度；缩放 > Middle 且未选中时隐藏。
- 自动入库：`WorkGiver_HaulToWarehouse` + 原版 `HaulToContainer`。
- 自动出库：`WorkGiver_WithdrawFromWarehouse` + `CK_WithdrawFromWarehouse`；目标为更高优先级库存区。
- 手动：检视面板逐堆「取出」、Gizmo「收集附近物品」「取出全部」。
- 管理：底部 `CK_StorageManagement` 主标签页，检索/选中/跳转。
- 资源列表：`Patch_ResourceCounter` 把库内 `CountAsResource` 物品计入底部资源条。

### 研究

| 研究 | 费用 | 前置 | 效果 |
|---|---:|---|---|
| `CK_StorageTier1` | 800 | Electricity | 全局可堆叠物品固定 ×10；设置页倍率滑条隐藏 |
| `CK_StorageTier2` | 1600 | T1 | 解锁立体库；库内 ×3；温控 4°C |
| `CK_StorageTier3` | 2400 | T2 | 库内再 ×2（合计 ×6）；温控 -20～30°C；履带 Def 前置（建造菜单未挂） |

### 履带（暂停开发）

- `CK_ConveyorBelt` / `CK_ConveyorHub` 是 1×1、T3 前置、可最小化、`maxItemsInCell=1`。
- `Building_ConveyorBase` 每 30 tick 自动路由：贴仓库直接入库；否则 BFS 相邻履带找最近仓库并逐格移动。
- 没有建造分类（`designationCategory`），正常菜单不可见；没有端口/方向切换/反向 Gizmo/自动出库。
- 详见 [2008](2008-立体库-转向盘.md)、[2009](2009-立体库-双向履带.md)。

### 明确不做/未做

- 原版账单直接取库内物品（无 `ListerThings` 注入/取货请求）。
- 容量/材料升级、固定出库口、按数量取出、禁止入库 Gizmo、质量/耐久过滤。
- LWM Deep Storage 专项检测；Stack XXL 已做让位。
- 履带建造菜单/出库/端口。

## 绘制调用逻辑图

```text
Bootstrap
  └─ ModuleRegistry.DiscoverFromAssembly
        └─ StorageModule.OnDefsLoaded
              ├─ StorageStackLimitManager.Apply(settings)
              │     ├─ 检测 Stack XXL → Restore/让位
              │     ├─ 首次缓存可放大 Def 原值
              │     └─ T1 ? ×10 : 设置倍率
              └─ 日志：jobs / default filter extras

建造 CK_VerticalWarehouse（T2）
  ├─ CompPowerTrader（250W）
  ├─ CompTempControl（-21，默认 4°C）
  ├─ WarehouseThingOwner（12 堆，库内 ×3/×6）
  └─ IStoreSettingsParent → ITab_Storage

入库
  地上物品 → WorkGiver_HaulToWarehouse
        ├─ 有更好库存区且仓库优先级 ≤ 库存区 → 让位
        └─ JobDefOf.HaulToContainer → WarehouseThingOwner.TryAdd

出库
  WorkGiver_WithdrawFromWarehouse
        ├─ 找更高优先级库存格
        └─ CK_WithdrawFromWarehouse
              ├─ Take(min(堆数, 全局上限))
              ├─ 放脚边 + CarryTracker
              └─ PlaceHauledThingInCell

温控
  每 250 tick
  └─ TickRare
        ├─ 无电/无室内房间 → 停
        ├─ 目标 4°C 或 -20..30°C
        └─ room.Temperature += ControlTemperatureTempChange(-21*4.166, target)

界面
  ITab_VerticalWarehouse（库存/倍率/温度/检索/取出）
  ITab_Storage（过滤/优先级）
  MainTabWindow_StorageManagement（全图检索/选中）
  DrawGUIOverlay（圆环下方实时温度）
  Patch_ResourceCounter（资源条）
```
