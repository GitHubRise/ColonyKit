## 简介

淋浴成功后顺便做两件事：清掉淋浴器周围 2.5 格内的 RJW 精液污渍；把小人在自己房间看到的污渍排成一条原版清洁工作。只在**卫生真正刷满**的淋浴结束时触发，中断不触发。

## 描述

- 触发点：`JobDriver_TakeShower` 的 finish action 内，`completed == true` 才执行。
- `ClearCumAround(pawn, shower.Position)`：
  - 半径 2.5 格；
  - 识别 `FilthCum`、`FilthGirlCum`、`FilthInsectCum`、`ResinCum`；
  - 没装 RJW 时集合为空，直接跳过；
  - 逐个 `Destroy(DestroyMode.Vanish)`。
- `TryQueueRoomCleaning(pawn)`：
  - 要求小人未倒地/未死亡/非精神崩溃、未禁用清洁工作、操作能力可用；
  - 取 `pawn.ownership.OwnedBed` 所在房间；
  - 最多收集 12 个污渍；要求在小人活动区、可到达；
  - 生成原版 `JobDefOf.Clean`，`playerForced=true`，`jobQueue.EnqueueFirst`。
- 浴缸完成不调用这套清理；洗手池/马桶也不调用。

## 绘制调用逻辑图

```text
JobDriver_TakeShower
      └─ finish action
            ├─ completed == false → 直接返回
            └─ completed == true
                  ├─ ClearCumAround(半径 2.5)
                  └─ TryQueueRoomCleaning
                        └─ JobDefOf.Clean（最多 12 个污渍）
```

## 所含功能

- 淋浴后清 RJW 污渍。
- 淋浴后自动排队清洁自己房间。
- 只对成功完成的淋浴生效。

## 如何使用

1. 建淋浴器并保证有水/电/未堵塞。
2. 让小人正常洗完（卫生刷满）。
3. 观察淋浴器周围污渍消失，以及小人 Job 队列里出现清洁工作。
4. 没有 RJW 时只做房间清洁排队。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 洗完了污渍还在 | 没装 RJW / 污渍不在 2.5 格 / 淋浴中断 | 确认 RJW 与半径；看是否 completed |
| 没有排清洁工作 | 没有自己的床/房间、污渍不在活动区、不可达、清洁工作被禁用 | 分配床、检查活动区与工作优先级 |
| 清洁工作排队但不做 | 小人清洁工作被禁用/优先级低 | 调整工作优先级 |
| 浴缸洗完不清理 | 当前只接了淋浴 | 手动清洁 |
