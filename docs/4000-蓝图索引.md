## 模块一句话

把一片**已建好的玩家建筑**存成蓝图，之后在新地方或新存档按原材质/当前可用材料重新放出来，施工仍交给原版；当前 Mod 列表里不存在的建筑会被跳过并提示。

## 快速开始

1. 底部「蓝图」主按钮进入页面（只在有地图时可用）。
2. 点右上角「捕获蓝图」，在已建好的建筑上拉框。框内**可见的玩家完工建筑**会被收集，拖框四周的空白边距会被裁掉。
3. 捕获后自动入库、打开蓝图页并选中新蓝图；可「重命名」或「另存为模板」。
4. 选中蓝图点「放置」，鼠标处显示整张幽灵预览：Q/E 旋转、B 镜像；红色表示整张不能放。
5. 左键放置；设计器不会自动退出，可以连续点多份。右键/ESC 取消。
6. 默认生成原版施工蓝图，殖民者按材料施工；缺料会等料。开启上帝模式时直接生成完工建筑。

## 范围

- 每存档一份蓝图库，由模块自己的 `BlueprintGameComponent` 持有；不写进 `ColonyKitGameComponent`。
- 只收**玩家阵营、已完工、可见**的建筑；跳过未施工蓝图/框架/矿物/自然岩石/物品。
- 记录 `defName`、材质 `stuffDefName`、朝向 `rot`、相对坐标 `x/z` 与蓝图尺寸；不记录耐久/品质/地形/物品。
- 材料策略三档：原材质优先 / 就地取材（默认）/ 最便宜。
- 缺 Def 的条目跳过并计数提示，不阻塞其余建筑；研究未完成则整张拒绝（上帝模式除外）。
- 模板分两层：
  - 玩家模板：`Config/ColonyKit/Blueprints/*.xml`，可另存、覆盖式改名、删除；
  - 内置模板：Mod 根目录 `Blueprints/*.xml`，只读、随包发布；同名时玩家模板优先。
- 上帝模式放置直接 `ThingMaker.MakeThing` + `GenSpawn.Spawn` 成完工建筑，不再生成施工蓝图。
- 不含：地形/地板、物品、耐久/品质/艺术/染色、自动重建/修复、创意工坊分享。

## 依赖与兼容

- 只依赖原版建造系统：`GenConstruct.CanPlaceBlueprintAt` / `PlaceBlueprintForBuild`、`GenSpawn.WipeExistingThings`、`GhostDrawer`。
- 与「计划」设计器（vanilla plan）不冲突；蓝图是施工单，不是计划标记。
- 多格建筑、旋转建筑、Modded 建筑是主要兼容面；镜像对非方形多格建筑的朝向是近似处理。
- 模块软停用时主按钮隐藏（`MainButtonWorker_Blueprint.Visible` 检查 `ModuleRegistry`），库数据仍留在存档里。

## 已知限制 / 待确认

- 不含地形/地板：复刻后需要玩家自己铺地板；捕获范围里的物品会被忽略。
- 捕获按**实际建筑包围盒**记录，拖框四周的空白边距不会保留；框内雾格/未探索格直接忽略。
- 旋转/镜像后多格建筑的 `Position` 由占用矩形反推；非方形建筑的镜像朝向可能不完美。
- 没有「蓝图管理」研究门控，入口常驻；后续可按需要加。
- 蓝图库上限默认 256 张/存档；上限在**捕获入口**检查，从模板「载入」不额外检查。
- 单张默认 80×80、3000 个建筑，可在设置页调整（边长 8–200、条目 50–10000）。
- 蓝图页没有搜索/分页，条目多时靠滚动。
- 模板 XML 的 `schema` 属性目前只写出、不参与读取校验/迁移。
