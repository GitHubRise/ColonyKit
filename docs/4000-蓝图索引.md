## 模块一句话

把一片**已建好的建筑**存成蓝图，之后在新地方/新存档按原材质或当前可用材料重新放出来，交给原版施工。

## 快速开始

1. 底部主按钮进入「蓝图」页。
2. 点右上角「捕获蓝图」，在已建好的房子上拉框。
3. 捕获完成后蓝图库会自动打开并选中新蓝图；可「重命名」或「另存为模板」。
4. 选中蓝图点「放置」，鼠标带幽灵预览：Q/E 旋转、B 镜像；红色表示有建筑不能放。
5. 左键放置；设计器不会退出，可以连续点三次，把同一格局复刻成另外三座。
6. 生成的是原版施工蓝图，殖民者按材料施工；缺料会等到料齐。

## 范围

- 每存档一份蓝图库，由模块自己的 `BlueprintGameComponent` 持有（不污染 `Core`）。
- 首版只收**玩家建造的、已完工的建筑**；跳过蓝图/框架/矿物/物品；不含地形。
- 保留 `defName`、材质（stuff）、朝向、相对坐标与蓝图尺寸。
- 材料策略三档：原材质优先 / 就地取材（默认）/ 最便宜。
- 缺 Def 的条目跳过并计数提示；研究未完成则整张拒绝。
- 模板写到 `Config/ColonyKit/Blueprints/*.xml`，可跨存档/跨殖民地复用。
- 不含：地形、物品、耐久/品质、自动重建/修复、创意工坊分享。

## 依赖与兼容

- 只依赖原版建造系统（`GenConstruct.PlaceBlueprintForBuild` / `CanPlaceBlueprintAt`）。
- 与「计划」设计器（vanilla plan）不冲突；蓝图是施工单，不是计划标记。
- 多格建筑、旋转建筑、Modded 建筑是主要兼容面；镜像对非方形多格建筑是近似处理。

## 已知限制 / 待确认

- 不含地形/地板：复刻后需要玩家自己铺地板（首版范围）。
- 房间/物品不记录；捕获范围里的物品会被忽略。
- 旋转/镜像后多格建筑的 `Position` 由占用矩形反推；非方形建筑的镜像朝向可能不完美。
- 没有「蓝图管理」研究门控，入口常驻；后续可按需要加。
- 蓝图库上限默认 256 张/存档、单张 80×80 / 3000 建筑，可在设置页调整。
