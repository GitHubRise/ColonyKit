## 模块一句话

把一片**已建好的建筑**存成蓝图，之后在新地方/新存档按原材质、原朝向重新放出来，交给原版施工。

## 快速开始（草案）

1. 研究「蓝图管理」。
2. 点「捕获蓝图」，拉框选中已建好的建筑；确认后存进当前存档的蓝图库。
3. 打开「蓝图库」，选中一条，点「放置」。
4. 鼠标带幽灵预览：Q/E 旋转，镜像键翻转；红色格子表示不能放。
5. 确认后生成原版蓝图，殖民者按材料施工；缺料会提示。

## 范围

- 每存档一份蓝图库，由 `ColonyKitGameComponent` 持有。
- 首版只收**玩家建造的建筑**；跳过蓝图/框架/物品；可选包含地形。
- 保留 `defName`、材质（stuff）、朝向、相对坐标。
- 缺 Mod/缺 Def 时跳过并给警告清单，不静默丢建筑。
- 导入/导出 JSON、跨存档共享库排到 M5 之后。

## 依赖与兼容

- 只依赖原版建造系统（`GenConstruct.PlaceBlueprintForBuild`）。
- 与「计划」设计器（vanilla plan）不冲突；蓝图是施工单，不是计划标记。
- 多格建筑、旋转建筑、Modded 建筑是主要兼容面。

## 已知限制 / 待确认

- 蓝图库是每存档还是全局共享，待确认（当前按每存档设计）。
- 是否包含地形/物品，待确认（当前只建筑，地形可选）。
- 蓝图库的存档体积上限、单张蓝图的尺寸上限，M5-0 定稿。
