## 简介

设置窗口顶栏增加检索框：输入关键字后，当前页只保留匹配的控件/文本；同时把滚动容器抽成 `AutoScrollView`，内容超过视口时自动出现滚动条。

## 描述

- 检索状态：`SettingsSearch.Query`；`Active` 表示非空；`Matches(text)` 不区分大小写；`PageMatches` 由控件库递增。
- 交互：`SettingsController.DrawToolbar` 画 `Widgets.TextField` + 灰色占位提示；查询变化时清空 `pageHeights` 和 `scrollPositions`，回到顶部并重算高度。
- 过滤规则（`SettingsWidgets.BeginControl`）：
  - 匹配控件标签、Tooltip，或当前 Section 标题；
  - 命中才绘制，并补画之前挂起的 Section；
  - 未命中直接跳过，返回原值/`false`，不改变设置。
- 控件覆盖：`Checkbox`、`Slider`、`Dropdown`、`TextField`、`Label`、`Button` 全部参与检索。
- 无结果：`PageMatches == 0` 时页面底部显示「本页没有匹配的设置」。
- 检索范围：**当前页**；页签标题不参与过滤，切页后查询保留。直接调用 `listing.Label/ButtonText` 而未走控件库的行不会被过滤。
- 自动滚动：`AutoScrollView.Draw(outRect, ref scroll, ref contentHeight, draw)` 用上一帧 `contentHeight` 撑开 `viewRect`，`Widgets.BeginScrollView` 在内容高于视口时自动显示滚动条；`contentHeight` 由 `Listing_Standard.CurHeight` 回写。
- 第一帧限制：Immediate Mode GUI 无法预知高度，第一帧可能没有滚动条/被裁切，第二帧校正；这是原版设置页的常规做法。

## 绘制调用逻辑图

```text
SettingsController.Draw
  ├─ DrawTabs
  ├─ DrawToolbar
  │    ├─ TextField → SettingsSearch.Query
  │    └─ 查询变化 → pageHeights.Clear / scrollPositions.Clear
  └─ DrawPage(contentRect)
        ├─ SettingsSearch.BeginPage()   // PageMatches=0
        ├─ SettingsWidgets.BeginPage()  // pendingSection=null
        └─ AutoScrollView.Draw(contentRect, ref scroll, ref height, listing =>
              ├─ viewHeight = max(outRect.height, height + 8)
              ├─ BeginScrollView(outRect, viewRect=width-16 × viewHeight)
              ├─ page.DoContents(listing)
              │     ├─ Section(active) → pendingSection=title
              │     ├─ Checkbox/Slider/… → BeginControl
              │     │     ├─ 不匹配 → 跳过
              │     │     └─ 匹配 → 补画 Section + 画控件 + PageMatches++
              │     └─ Label/Button → 同样过滤
              ├─ 无命中 → Label("No matching setting")
              └─ EndScrollView；height = listing.CurHeight
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `SettingsSearch.Query` | `static string` | 当前查询 |
| `SettingsSearch.Active` | `static bool` | 是否启用检索 |
| `SettingsSearch.Matches` | `static bool Matches(string text)` | 不区分大小写匹配 |
| `SettingsSearch.BeginPage` | `static void BeginPage()` | 重置 `PageMatches` |
| `SettingsWidgets.BeginPage` | `static void BeginPage()` | 清空挂起 Section |
| `SettingsWidgets.Section` | `static void Section(listing, title)` | 检索时挂起，命中后补画 |
| `SettingsWidgets.Label` | `static void Label(listing, text)` | 可检索只读行 |
| `SettingsWidgets.Button` | `static bool Button(listing, label)` | 可检索按钮 |
| `SettingsWidgets.Checkbox/Slider/Dropdown/TextField` | 原签名 | 内部加检索过滤 |
| `AutoScrollView.Draw` | `static void Draw(Rect, ref Vector2, ref float, Action<Listing_Standard>, float)` | 自适应滚动容器 |
| `SettingsController.DrawToolbar` | `private void` | 搜索框 + 提示 + 重置 |
| `SettingsController.DrawPage` | `private void` | 调 AutoScrollView + 无结果提示 |

## 所含功能

- 当前页关键字检索；
- 标签/Tooltip/Section 三种匹配；
- Section 延迟绘制，避免空标题；
- 控件跳过时保持原值；
- 无结果提示；
- 查询变化重置滚动/高度缓存；
- 可复用的自动滚动容器；
- 首帧限制与第二帧校正说明。
