# 设置系统（Settings）

> 状态：✅ 已实现（多页签 + 页面自动发现 + `moduleSettings` 持久化） · 适用：ColonyKit 0.0.2 · 最后更新：2026-10-27
> 本页描述实际设置架构；淋浴设置项的玩家说明见 [1005-淋浴-卫生设置.md](1005-淋浴-卫生设置.md)。

## 1. 结构

- `ColonyKitSettings : ModSettings` 持有 `moduleSettings`（模块设置对象列表）。
- 每个模块设置实现 `IColonyKitModuleSettings`：
  - `string SettingsKey`；
  - `void ExposeData()`；
  - `void Reset()`；
  - `bool Validate()`。
- 模块通过 `ColonyKitMod.Settings.GetModuleSettings<T>()` 读取自己的设置；没有注册时回退到无持久化的 fallback 实例。
- 模块启停由 `ModuleRegistry` 独立管理，不在模块设置对象里重复存 `Enabled`。

## 2. 页面

- `SettingsController` 自动发现设置页，当前顺序：
  `modules` → `hygiene` → `storage` → `blueprint` → `general-settings` → `about`。
- 卫生页 `HygieneSettingsPage`：
  - 需求速率、耗水、热水用量、污染概率；
  - DBH 策略；
  - 囚犯/访客/非人形开关；
  - 种族/体型/Hediff 豁免；
  - 「应用到现有小人」「重置本页」。
- 控件统一用 `SettingsWidgets`：`Slider`、`Dropdown`、`Checkbox`、`TextField`、`Section`。
- 滚动由 `AutoScrollView` 统一处理：按上一帧内容高度撑开 `viewRect`，内容超过视口时自动出现竖直滚动条，内容变短（例如检索过滤后）时自动收起；每页的滚动位置和高度按 `SettingsPage.Id` 缓存。
  - 内部 `Listing_Standard` 必须 `maxOneColumn = true`：否则内容一旦超过视口，`Listing` 会按 `NewColumnIfNeeded` 换到第二列，`curY` 归零、第二列画在视口外，量出的高度永远不超过视口，滚动条就永远不出现。
  - 高度回写用 `MaxColumnHeightSeen`（不是 `CurHeight`），并给滚动条预留 16 px 列宽。
- 模块页切换模块时，`ModulesSettingsPage` 调用 `module.ResetRuntimeState()`；卫生模块借此增删现有需求。

## 3. 持久化

```text
Dialog_ModSettings 关闭
      └─ ColonyKitMod.WriteSettings()
            └─ ColonyKitSettings.ExposeData()
                  ├─ moduleSettings（按 SettingsKey 保存）
                  └─ 通用设置

读档/启动
      └─ ColonyKitSettings.ExposeData()
            └─ GetModuleSettings<T>() → 当前模块设置
```

- 设置属于 Mod 设置，不随存档；换档仍生效。
- 数值在读取点实时读，不缓存；改滑条后下一 tick/下次结算生效。
- 「重置本页」恢复默认并刷新现有小人。
- 文本豁免名单需要点「应用到现有小人」才重新评估。
