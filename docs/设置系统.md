## 简介

ColonyKit 的设置按**模块分节**：一个滚动页里依次是「通用 / 淋浴 / 立体库 / 农业 / 蓝图 / 机器人 / 本地化」，每节可折叠，节首是模块的 `Enabled` 软开关。开关只停用行为，不卸载 Def（README §3.4）。

模板已经有一套多页签设置框架和控件库；ColonyKit 不重复实现控件，M0-5 只做「模块分节 + 每模块设置对象 + 软开关语义」。

## 描述

- `ColonyKitSettings : ModSettings` 持有每个模块的设置对象（嵌套类），`ExposeData` 用 `Scribe_Deep` 按模块保存。
- 每个模块设置实现 `ICKModuleSettings`（`Enabled`、`ExposeData()`、`Reset()`）。
- key 规范：`ck_<module>_<field>`，例如 `ck_hygiene_enabled`、`ck_robotics_chargePower`；**发布后不改名**。
- `SettingsUI.Draw(Rect)` 遍历 `ModuleRegistry` 的模块顺序画分节；折叠状态只存内存，不写存档。
- 软开关的读取点统一走 `ModuleRegistry.IsEnabled(moduleId)`；Harmony 补丁、Gizmo、JobGiver、Alert 都先判它。
- 关闭窗口时 `Dialog_ModSettings.PreClose()` 自动 `WriteSettings()`；「恢复默认」只改内存。
- 控件复用模板 `SettingsWidgets`：勾选框（含禁用态）、滑块、下拉框、输入框、分区标题。

## 绘制调用逻辑图

```text
Dialog_ModSettings.PreClose()
        └─ ColonyKitMod.WriteSettings() → ColonyKitSettings.ExposeData()
                                            ├─ Scribe_Deep(hygiene)
                                            ├─ Scribe_Deep(storage)
                                            └─ …

ColonyKitMod.DoSettingsWindowContents(rect)
        └─ SettingsUI.Draw(rect)
              ├─ Section("通用")
              └─ foreach module (按 InitOrder)
                    ├─ 折叠头：Enabled 勾选 + 模块名
                    └─ 展开时：moduleSettings.Draw(listing)
                          └─ SettingsWidgets.Checkbox / Slider / Dropdown / TextField
```

## 函数清单

> 规划签名；M0 落地时以实际代码为准。

| 类型 / 函数 | 签名（规划） | 作用 |
|---|---|---|
| `ColonyKitSettings` | `class ColonyKitSettings : ModSettings` | 设置根，持有各模块设置 |
| `ColonyKitSettings.ExposeData` | `override void ExposeData()` | 按模块 `Scribe_Deep` |
| `ICKModuleSettings` | `bool Enabled { get; set; }` | 模块软开关 |
| `ICKModuleSettings.ExposeData` | `void ExposeData()` | 模块字段持久化 |
| `ICKModuleSettings.Reset` | `void Reset()` | 恢复本模块默认值 |
| `SettingsUI.Draw` | `static void Draw(Rect rect)` | 画分节设置页 |
| `SettingsUI.DrawModuleSection` | `static void DrawModuleSection(Listing_Standard, IColonyModule)` | 折叠头 + 内容 |
| `ModuleRegistry.IsEnabled` | `static bool IsEnabled(string moduleId)` | 补丁/Job 统一读取软开关 |
| `SettingsWidgets.Checkbox/Slider/Dropdown/TextField` | 见模板控件库 | 通用控件，直接复用 |

## 所含功能

- 单页分节 + 折叠，模块顺序跟 `InitOrder`；
- 每模块独立设置对象与默认值；
- 软开关统一读取点，避免各模块各写一套判断；
- 持久化 key 规范与兼容约定；
- 复用通用控件，减少排版代码；
- 关窗保存、恢复默认、Tooltip 解释软停用限制。
