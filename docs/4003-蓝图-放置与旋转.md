## 简介

选中蓝图后进入放置模式：鼠标处显示整张幽灵预览，Q/E 旋转、B 镜像；预览按条目逐条校验，只要有一条可解析条目不能放，整张蓝图就拒绝落地。确认后默认生成原版施工蓝图；上帝模式则直接生成完工建筑。

## 描述

- 落点以鼠标格为中心（`anchor = 鼠标 - (旋转后尺寸 - 1) / 2`，偶数尺寸会向左上偏半格）。
- 外框尺寸随旋转交换 `sizeX/sizeZ`；条目位置由 `GenAdj.OccupiedRect` 变换后反推 `Position`，不直接把 `Position` 当格子旋转。
- 逐条校验：
  - Def 不存在/不是可建造建筑 → 标记缺 Def，**跳过该条**，不阻塞整张；
  - 需要材质但当前策略选不出任何可用材质 → 整张拒绝；
  - 研究未完成 → 整张拒绝（上帝模式跳过）；
  - 超出地图边界 → 整张拒绝；
  - 地形/占用/水域/互动点等 → 交给原版 `GenConstruct.CanPlaceBlueprintAt`，任一失败整张拒绝。
- **材料库存不参与可放置判定**：缺料只会让殖民者等料；只有「找不到可用材质 Def」才会拒绝。
- 只要有一条非缺 Def 条目失败，`canPlace = false`，预览变红、左键拒绝并显示第一条失败原因。
- 预览/材料结果有缓存：鼠标格、旋转、镜像、材料策略或地图变化时重算；点击落地使用当前缓存结果。
- 落地是「先整张校验、通过后一次落地」：不会先生成一半再回滚；缺 Def 条目会跳过并在消息里报数量。
- 落地前用 `GenSpawn.WipeExistingThings` 清掉同格允许替换的旧蓝图/框架/建筑（与原版建造设计器一致）；不能替换的占用仍会被 `CanPlaceBlueprintAt` 拒绝。
- 放置后设计器保留，可连续放多份；右键/ESC 退出。
- 上帝模式：`CanPlaceBlueprintAt` 以 godMode 调用，研究检查跳过；落地直接 `ThingMaker.MakeThing` + `GenSpawn.Spawn` 成完工建筑，并给可拥有阵营的建筑设玩家阵营。

## 绘制调用逻辑图

```text
库中选中 → 「放置」
        │
        ▼
Designator_BlueprintPlace
        ├─ SelectedUpdate / CanDesignateCell
        │     └─ EnsurePlacements(mouse)（按鼠标/朝向/镜像/策略/地图缓存）
        │           └─ BlueprintPlacementUtility.Build
        │                 ├─ 算 anchor / 旋转后尺寸 / footprint
        │                 ├─ 逐条：Def → 材质策略 → 研究 → 变换 → 界内
        │                 │        └─ GenConstruct.CanPlaceBlueprintAt
        │                 ├─ 缺 Def → missingDef（跳过，不阻塞）
        │                 └─ 任一其他失败 → canPlace = false
        ├─ SelectedUpdate → 绿色/红色幽灵 + footprint 边框
        └─ 左键 → cachedCanPlace ?
              ├─ 否 → 消息显示 cachedFailure
              └─ 是 → BlueprintPlacementUtility.PlaceAll
                    ├─ GenSpawn.WipeExistingThings（允许替换的旧物）
                    ├─ 上帝模式 → MakeThing + Spawn（完工）
                    └─ 普通 → GenConstruct.PlaceBlueprintForBuild（施工蓝图）
```

## 所含功能

- 整张幽灵预览 + footprint 边框。
- Q/E 旋转、B 镜像、底部旋转按钮。
- 逐条可放置校验；缺 Def 跳过。
- 原版施工蓝图生成。
- 覆盖允许替换的旧建筑/框架。
- 连续放置。
- 上帝模式直接建成。
- 左下角面板显示旋转、材料策略、缺 Def、失败原因、前 4 项材料需求。

## 如何使用

**前提**：库里有蓝图；目标区域已探索；模块未软停用。

1. 库里选蓝图 →「放置」。
2. 移动鼠标；Q/E 旋转，B 镜像（底部也有旋转按钮）。
3. 看红/绿预览、footprint 边框与左下材料清单；红色说明有非缺 Def 条目不能放。
4. 左键确认，等殖民者施工；右键/ESC 取消。
5. 设计器不会自动退出，可连续点多次复刻多份。
6. 需要直接建成时先开上帝模式（`DebugSettings.godMode`），再左键。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 一片红放不下 | 地形/占用/水域/研究/无可用材质 | 换位置、清空、先研究或调材料策略 |
| 缺料但预览是绿的 | 库存不参与可放置判定 | 放下后等料，或先补料 |
| 旋转后错位 | 多格建筑朝向/非方形镜像近似 | 换朝向或手动修正；记录具体建筑 |
| 镜像后门朝向不对 | 非方形多格建筑的镜像近似 | 避免镜像或手动改门 |
| 放了但不动工 | 缺材料/没搬运工/区域不可达 | 看材料清单与 Job |
| 想撤销已放的蓝图 | 未实现落地撤销 | 按原版取消/拆除 |
| 缺 Def 的条目没变红 | 缺 Def 是跳过而不是失败 | 看黄色「将跳过 X 个建筑」与消息 |
| 研究刚完成但预览仍是红的 | 预览缓存只在鼠标/旋转/镜像/策略/地图变化时重算 | 移动鼠标或转一下刷新 |
