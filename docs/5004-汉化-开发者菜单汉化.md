## 简介

把 RimWorld **开发者模式（Dev Mode）Debug 菜单**里的动作/分类标签替换成中文。翻译表外置，可按「极简 / 常用 / 全量」或自定义方案启用；只改显示文本，不碰玩法、Def、存档。

## 描述

- 拦截 `LudeonTK.DebugActionNode.LabelNow` 的 getter（Harmony Postfix），返回翻译后的标签。
- 翻译表：`Translations/DevMenuLabels.xml`（约 72 KB，当前约 880 条词条 + 34 个菜单名）。
- 词条带 `menu` 分组；方案勾选某菜单后，该菜单下所有已知词条生效。
- 默认三个方案：极简、常用、全量；最多 10 个，可新建/删除/改名/全选/全不选/恢复默认。
- 只翻译开发者菜单与 Debug 窗口的部分 tooltip；建筑/物品/研究/Gizmo 等游戏文本不走这里。
- **覆盖层级与来源 Mod 一致**：使用同一个 `DebugActionNode.LabelNow` getter，菜单嵌套多深都经过这里；默认「全量」包含全部 34 个菜单组，quicktest 记录为 882/882 词条启用（含底部叶子条目）。
- 检测到原 `DevMenuChinese`（`local.devmenuchinese`）启用时，两个补丁都会运行；本模块仍按当前方案翻译全部 34 个菜单组，建议只保留一个以避免文本来源混乱。

## 绘制调用逻辑图

```text
LocalizationModule.OnDefsLoaded
  ├─ 检测 local.devmenuchinese
  │    ├─ 已启用 → Conflict=true，两个补丁都运行；仍加载本表
  │    └─ 未启用 → 正常加载
  │
  └─ DevLabelTranslations.Load()
        ├─ 读 Translations/DevMenuLabels.xml
        └─ 建 menus / entries / allDefs 索引
  └─ 日志：entries / menus / enabled

DebugActionNode.LabelNow (getter)
  └─ Patch_DebugActionNode_LabelNow.Postfix
        └─ LocalizationModule.ShouldTranslate?
              ├─ 否 → 返回原文
              └─ 是 → DevLabelTranslations.Translate(label)
                    ├─ 菜单名 → menus
                    ├─ 词条 → entries（按方案过滤）
                    ├─ 品质常量 → constants
                    ├─ defName → Def.LabelCap / HumanizeDefName
                    └─ 都没有 → 原文

DebugWindowsOpener.DrawButtons
  └─ Transpiler 在每个已知字符串常量后插入 TranslateTooltip
```

## 所含功能

- 开发者菜单标签中文化。
- 外置 XML 翻译表，改词条免重编译。
- 三个默认方案 + 自定义方案（最多 10 个）。
- 设置页状态/重新加载/方案编辑。
- 原 DevMenuChinese 冲突保护。
- Debug 窗口已知 tooltip 翻译。

## 如何使用

1. 游戏选项里开启开发者模式，进入一局。
2. 选项 → Mod 设置 → 殖民地套件 → 汉化。
3. 确认「启用开发者菜单汉化」；需要时点「编辑翻译方案」。
4. 选「全量」或勾选常用菜单；点「重新加载翻译表」。
5. 重新打开 Debug 菜单，标签应显示中文；切方案后重开菜单生效。
6. 改 `Translations/DevMenuLabels.xml` 后建议重启游戏（或点重新加载）。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| Debug 菜单仍是英文 | 模块/总开关关闭；开发者模式未开；方案未包含该菜单 | 检查设置页与 `Player.log` 的 `[ColonyKit][Localization]` |
| 只有部分菜单中文 | 当前方案只勾了部分菜单 | 切「全量」或勾选对应菜单 |
| 和 DevMenuChinese 同时装没效果 | 两个补丁都跑，可能互相覆盖/方案不同 | 只保留一个；或都开时用本模块「全量」 |
| 和 DevMenuChinese 同时装文本混乱 | 两个 Mod 的译法/方案不同 | 只保留一个 |
| 改了 XML 没生效 | 未重新加载/未重启 | 点「重新加载翻译表」或重启 |
| 设置页显示表未加载 | `Translations/DevMenuLabels.xml` 缺失/路径不对 | 确认文件在 Mod 根目录 `Translations/` 下 |
