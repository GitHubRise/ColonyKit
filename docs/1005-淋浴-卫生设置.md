## 简介

「选项 → Mod 设置 → 卫生」页集中调节卫生/膀胱需求速度、洁具耗水、热水消耗、脏水污染概率、DBH 策略和需求豁免。所有数值立即生效，不需要重开游戏。

## 描述

### 数值项

| 设置 | 范围 | 默认 | 实际读取点 |
|---|---|---|---|
| 卫生需求速率 | 0–5× | 1.00 | `Need_Hygiene.FallPerTick` |
| 膀胱需求速率 | 0–5× | 1.00 | `Need_Bladder.FallPerTick` |
| 洁具耗水 | 0.25–4× | 1.00 | 淋浴/浴缸/洗手池/马桶的 `waterUsed` 与每 tick 取水 |
| 热水消耗 | 0.10–2× | 1.00 | `PlumbingNet.PullHotWater` 的 `draw` |
| 脏水污染概率 | 0–300% | 100% | `SanitationUtil.ContaminationCheckWater` |

- 0× 卫生/膀胱速率 = 需求不下降；0% 污染 = 关闭脏水致病/污染标记。
- 耗水/热水倍率只影响消耗，不改建筑标称容量；实际以 `Defs/` 与游戏内 tooltip 为准。

### 策略与豁免

| 设置 | 默认 | 说明 |
|---|---|---|
| DBH 策略 | 软停用 | 软停用/始终并存/完全禁用，见 [1004](1004-淋浴-DBH共存.md) |
| 囚犯获得卫生 | 开 | 关闭后囚犯不注入需求 |
| 访客获得卫生 | 开 | 关闭后访客不注入需求 |
| 允许非人形 | 开 | 关闭后非人形不注入需求 |
| 豁免种族 | 空 | 逗号/分号分隔 `RaceDef.defName` |
| 豁免体型 | `HumanoidTerminator,AIRobot,AIPawn` | 类型 `BodyDef.defName` |
| 豁免 Hediff | 空 | 拥有任一 Hediff 即豁免 |

### 应用与持久化

- 设置属于 Mod 设置，由 `ColonyKitSettings.moduleSettings` 统一 `Scribe` 保存，不随存档。
- 复选框/下拉框修改会立即 `HygieneUtility.RefreshAllPawns`；文本框名单需点「应用到现有小人」。
- 「重置本页」恢复默认值并刷新现有小人。
- 刷新范围包含地图、商队、远行队。

## 所含功能

- 需求/耗水/热水/污染数值调节。
- DBH 三策略。
- 四类需求豁免。
- 立即刷新现有小人。
- 设置持久化与恢复默认。

## 如何使用

1. 打开「选项 → Mod 设置 → 卫生」。
2. 拖滑条或切换复选框；数值立即生效。
3. 修改种族/体型/Hediff 名单后点「应用到现有小人」。
4. 想恢复默认点「重置本页」。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 改了速率但没立刻变化 | 需求每 150 tick 才结算 | 等一个结算周期或洗澡/上厕所刷新 |
| 改了名单没生效 | 文本框需要应用 | 点「应用到现有小人」 |
| 商队小人仍有需求 | 旧版本/未刷新 | 切换模块开关或应用；当前版本已覆盖商队 |
| 0× 后需求不动 | 这是预期 | 改回 >0 |
