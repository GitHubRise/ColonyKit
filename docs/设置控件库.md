## 简介

`SettingsWidgets` 把原版零散的 `Widgets.*` 调用包成「一行一个控件」：页面只关心值和标签，不用重复摆 Rect、算行高、加 Tooltip。五个控件覆盖了 ColonyKit 计划里需要的全部基础交互。

## 描述

- `Section`：分隔线 + 小标题，用来在一个页签内分区。
- `Checkbox`：支持禁用态。`enabled: false` 时灰显不可点，Tooltip 仍显示，用来解释「为什么不能点」。
- `Slider`：左标签右滑条，`step` 做吸附，`format` 自定义右侧值文本（例如 tick + 天数）。
- `Dropdown<T>`：按 `controlMode` 分发：下拉 `FloatMenu`、◀ / ▶ 循环、或 ✓ / ✗ 列表；选项几十个以内最省事，上百项应换带搜索的窗口。
- `TextField`：单行输入，超过 `maxLength` 的输入直接丢弃、返回旧值。
- `Label` / `Button`：可检索的只读行/按钮；未命中时按钮返回 false、动作不执行。
- `Cycle`：◀ / ▶ 循环切换，首尾相接；由 `SettingsControlMode.Cycle` 启用。
- `CheckCross`：每个选项一行，选中 ✓、其他 ✗，点击整行切换；由 `SettingsControlMode.CheckCross` 启用。
- `ControlModePicker`：三张卡片并排预览三种模式，点击卡片切换；悬停套用亮色蒙版 + 2px 边框。
- 普通配置行（`Checkbox` / `Slider` / `Dropdown` / `TextField`）：悬停时灰色蒙版 + 1px 边框 + 左侧黄色强调条，和选中态区分。
- 页签悬停：亮色高亮；选中的页签保持实心背景。
- 下拉按钮统一在右侧显示 `▼`；打勾行悬停与选中态区分。
- 所有控件都参与 `SettingsSearch` 过滤（标签/Tooltip/当前 Section）；`Section` 在检索时延迟到第一个命中控件前绘制。
- 日志页是完整示例：下拉选级别 → Verbose 才可勾明细（禁用态）→ 滑块调间隔 → 输入框改前缀 → 测试日志按钮。

最小用法：

```csharp
SettingsWidgets.Section(listing, "ModTemplate.Settings.Section.Level".Translate());

SettingsWidgets.Dropdown(listing, label, data.detail, Details,
	d => ("ModTemplate.Settings.LogDetail." + d).Translate(),
	d => data.detail = d);

SettingsWidgets.Checkbox(listing, label, ref data.verboseSpawnLog, tooltip,
	enabled: data.detail == LogDetail.Verbose);

data.logIntervalTicks = (int)SettingsWidgets.Slider(listing, label,
	data.logIntervalTicks, 600f, 60000f, 600f);

data.customPrefix = SettingsWidgets.TextField(listing, label, data.customPrefix, 24, tooltip);
```

## 绘制调用逻辑图

```text
LoggingSettingsPage.DoContents(listing, settings)
        ├─ SettingsWidgets.Section(listing, title)
        ├─ SettingsWidgets.Dropdown(listing, label, data.detail, Details,
        │        d => ("…LogDetail." + d).Translate(), d => data.detail = d)
        │        └─ ButtonText → FloatMenu → onChanged
        ├─ SettingsWidgets.Checkbox(listing, label, ref data.verboseSpawnLog,
        │        tooltip, enabled: data.detail == Verbose)
        │        └─ Widgets.CheckboxLabeled(disabled: !enabled)
        ├─ SettingsWidgets.Slider(listing, label, data.logIntervalTicks,
        │        600, 60000, 600, v => "...".Translate(...))
        │        └─ Widgets.HorizontalSlider(roundTo: step)
        └─ SettingsWidgets.TextField(listing, label, data.customPrefix, 24, tooltip)
                 └─ Widgets.TextField(rect, value, maxLength)
```

## 函数清单

| 函数 | 签名 | 作用 |
|---|---|---|
| `Section` | `static void Section(Listing_Standard, string title)` | 分区标题 + 分隔线 |
| `Label` | `static void Label(Listing_Standard, string text)` | 可检索只读行 |
| `Button` | `static bool Button(Listing_Standard, string label)` | 可检索按钮 |
| `Checkbox` | `static bool Checkbox(Listing_Standard, string label, ref bool value, string tooltip = null, bool enabled = true)` | 勾选，支持禁用态 |
| `Slider` | `static float Slider(Listing_Standard, string label, float value, float min, float max, float step = -1f, Func<float,string> format = null)` | 滑块 + 值文本 |
| `Dropdown<T>` | `static void Dropdown<T>(Listing_Standard, string label, T current, IEnumerable<T> options, Func<T,string> optionLabel, Action<T> onChanged)` | 按 `controlMode` 分发 |
| `Cycle<T>` | `static T Cycle<T>(Listing_Standard, string label, T current, IEnumerable<T> options, Func<T,string> optionLabel)` | ◀ / ▶ 循环 |
| `CheckCross<T>` | `static T CheckCross<T>(Listing_Standard, string label, T current, IEnumerable<T> options, Func<T,string> optionLabel)` | ✓ / ✗ 列表 |
| `TextField` | `static string TextField(Listing_Standard, string label, string value, int maxLength = 64, string tooltip = null)` | 单行输入 |

## 所含功能

- 页内分区标题；
- 禁用态勾选 + Tooltip；
- 滑块步长吸附与自定义值格式；
- 下拉框（原生 FloatMenu，当前项标记）；
- 单行输入与长度限制；
- 控件级空值/边界处理；
- 与 `Listing_Standard` 的行布局集成。
