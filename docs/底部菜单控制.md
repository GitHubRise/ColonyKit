## 简介

RimWorld 底部主菜单（Architect / Work / Research…）由 `MainButtonsRoot` 读取 `MainButtonDef` 列表绘制。模板用 `MainButtonService` 控制显示/隐藏/排序，并额外提供一个 **独立的「模板演示」按钮** 作为底部菜单测试项；原版 Research 按钮保持原样，研究树入口在原版 Research 窗口的示例页签。

## 描述

- 可见性：`SetVisible(defName, bool)` 强制显示/隐藏；`IsVisible(def)` 检查 `def.buttonVisible`、模板设置 `showDemoButton`（仅模板演示按钮）、显式覆盖。
- 演示按钮：`Defs/Core/MainButton_Demo.xml`，defName `ModTemplate_Demo`，worker `MainButtonWorker_Demo`；点击打开贴着底栏的全宽 `DemoDrawerWindow`，再点一次按钮 / X / Close 关闭。
- 点击其他底部主菜单时，`MainTabsRoot.OpenTab` 变化，抽屉在 `WindowUpdate` 里自动收起，不需要给每个原版按钮打补丁。
- 打开抽屉前，如果当前主菜单页签不是 World，会先 `EscapeCurrentTab` 收起它；World 例外，保持打开。
- 顺序：`SetOrder(defName, int)` 记录覆盖值并立即重排；启动时 `Patch_MainButtonsRoot_Ctor` 按覆盖值排序。
- 不影响原版按钮的 Worker 行为，也不替换 Research。
- 研究树：原版 Research 窗口新增 `MT_ResearchTab` 示例页签；独立 `TechTreeWindow` 从设置「关于」/`-modtemplate-techtree` 打开。

## 绘制调用逻辑图

```text
游戏启动:
  new MainButtonsRoot()
        ├─ allButtonsInOrder = DefDatabase<MainButtonDef>.AllDefs.OrderBy(order)
        └─ Postfix → MainButtonService.ApplyOrder(root)
              └─ 按 OrderOf(def) 重排

每帧:
  MainButtonsRoot.MainButtonsOnGUI()
        └─ foreach button:
              Worker.Visible
                └─ Postfix → MainButtonService.IsVisible(def)
                      ├─ buttonVisible == false → false
                      ├─ 演示按钮 && !showDemoButton → false
                      └─ visibleOverrides → true/false
              Worker.DoButton(rect) → Activate()
                    └─ MainButtonWorker_Demo.Activate()
                          └─ DemoDrawerWindow（贴着底栏向上展开，不暂停）

运行时:
  MainButtonService.SetOrder(defName, order)
        └─ ApplyOrder(Find.MainButtonsRoot)  // 立即重排
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `MainButtonService.SetVisible` | `static void SetVisible(string defName, bool visible)` | 强制显示/隐藏 |
| `MainButtonService.ClearVisible` | `static void ClearVisible(string defName)` | 取消可见性覆盖 |
| `MainButtonService.SetOrder` | `static void SetOrder(string defName, int order)` | 调整顺序并立即重排 |
| `MainButtonService.ClearOrder` | `static void ClearOrder(string defName)` | 取消顺序覆盖 |
| `MainButtonService.IsVisible` | `static bool IsVisible(MainButtonDef def)` | 可见性判定 |
| `MainButtonService.OrderOf` | `static int OrderOf(MainButtonDef def)` | 顺序判定 |
| `MainButtonService.DemoButtonDefName` | `const string = "ModTemplate_Demo"` | 演示按钮 defName |
| `MainButtonWorker_Demo.Activate` | `override void Activate()` | 打开/关闭抽屉 |
| `DemoDrawerWindow` | `MainTabWindow` 之外的 `Window` | 全宽、贴底、向上滑入、不暂停 |
| `Patch_MainButtonWorker_Visible` | `[HarmonyPostfix]` on `Visible` getter | 叠加可见性 |
| `Patch_MainButtonsRoot_Ctor` | `[HarmonyPostfix]` on ctor | 启动时重排 |

## 所含功能

- 底部按钮显示/隐藏/排序；
- 独立于研究系统的「模板演示」按钮；
- 贴底全宽抽屉：滑入、不暂停、面板外仍可拖地图；
- 点其他底部菜单自动收起；
- 原版 Research 保持不变；
- 研究与底部菜单解耦；
- 反射失败时安全降级并记录一次警告。
