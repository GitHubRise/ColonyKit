## 简介

RimWorld 的底部主菜单（Architect / Work / Assign…）由 `MainButtonsRoot` 读取 `MainButtonDef` 列表绘制。模板提供 `MainButtonService` 统一控制可见性与顺序，并自带一个「科技树」按钮作为自定义按钮示例。

## 描述

- 可见性：`SetVisible(defName, bool)` 强制显示/隐藏；`IsVisible(def)` 依次检查 `def.buttonVisible`、模板设置 `showTechTreeButton`（仅科技树按钮）、显式覆盖。
- 顺序：`SetOrder(defName, int)` 记录覆盖值，并立即重排当前 `MainButtonsRoot`；启动时构造 Postfix 也会按覆盖值排序。
- 自定义按钮：`Defs/Core/MainButton_TechTree.xml` 定义 `MainButtonDef`，`workerClass = ModTemplate.MainButtonWorker_TechTree`；Worker 的 `Activate()` 打开 `TechTreeWindow`。
- 设置：`GeneralSettings.showTechTreeButton` 控制模板按钮是否显示；关闭后不会影响其他按钮。
- 不影响 Worker 自身行为（`Disabled`/`Activate`），只控制「是否画」和「画在哪」。
- 顺序立即生效依赖 `AccessTools` 反射拿 `MainButtonsRoot.allButtonsInOrder`；字段名随版本变化时 `ApplyOrder` 会安全返回，不崩。

## 绘制调用逻辑图

```text
游戏启动:
  new MainButtonsRoot()
        ├─ allButtonsInOrder = DefDatabase<MainButtonDef>.AllDefs.OrderBy(order)
        └─ Postfix → MainButtonService.ApplyOrder(root)
              └─ 按 OrderOf(def) 重排

每帧:
  MainButtonsRoot.MainButtonsOnGUI()
        └─ foreach button:
              Worker.Visible
                └─ Postfix → MainButtonService.IsVisible(def)
                      ├─ buttonVisible == false → false
                      ├─ 科技树按钮 && !showTechTreeButton → false
                      └─ visibleOverrides → true/false
              Worker.DoButton(rect) → Activate()
                    └─ MainButtonWorker_TechTree.Activate()
                          └─ Find.WindowStack.Add(new TechTreeWindow())

运行时:
  MainButtonService.SetOrder(defName, order)
        └─ ApplyOrder(Find.MainButtonsRoot)  // 立即重排
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `MainButtonService.SetVisible` | `static void SetVisible(string defName, bool visible)` | 强制显示/隐藏 |
| `MainButtonService.ClearVisible` | `static void ClearVisible(string defName)` | 取消可见性覆盖 |
| `MainButtonService.SetOrder` | `static void SetOrder(string defName, int order)` | 调整顺序并立即重排 |
| `MainButtonService.ClearOrder` | `static void ClearOrder(string defName)` | 取消顺序覆盖 |
| `MainButtonService.IsVisible` | `static bool IsVisible(MainButtonDef def)` | 可见性判定 |
| `MainButtonService.OrderOf` | `static int OrderOf(MainButtonDef def)` | 顺序判定 |
| `MainButtonService.TechTreeButtonDefName` | `const string` | 模板按钮 defName |
| `MainButtonWorker_TechTree.Activate` | `override void Activate()` | 打开科技树窗口 |
| `Patch_MainButtonWorker_Visible` | `[HarmonyPostfix]` on `Visible` getter | 叠加可见性 |
| `Patch_MainButtonsRoot_Ctor` | `[HarmonyPostfix]` on ctor | 启动时重排 |
