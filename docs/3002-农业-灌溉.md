## 简介

`CK_Sprinkler` 消耗水网的水和电力，把半径 5 格内的肥力逐步提升到目标值；断水/断电自动停。

## 描述

- 半径 5 格；目标肥力、每格耗水/耗电、提升速度以 Def 为准。
- 只提升网格肥力，不改地形；对非种植格无意义。
- 多台可叠加覆盖，同一格不重复计算（M4-2 定稿）。
- 断水/断电停止，肥力是否衰减 M4-7 定稿。
- 水网消费者优先级：水不够时按 M1 的规则分配。
- 雨天/露天免费灌溉首版不做。

## 绘制调用逻辑图

```text
水网 + 电力
      │
      ▼
CK_Sprinkler + CompSprinkler
      ├─ 有水有电 → 每 250 tick 提升半径内网格肥力
      ├─ 无水/无电 → 停机 + Gizmo 原因
      └─ 达到目标值 → 保持/待机
      │
      ▼
MapComponent_FertilityGrid → 作物生长
```

## 所含功能

- 半径 5 格喷灌。
- 水网/电力消耗与停机。
- 目标肥力/逐步提升。
- Gizmo 状态。
- 与覆盖层/生长联动。

## 如何使用

**前提**：研究「灌溉」；水网接电；半径内有农田。

1. 建 `CK_Sprinkler`，接水网和电。
2. 选中看半径覆盖。
3. 等待肥力上升；打开覆盖层确认。
4. 断水/断电会停；水不够时按优先级分配。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 喷灌机不工作 | 没水/没电/没接水网 | 看 Gizmo 状态与 Alert |
| 肥力不涨 | 已到目标值/半径没覆盖/断电 | 看覆盖层与半径 |
| 水消耗太快 | 多台同时开/水箱太小 | 加水箱或减少同时运行 |
