## 模块一句话

一台 3×3 的**高容量室内仓库**：四边可接履带，物品存进建筑内部；需要时从面板取出，不占地图格；自带可调温控。

## 快速开始（草案）

当前版本先验证 **堆叠规则 + 内部库存原型**：

1. 打开 **选项 → Mod 设置 → 殖民地套件 → 立体库**。
2. 勾选「启用堆叠增强」，设置 1–20× 倍率。
3. 进游戏，在 **Furniture** 分类建 `CK_VerticalWarehouse`（3×3），接电，并在任意一边接一条履带（1×1 双向或 1×1 转向盘，任意相邻格）；相邻的立体库会互联，整个网络只要有一条履带即可。仓库自带温控，默认 4°C。
4. 选中建筑：检视面板有检索框/滚动条，可查看库存/逐堆取出；**Storage** 页设置过滤/优先级（默认不允许腐烂/尸体）；温控用原版温度 Gizmo 调；Gizmo 收集附近物品或全部取出。
5. 底部主菜单 **立体库** 打开管理标签页，可检索本图全部仓库并选中跳转。
6. 履带会自动路由到最近的立体库；取货需要小人搬运或玩家手动处理。
7. 研究菜单新增 **立体仓库** 页签：一级（×10，800，Electricity）→ 二级（×30，解锁核心）→ 三级（×60，解锁履带，核心温控 -20～30°C）。
8. 自动入库在普通库存区放不下/无库存区，或仓库优先级更高时接手；仓库默认 **Normal** 优先级。自动出库要求目标库存区优先级高于仓库；没有履带时自动入/出库停止。

## 容量与电力

- 容量默认 **24 堆**，可在 **Mod 设置 → 立体库 → 立体库容量** 调到 1–200；对已建和新建仓库立即生效。
- T1/T2/T3 研究只提升堆叠倍率（×10 / ×30 / ×60），不改变堆数。
- 电力 250W 仅用于温控；断电时库内物品不丢，入库/出库仍可用。

## 依赖与兼容

- 依赖原版电力，不依赖水网。
- Stack XXL：叠加会改变单堆数量，容量口径要按「堆」还是「件」重新确认（M3-7）。
- LWM Deep Storage 类 Mod：功能重叠，检测到会提示。
- 与 DBH 的仓库类建筑不冲突。

## 已知限制 / 待确认

- **当前只做了堆叠规则 + 3×3 内部库存 + 双向自动 Job + 1×1 双向履带/转向盘实体与移动**：账单、T2/T3、腐烂策略仍未实现；详见 [2006](2006-立体库-堆叠规则.md)、[2007](2007-立体库-内部库存原型.md)、[2008](2008-立体库-转向盘.md)、[2009](2009-立体库-双向履带.md)。
- 容量默认 24 堆，可在设置页调整；T1/T2/T3 研究只改变堆叠倍率。
- 自动入/出库要求整个仓库网络至少有一条履带接在四边端口；没有履带时只保留手动 ITab/拆除掉落，并闪烁红色履带图标。
- 原型已接自动入库/出库；库内资源会计入原版底部资源列表，但**原版账单仍不能直接取库内物品**。
- 默认过滤不允许腐烂物品/尸体；可在原版 Storage 页手动允许。
- 自动入库在库存区放不下/无库存区，或仓库优先级更高时接手；自动出库要求目标库存区优先级高于仓库（仓库默认 **Normal**）。
- 库内物品的腐烂/防火策略还没定：完全隔绝还是照常计时。
- 拆除建筑时物品掉落的规则见 2005。
- 容量单位「堆」在 Stack XXL 下会变化，UI 需要同时显示件数。
- 堆叠规则排除武器/衣物/尸体/最小化建筑/科技义体；这些留给仓库按重量合并。
