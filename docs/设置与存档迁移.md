## 简介

设置和存档都会随版本演进：加字段、改结构、把非法值夹回范围。模板提供：

- `ModTemplateSettings.schemaVersion` + `SettingsMigration` 迁移链；
- 启动时把旧设置复制为 `.bak`；
- `Validate()` 统一纠正非法值，并在迁移/写盘前调用；
- `DemoGameComponent.saveVersion` + `MigrateSave()` 处理旧存档。

## 描述

- 设置版本：`SettingsMigration.CurrentVersion = 2`（1 = 嵌套结构，2 = 模块开关 + 框架日志级别）。
- 迁移时机：`ModTemplateSettings.ExposeData` 的 `LoadSaveMode.PostLoadInit`；`Migrate` 按 `from` 逐级补默认值/结构。
- 备份：`ModTemplateMod` 构造时先调 `SettingsMigration.BackupSettings(folder, type)`，把 `Config/Mod_<folder>_<type>.xml` 复制为 `.bak`，再读取。
- 回写：迁移或校验改过值 → `SettingsMigration.ConsumeDirty()` 为 true → 构造末尾 `WriteSettings()`。
- 写盘前校验：`ModTemplateMod.WriteSettings` 覆写为 `Settings?.Validate()` 后 `base.WriteSettings()`。
- `Validate` 规则：
  - 日志间隔 600–60000 tick；
  - 日志前缀去空白、截 24 字符；
  - `LogDetail` / `ModLogLevel` 必须是合法枚举；
  - 通知冷却 60–6000 tick；
  - 模块禁用列表去空值/重复。
- 存档版本：`DemoGameComponent.saveVersion` 默认当前版本；旧存档没有该节点 → 0 → `MigrateSave` 补到 1 并写迁移日志。字段/语义变化时递增并在 `MigrateSave` 里补步骤。
- 迁移/校验日志用 `Log` 直接写（设置尚未读完时不能走 `ModLog`）。
- 旧的**扁平**设置（v0，字段直接在根节点）只能恢复默认嵌套值，旧字段值不会自动搬到新结构；需要时在 v0→v1 步骤里手工读取旧节点。

## 绘制调用逻辑图

```text
ModTemplateMod 构造
  ├─ SettingsMigration.BackupSettings(folder, type) → Config/Mod_…xml.bak
  ├─ GetSettings<ModTemplateSettings>()
  │     └─ ExposeData（Loading）
  │           ├─ Scribe schemaVersion / general / logging / notifications / modules
  │           └─ PostLoadInit → SettingsMigration.Migrate(settings)
  │                 ├─ from<1：旧扁平结构 → 嵌套默认值
  │                 ├─ from<2：补 modules
  │                 ├─ settings.Validate()
  │                 ├─ schemaVersion = CurrentVersion
  │                 └─ dirty = true
  └─ ConsumeDirty()? → WriteSettings()
        └─ Settings.Validate() → base.WriteSettings()

新游戏/读档
  DemoGameComponent.ExposeData
    ├─ Scribe saveVersion / spawnsTracked / nextLogTick
    └─ PostLoadInit → MigrateSave()
          ├─ saveVersion 0 → 1
          └─ Log "[Migration] save data migrated 0 -> 1"
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `SettingsMigration.CurrentVersion` | `const int = 2` | 当前设置 schema |
| `SettingsMigration.Migrate` | `static void Migrate(ModTemplateSettings)` | 逐级迁移 + 校验 |
| `SettingsMigration.BackupSettings` | `static void BackupSettings(string folder, string type)` | 启动备份 `.bak` |
| `SettingsMigration.ConsumeDirty` | `static bool ConsumeDirty()` | 是否需要回写 |
| `ModTemplateSettings.schemaVersion` | `int` | 设置 schema 版本 |
| `ModTemplateSettings.Validate` | `bool Validate()` | 聚合各页校验 |
| `LoggingSettings.Validate` | `bool Validate()` | 夹范围/截前缀/枚举 |
| `NotificationSettings.Validate` | `bool Validate()` | 冷却夹范围 |
| `ModuleSettings.Validate` | `bool Validate()` | 去空值/重复 |
| `ModTemplateMod.WriteSettings` | `override void WriteSettings()` | 写前校验 |
| `DemoGameComponent.saveVersion` | `int` | 存档 schema |
| `DemoGameComponent.MigrateSave` | `void MigrateSave()` | 存档迁移 |

## 所含功能

- 设置 schema 版本与迁移链；
- 旧设置 `.bak` 备份；
- 迁移/校验后的自动回写；
- 写盘前统一校验；
- 数值夹取、前缀截断、枚举合法性；
- 存档数据版本与迁移钩子；
- 迁移日志（设置未就绪时用原版 `Log`）。
