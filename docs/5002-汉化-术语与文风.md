## 简介

统一六个模块的术语、文风和键命名，避免同一个东西在淋浴页叫「卫生」、在机器人页叫「清洁度」。

## 描述

高频术语表（草案）：

| 英文 | 简中 | 说明 |
|---|---|---|
| Hygiene | 卫生 | 需求名；不要译成「清洁」 |
| Clean | 清洁 | 工作类型/动作 |
| Shower | 淋浴器 | 建筑；「洗澡」是动作 |
| Water network | 水网 | 管道/泵/箱的整体 |
| Vertical warehouse | 立体库 | 建筑；不要叫「仓库」 |
| Storage filter | 存储过滤 | 原版 StorageSettings |
| Fertility | 肥力 | 网格/地形都用它 |
| Irrigation | 灌溉 | 喷灌动作 |
| Compost | 堆肥 | 过程/建筑 |
| Fertilizer | 肥料 | 物品 |
| Blueprint | 蓝图 | 捕获/放置的对象 |
| Robot | 机器人 | 智能机器人模块 |
| Charging pod | 充电桩 | `CK_ChargingPod` |
| Dormant charge | 休眠快充 | 4h 模式 |
| Energy | 能量 | 需求名；UI 可显示「电量」 |
| Shutdown | 停机 | 0% 状态，不是死亡 |
| Localization | 汉化/本地化 | 模块名用「汉化集合」 |

- 键命名：`ColonyKit.<Module>.<Area>.<Name>`；DefInjected 用 `<defName>.<field>`。
- 文件名按模块拆：`Hygiene.xml`、`Storage.xml`、`Robotics.xml`。
- 中文与数字/英文之间加空格；Alert 先说「缺什么」再说「怎么修」。
- 机器人用「它」，避免人格化。

## 所含功能

- 高频术语表。
- Keyed/DefInjected 命名规则。
- 文风/长度/标点规范。
- 贡献与校对流程。
- 与校验脚本衔接。

## 如何使用

1. 新增文本先改英文基准。
2. 查术语表确定译法。
3. 在简中文件补同名键。
4. 跑 `check-l10n`（5003），再进游戏看截断/语序。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 同一词两种译法 | 没查术语表 | 统一到本页/`l10n.md` |
| 句子太长被截断 | 中文比英文长 | 缩短或拆行 |
| 占位符丢失 | 翻译时删了 `{0}` | 保留占位符 |
