## 0.0.2 变更

- **默认打开交互**：底部按钮打开贴底全宽 `ModDrawerWindow`，向上滑入、不暂停、面板外可拖地图；点其他底部菜单自动收起，打开时收起其他页签（World 例外）。
- 原版 Research 新增 `MT_ResearchTab` 页签 + 15 个示例研究；不再注册研究树底部按钮，底部「模板演示」为独立测试项。
- 修复清洁构建 `CS0618`、通知早期 `TickManager`、`Dropdown` 空 options、主按钮反射静默失败、robocopy 退出码、配方 products 语法。
- `build.ps1` 默认 `-t:Rebuild`，警告视为失败；新增 `-NoRebuild`；部署 `/MIR`。
- 新增 `smoke-test.ps1`、CI、`05-demo-drawer` 截图场景。

## 已知限制（0.0.2）

- 模块仍编译在同一个 DLL，没有独立程序集与热卸载。
- `DefInjected`、原版 Close 按钮不参与 `ModLoc` 设置语言覆盖。
- 检索只覆盖当前页。
- 研究树绘制、UI 自动化截图、非空建造规则等仍需发布前人工复验。

## 版本号规则

- `0.0.x`：预发布/脚手架迭代，允许调整 API 与文档结构。
- `0.x.0`：模块契约、设置 schema 或存档结构发生不兼容变化。
- `1.0.0`：模板 API、文档与升级路径稳定。

发版时必须同步：

1. `About/About.xml` 的 `modVersion`；
2. `CHANGELOG.md` 增加对应小节；
3. 本文件「当前版本」表；
4. 各功能文档头部的「适用：Mod Template x.y.z」；
5. `package.ps1` 产出的 zip 名与文件数；
6. git 提交 + `vX.Y.Z` tag。
