## 简介

机器人是玩家阵营的机械族工人，靠研究 + 建造工作站获得。它们不需要吃饭/睡觉/娱乐/心情，只消耗电能；没电不是死亡，而是停机。

当前落地的是**保姆机器人**：一个型号承担扫地、清洁、搬运、灭火、屠宰、发电机加燃料、囚犯送餐、卫生维护和优先救援；设置页统一开关与阈值，单机可暂停/召回/前往/点选污渍/改名/涂装。Pawn 架构为 **ToolUser 机械族 + 自定义 ThinkTree**，不依赖 Biotech；耐久 1000、可维修、0 报废。其余专用型号仍是规划。

## 描述

| 型号 | 默认工作 | 关键能力 | 备注 |
|---|---|---|---|
| 搬运机器人 | `Haul` | 高携带、移速略高 | 不做清洁/做饭 |
| 清洁机器人 | `Clean` | 清洁速度加成 | 不做搬运 |
| 做饭机器人 | `Cook` | 烹饪技能高 | 不做种植/屠宰 |
| 医疗机器人 | `Doctor` | 医疗技能高，可照顾病人 | 手术是否开放由 M6-0 定 |
| 战斗机器人 | 无工作，只能 draft | 射击/近战、可穿护甲 | draft 时不自动充电 |

- **能量**：`Need_RobotEnergy`（0–1）。满电行动 12 小时（30000 tick），活跃耗电 `1/30000` 每 tick；0% 停机（不是死亡）。
- **充电桩**：`CK_ChargingPod`（1×2，独占）。
  - 普通对接：8 小时充满（20000 tick），`1/20000` 每 tick，功耗 2000W；不算睡眠，可被中断。
  - 休眠快充：4 小时充满（10000 tick），`1/10000` 每 tick，功耗 4000W；视为睡眠，完全无防备。
- **需求裁剪**：移除 Food / Rest / Joy / Mood / Beauty / Comfort / Social；不睡眠、不社交、不生育、无背景故事/特质。
- **自主充电**：电量 < 25% 自动找桩；< 5% 强制休眠快充；0% 原地停机，可被搬运后恢复。draft 中不自动去充，低电强制解除 draft。
- **休眠 = 睡眠**：只让 `PawnUtility.IsSleeping` 返回 true，参与「是否在睡觉」判断；不给机器人加 `Need_Rest`。
- **EMP/断电**：断电停止充电；EMP 眩晕并额外掉电（可选）。
- **获得**：研究「机器人学」→ 机械加工台/精密装配台制造；成本含塑钢/零部件/高级零部件/AI 核心（可选）。

## 绘制调用逻辑图

```text
Need_RobotEnergy 每 tick 下降
      │
      ├─ ≥ 25%：正常工作
      ├─ < 25%：JobGiver_SelfCharge → 找空闲充电桩 → JobDriver_Charge（普通）
      ├─ < 5% ：强制休眠快充 → JobDriver_DormantCharge（4000W，视为睡眠）
      └─ = 0% ：停机（downed），可被搬运到桩后恢复
                        │
                        ▼
              CK_ChargingPod（独占）
                ├─ 通电：按普通/休眠模式充能
                └─ 断电/被占：排队或失败原因

draft 中：
  不触发自动充电；电量低于阈值强制解除 draft
```
