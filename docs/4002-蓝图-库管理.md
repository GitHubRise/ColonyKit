## 简介

「蓝图库」是当前存档里所有蓝图记录的列表：查看尺寸/建筑数/材料统计，重命名、删除、选择放置。

## 描述

- 首版每存档一份，由 `ColonyKitGameComponent` 持有；换存档看不到（M5-7 再考虑导入导出/全局库）。
- 删除只删库记录，不影响地图上已建建筑。
- 材料统计按当前 Def 重新计算，Mod 更新后可能变化。
- 蓝图数量/存档体积上限 M5-0 定稿；过多时需分页/搜索。
- 关闭窗口不影响已捕获蓝图。

## 所含功能

- 当前存档蓝图列表。
- 尺寸/建筑/材料详情。
- 重命名/删除。
- 放置入口。
- 随存档保存。
- 模板区：内置默认模板（只读）+ 玩家模板，同名时玩家版本优先。

## 如何使用

**前提**：至少捕获过一条蓝图。

1. 底部「蓝图」页，左侧选条目。
2. 右侧看尺寸/建筑数/材料清单（缺料红色）。
3. 「另存为模板」写到 `Config/ColonyKit/Blueprints`；下方模板区可「载入 / 删除 / 刷新」。内置模板带「内置」标记，只能载入，不能删除；玩家保存的同名模板会覆盖内置版本的显示。
4. 「放置」进入 4003。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 换存档看不到蓝图 | 每存档库 | 用导入/导出（后续）或重新捕获 |
| 材料数对不上 | Def/材质变化 | 以放置时清单为准 |
| 删不掉 | 有确认框/权限 | 再确认一次 |
