## 简介

「蓝图」标签页同时管理两条数据：**当前存档的蓝图库**（捕获下来的记录）和**跨存档模板**（磁盘 XML）。左侧选记录，右侧看尺寸/建筑数/材料，可置顶、分组、打标签、编辑、删除、放置、另存为模板；下方模板区可载入或删除玩家模板。

## 描述

- 蓝图库**每存档一份**，由 `BlueprintGameComponent` 持有并随存档保存；换存档看不到上一局的库。跨存档复用走「另存为模板 → 在新存档载入」。
- 库数量上限 `maxRecords` 默认 256，只在**捕获入口**检查；从模板「载入」会直接入库，当前不额外检查上限。
- 删除库记录只删存档里的记录，不影响地图上已建建筑，也不删除磁盘模板。
- 材料统计按当前 Def + 当前材料策略实时重算；Mod 改配方/材质后数字会变。
- 组织：每条记录可置顶、填分组、加最多 8 个标签。置顶记录排在最前；其余按分组名排序，未分组排在最后。分组/标签只影响列表显示与筛选，不参与放置。
- 左侧顶部有筛选框：匹配名称、分组或标签；输入 `#标签` 只搜标签。页面仍不分页，库/模板多了靠滚动。
- 模板分两层：
  - 玩家模板：`Config/ColonyKit/Blueprints/*.xml`，可保存、载入、删除；
  - 内置模板：Mod 根目录 `Blueprints/*.xml`，随包发布、**只读**，同名玩家模板优先显示。

### 页面布局

| 区域 | 内容 |
|---|---|
| 顶部 | 「蓝图」标题、`已保存 X/Y`、三个材料策略按钮、右上「捕获蓝图」 |
| 左侧列表（300 px） | 筛选框 + 分组标题；每条：★置顶标记、名称、`尺寸×尺寸，N 个建筑`、`#标签`；选中高亮；滚动 |
| 右侧详情 | 名称、`尺寸 · 建筑数 · 捕获 tick`、分组、标签、放置/编辑/置顶/删除/另存为模板、材料清单、模板区 |
| 材料区 | 按策略汇总的 `材料 ×需求（现有 N）`；不足显示红色；下方列出「原 X → Y」替换 |
| 模板区 | 刷新按钮 + 模板行：`[分组] 名称 尺寸×尺寸 #标签`；载入 / 内置标记 / 删除 |

右键点击左侧记录可直接「置顶 / 取消置顶 / 编辑属性」；置顶记录统一归入「置顶」分组，不再按原分组显示标题（行内仍显示分组名）。

材料策略按钮直接改 Mod 设置（`materialMode`）并立即 `WriteSettings()`，不需要关窗口保存。


### 模板文件格式

内置与玩家模板共用同一格式，根节点必须是 `ColonyKitBlueprint`：

```xml
<?xml version="1.0" encoding="utf-8"?>
<ColonyKitBlueprint schema="1">
  <name>示例</name>
  <sizeX>19</sizeX>
  <sizeZ>19</sizeZ>
  <createdTick>65425</createdTick>
  <group>卧室</group>
  <tags>
    <li>双人</li>
    <li>木头</li>
  </tags>
  <entries>
    <entry def="Wall" stuff="Plasteel" rot="0" x="0" z="0" />
  </entries>
</ColonyKitBlueprint>
```

- 保存：文件名由蓝图名清洗（非法字符替换为 `_`、去首尾空格/点/下划线、最长 64 字符），同名文件自动加 ` (2)`，**不覆盖**旧文件。
- `group` 与 `tags` 可选；缺省 = 未分组/无标签。标签每个最长 24 字符、最多 8 个；`pinned` 不写入模板，载入后默认不置顶。
- 读取：只校验根节点与字段；缺 `name` 会用默认名，尺寸缺失按条目范围反推；没有条目则整张报「模板里没有建筑」。
- `schema="1"` 目前只写出，读取时不校验、也不做版本迁移。
- 坏文件不会抛异常：模板行显示红色「文件名 — 错误」，不提供载入按钮。
- 内置模板与玩家模板同名时只显示玩家版本；删掉玩家版本后，内置版本会重新出现并带「内置」标记。

## 所含功能

- 当前存档蓝图列表与自动选中。
- 尺寸、建筑数、捕获 tick、分组、标签、材料需求/现有、替换说明。
- 置顶（详情按钮/右键菜单，★ 标记）；置顶记录排在列表最前。
- 分组标题：按组名排序，未分组最后；右键/编辑可改分组。
- 标签：最多 8 个，列表显示 `#标签`；顶部筛选框按名称/分组/标签过滤。
- 编辑（名称/分组/标签/置顶）、删除（确认）、放置入口。
- 三档材料策略快捷切换，写回 Mod 设置。
- 模板区：刷新、载入、删除；内置模板只读标记；坏文件错误行；模板保留分组/标签。
- 库随存档保存；模板跨存档复用。
- 内置默认模板随 Mod 发布。

## 如何使用

**前提**：已进入有地图的存档；蓝图模块未软停用。

1. 底部「蓝图」页，左侧选条目（首次进入自动选第一条）。
2. 右侧看尺寸/建筑数/材料清单；缺料显示红色。
3. 组织：点「编辑」填名称/分组/标签/置顶，或在左侧行上右键快速置顶/编辑。分组名相同的记录会显示在同一个标题下；置顶记录统一排最前。
4. 筛选：左侧顶部输入名称/分组/标签片段；输入 `#标签` 只搜标签。清空输入框恢复全部。
5. 需要跨存档复用：点「另存为模板」写到 `Config/ColonyKit/Blueprints`（保留分组/标签）；新存档在模板区点「载入」。
6. 模板区：内置模板带「内置」标记、只能载入；玩家模板可「删除」，删除有确认。
7. 「放置」进入 4003；「编辑」改库记录名不会改磁盘文件名。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 换存档看不到蓝图 | 库是每存档一份 | 旧存档「另存为模板」，新存档「载入」 |
| 载入后名字多了 ` (2)` | 当前库里已有同名记录 | 正常去重；可编辑改名 |
| 内置模板删不掉 | 随 Mod 发布、只读 | 只能载入；要改就另存为玩家模板 |
| 模板行是红色的 | XML 坏/根节点不对/没有条目 | 修文件或删掉；看行尾错误 |
| 删了玩家模板后内置又出现 | 同名内置模板兜底 | 正常行为 |
| 置顶后不在原分组里了 | 置顶统一归入「置顶」段，行内仍显示分组名 | 取消置顶即回到原分组 |
| 载入模板后没有置顶 | `pinned` 不写入模板 | 正常；载入后手动置顶 |
| 标签/分组没保存 | 模板 XML 只保存 `group`/`tags`；存档保存全部 | 检查存档/模板文件 |
| 筛选后没结果 | 关键词不匹配名称/分组/标签 | 清空筛选或换关键词；`#` 只搜标签 |
| 材料数对不上 | Def/材质/策略变化 | 以当前难度与策略下的清单为准 |
| 库超过设置上限 | 模板载入不检查上限，只有捕获检查 | 手动删几条旧记录 |
