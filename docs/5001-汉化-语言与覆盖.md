## 简介

本 Mod 的文本支持哪些语言、覆盖哪些内容、怎么切换，以及缺翻译时游戏里会显示什么。

> 0.0.1 先落地的是**开发者菜单汉化**（见 [5000-汉化索引.md](5000-汉化索引.md)）；本页描述的六个模块 `Keyed`/`DefInjected` 全文本覆盖仍规划。

## 描述

- 覆盖六个模块的 `Keyed`：设置页、Gizmo、Alert、弹窗、拒绝原因、玩家可见日志。
- 覆盖六个模块的 `DefInjected`：建筑/研究/念头/物品/机器人型号的 `label` / `description`。
- 语言：英文（基准）、简体中文；繁体中文可选（M7-4）。
- 缺键显示 `Keyed.xxx`；缺 DefInjected 显示英文/defName。
- 切换语言不需要重开存档；已打开的窗口要关掉重开。
- 不在代码里硬编码玩家可见文本。

## 绘制调用逻辑图

```text
Languages/<语言>/Keyed/*.xml
Languages/<语言>/DefInjected/<DefType>/*.xml
        │
        ▼
LoadedLanguage 加载
        ├─ Keyed → Translate("ColonyKit....")
        └─ DefInjected → Def.label / description
        │
        ▼
UI（设置/研究/建筑/Gizmo/Alert）
        │
        └─ 缺键 → 显示 Keyed.xxx（测试重点）
```

## 函数清单

| 类型 / 函数 | 签名（规划） | 作用 |
|---|---|---|
| `LanguageDatabase`（原版） | 复用 | 语言切换 |

## 所含功能

- 英文/简中/繁中（可选）语言包。
- Keyed 与 DefInjected 覆盖。
- 语言切换与回退。
- 缺键表现与测试。
- 与术语/校验页的衔接。

## 如何使用

1. 游戏「选项 → 语言」选择简体中文/English。
2. 重载后进游戏，看设置页/研究页/建筑描述。
3. 出现 `Keyed.xxx` 记录键名，去补翻译。
4. 切换语言后关掉已打开窗口再开。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 设置页出现 `Keyed.xxx` | 缺 Keyed 键 | 补对应语言文件 |
| 建筑名是英文 | 缺 DefInjected | 补 `DefInjected/ThingDef/` |
| 切了语言没变 | 窗口缓存/没重载 | 关窗重开或重启 |
