## 简介

同一个枚举设置可以有三种交互：点击弹出 `FloatMenu` 下拉选择、用 `◀` / `▶` 逐个循环，或把每个选项画成一行、选中打 ✓、未选中打 ✗。模板用全局设置 `GeneralSettings.controlMode` 切换，所有走 `SettingsWidgets.Dropdown` 的控件自动跟随。

## 描述

- 模式枚举：`SettingsControlMode.Dropdown`（默认）/ `Cycle` / `CheckCross`。
- 持久化：`GeneralSettings.controlMode`，Scribe key `controlMode`；`Validate` 遇到非法枚举回退下拉框。
- 设置入口：常规页「界面」分区的「选项控件」；它本身也走 `Dropdown`，所以切到循环/打勾后自己也会变成对应形态。
- 分发：`SettingsWidgets.Dropdown` 先看当前模式；`Cycle` 模式转调 `Cycle`，`CheckCross` 模式转调 `CheckCross`，否则保留原来的 `FloatMenu`。
- 循环行为：
  - 首尾相接：第一项按 `◀` 到最后一项，最后一项按 `▶` 到第一项；
  - 当前值不在选项里时，`▶` 落到第一项、`◀` 落到最后一项；
  - 左右按钮带「上一项 / 下一项」Tooltip；
  - 当前值居中显示，行高与下拉框一致（30px）。
- 打勾行为：
  - 选项标题一行，下面每个选项一行；
  - 当前项前缀 `✓`，其他项前缀 `✗`；
  - 点击任意一行即选中，整行都是按钮；
  - 每行带「选择该项」Tooltip；
  - 适合 2–5 个选项，比下拉少一次点击。
- 卡片布局：三张卡片等宽，间距 12px、内边距 8px；卡片标题、示例行之间留 4px。
- 悬停：鼠标经过卡片或 ✓/✗ 行时显示亮色蒙版 + 2px 边框；选中态是实心底色，两者能区分。
- 下拉按钮：当前值右侧固定显示 `▼`，避免看起来像普通按钮。
- 打勾列表：每个选项整行 26px 高、可点，选中/悬停共用高亮，行间留 8px。
- 检索：`Cycle` / `CheckCross` 同样走 `BeginControl`，标签参与当前页过滤；被过滤时返回原值。
- 适用：枚举、少量固定选项（日志明细/框架日志级别/控件模式）。选项很多时仍建议下拉/搜索窗口。

## 绘制调用逻辑图

```text
SettingsWidgets.Dropdown(listing, label, current, options, optionLabel, onChanged)
      │
      ├─ controlMode == Cycle ?
      │     ├─ 是 → SettingsWidgets.Cycle(...)
      │     │        ├─ BeginControl（检索）
      │     │        ├─ ◀ → 前一项（首项回绕到末项）
      │     │        ├─ ▶ → 后一项（末项回绕到首项）
      │     │        └─ 返回新值 → Dropdown 调 onChanged
      │     └─ 否 → controlMode == CheckCross ?
      │              ├─ 是 → SettingsWidgets.CheckCross(...)
      │              │        ├─ 选项标题
      │              │        ├─ 每项一行：✓ 当前 / ✗ 其他
      │              │        └─ 点击整行 → 返回该值 → onChanged
      │              └─ 否 → 原下拉框
      │                       ├─ ButtonText(current)
      │                       └─ FloatMenu(options, 当前项 ✓) → onChanged
      │
      └─ 页面把返回值写入 data（Cycle）或由 onChanged 写入（Dropdown）
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `SettingsControlMode` | `enum { Dropdown, Cycle, CheckCross }` | 展示模式 |
| `GeneralSettings.controlMode` | `SettingsControlMode` | 持久化模式 |
| `SettingsWidgets.Dropdown<T>` | `static void Dropdown(Listing_Standard, string, T, IEnumerable<T>, Func<T,string>, Action<T>)` | 按模式分发 |
| `SettingsWidgets.Cycle<T>` | `static T Cycle(Listing_Standard, string, T, IEnumerable<T>, Func<T,string>)` | ◀ / ▶ 循环，返回新值 |
| `SettingsWidgets.CheckCross<T>` | `static T CheckCross(Listing_Standard, string, T, IEnumerable<T>, Func<T,string>)` | ✓ / ✗ 列表，返回新值 |
| `GeneralSettings.Validate` | `bool Validate()` | 非法枚举回退 Dropdown |
| `GeneralSettingsPage` | `DoContents` | 「选项控件」入口 |
