## 简介

搬运工把符合过滤条件的物品送到立体库的**入库口**，物品被收进建筑内部，不占地图格；同类物品会合并到已有堆。

## 描述

- `WorkGiver_HaulToWarehouse` 让搬运工接活：取货 → 走到入库口 → 存入。
- 入库口是建筑固定格（M3-1 定稿）；小人不需要进入建筑内部。
- 过滤/优先级不满足、库满、断电、被禁用时拒收。
- 一次搬运按原版携带量；入库后按堆合并。
- 过滤变更后，已计划的 Job 可能继续完成，下一次按新过滤。
- 与 Stack XXL 同开时，单堆上限变化会影响合并与堆数。

## 绘制调用逻辑图

```text
小人取货
   │
   ▼
WorkGiver_HaulToWarehouse
   │ 选择目标库（过滤/优先级/容量）
   ▼
JobDriver_StoreInWarehouse
   │ 走到入库口
   ▼
CompWarehouse.TryAccept(thing)
   ├─ 过滤不允许 → 拒收（留在小人身上/地上）
   ├─ 已满 → 拒收
   ├─ 断电/禁用 → 拒收
   └─ 接受 → 合并到已有堆 / 新堆
   │
   ▼
库存 ITab 更新
```

## 如何使用

**前提**：库已建好、通电、未满；过滤允许该物品。

1. 设置过滤/优先级（2004）。
2. 殖民者自动接活；物品送到入库口。
3. 在 ITab 看库存增加。
4. 出问题看 Job 失败原因/Alert。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 东西一直不搬 | 过滤不允许/优先级低/库满/没电 | 看 2004 与 ITab |
| 搬到门口又放下 | 入库口被占/建筑被禁用 | 清出入口/启用建筑 |
| 堆数对不上 | Stack XXL 改了单堆件数 | 看件数而不是堆数 |
