## 简介

搬运工把符合过滤条件的地面物品送进立体库内部；入库不占地图格，同类物品会优先并进已有堆，空间不够时再开新堆。

## 描述

- 扫描器：`WorkGiver_HaulToWarehouse`，工作类型 **Hauling**，`priorityInType=14`，需要 `Manipulation` 能力。
- 候选物品：`ThingRequestGroup.HaulableEver` 中 `listerHaulables.ThingsPotentiallyNeedingHauling()` 的物品；跳过未生成、被禁用、堆数为 0 的物品。
- 选库：`FindWarehouse` 遍历玩家立体库，要求 `warehouse.CanStore(thing)` 且小人能到达 `InteractionCell`；取**第一个**满足条件的仓库（不按距离/优先级排序）。
- 让位规则：如果原版能找到一个可放该物品的库存格，且**仓库优先级 ≤ 该库存区优先级**，则返回 false，把活让给原版搬运；仓库优先级更高，或没有可放库存格时才接手。仓库默认 **Normal**。
- 执行：`JobMaker.MakeJob(JobDefOf.HaulToContainer, thing, warehouse)`，`job.count = thing.stackCount`；实际取货/携带/存入复用原版 `JobDriver_HaulToContainer`，没有单独的入库 JobDriver。
- 存入：`Building_VerticalWarehouse.TryStore` → `Accepts`（物品类别/尸体/最小化/`StorageSettings.AllowedToAccept`）→ `Container.CanAcceptAnyOf`（按库内倍率/堆数判断）→ `WarehouseThingOwner.TryAdd`。
- 合并：先并进未到库内上限的同类堆；剩余再作为新堆加入，最多 `MaxStacks` 堆。库内堆可以超过全局 `stackLimit`，但不会超过库内上限（普通地图堆本身 ≤ 全局上限）。
- 电力：**入库不需要电**；断电只影响温控。过滤/优先级修改只影响后续接活，已经开始的 Job 可能继续完成。
- 当前没有独立的「入库口」实体，也没有拒绝原因文本/Alert。

## 绘制调用逻辑图

```text
地上有可搬运物品
   │
   ▼
WorkGiver_HaulToWarehouse.HasJobOnThing
   ├─ 未生成/被禁用/堆数 0 → false
   ├─ 小人不能预约/到达 → false
   ├─ FindWarehouse：CanStore + 可到 InteractionCell
   ├─ 原版能找到库存格，且仓库优先级 ≤ 库存区优先级 → 让位
   └─ 否则 → JobDefOf.HaulToContainer（count = 整堆）
                     │
                     ▼
          JobDriver_HaulToContainer（原版）
                     ├─ 取货
                     ├─ 走到仓库
                     └─ IThingHolder.TryAdd → WarehouseThingOwner
                              ├─ 并进已有堆（≤ 库内上限）
                              └─ 或开新堆（≤ MaxStacks）
```

## 所含功能

- 搬运工自动入库。
- 过滤/容量检查。
- 普通库存区优先的让位规则。
- 堆合并与库内上限。
- 断电仍可入库。

## 如何使用

**前提**：库已建好；过滤允许该物品；还有空堆或可合并空间；普通库存区放不下，或仓库优先级更高。

1. 在 **Storage** 页设置过滤/优先级（默认 Normal）。
2. 让搬运工自然接活；想强制入库可提高仓库优先级或填满普通库存区。
3. 在检视面板/管理页看堆数与件数变化。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 东西一直不搬 | 过滤不允许、库满、仓库优先级不高于库存区、无可达路径 | 检查 Storage 页与库存区优先级 |
| 搬到旁边又放下 | 目标格/交互格被占，或 `CanStore` 在途中变了 | 清空周围、留出交互格 |
| 不按最近仓库送 | `FindWarehouse` 取 lister 顺序第一个 | 调整仓库过滤/优先级，或减少候选库 |
| 断电后还能入库 | 设计如此，电力只用于温控 | 正常现象 |
| 堆数对不上 | 按「堆」算容量，单堆件数受 T2/T3 影响 | 看件数与库内倍率 |
