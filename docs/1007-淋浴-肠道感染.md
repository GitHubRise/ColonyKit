## 简介

脏水/长期污染会让小人生病：`GiveNastyGutBug` 不再空实现，会添加 `CK_GutBug` Hediff，造成呕吐、频繁上厕所，约一天恢复，可治疗。

## 描述

- 触发链：
  1. 脏水通过 `SanitationUtil.ContaminationCheckWater` 标记 `Need_Hygiene.Contaminated`；
  2. 污染期间 `Need_Hygiene.NeedInterval` 每 150 tick 累加 `ticksAtZero`；
  3. 超过 50000 tick 后，按 MTB 判定；且 `CK_BadHygiene` 必须可见；
  4. 调用 `SanitationUtil.GiveNastyGutBug(pawn, ContaminationLevel.Untreated)`。
- `GiveNastyGutBug` 检查：
  - `contaminationChanceMultiplier > 0`（设置页 0% 可关闭）；
  - 没有重复 `CK_GutBug`；
  - `CK_GutBug` Def 存在；
  - 添加 Hediff 并发送负面消息（仅对需要通知的 Pawn）。
- `CK_GutBug` 属性：
  - 初始 severity 1，`HediffCompProperties_SeverityPerDay -1`，约 1 天自愈；
  - `tendable`，治疗可加速恢复（`severityPerDayTended -0.5`）；
  - 阶段 0：呕吐 MTB 1.5 天；阶段 1（severity ≥0.5）：呕吐 MTB 0.75 天；
  - `CK_BladderRateMultiplier +0.25/+0.75`，更快需要上厕所；
  - `makesSickThought`，带生病念头。
- 当前是一种通用肠道感染，不是 DBH 的 `Diarrhea`/`Dysentery`/`Cholera` 三种分支。

## 所含功能

- 脏水/长期污染致病。
- 呕吐与膀胱加速。
- 约一天自愈、可治疗。
- 0% 污染设置可关闭。

## 如何使用

1. 让小人喝脏水/用脏水洗澡，或长期处于污染状态。
2. 在「健康」页看 `肠道感染`；严重时会呕吐、频繁上厕所。
3. 医生治疗可加速恢复；约一天自行痊愈。
4. 不想生病：卫生设置页把「脏水污染概率」设为 0%。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 一直不生病 | 污染时间不够/`CK_BadHygiene` 不可见/设置 0% | 等更久、保持脏污、检查设置 |
| 生病了没消息 | `PawnUtility.ShouldSendNotificationAbout` 为 false | 看健康页即可 |
| 不会吐 | 处于阶段 0 且 MTB 未命中 | 等 MTB；阶段 1 更频繁 |
| 想得 DBH 的痢疾/霍乱 | 当前只有通用 `CK_GutBug` | 需后续拆分三种疾病 |
