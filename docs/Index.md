## 状态与维护

- 每个功能的「函数或功能完成情况」与代码同步；标 🧩 的功能说明代码已编译通过，但最后的 UI 点击/绘制没有实机复测。
- 改行为时同一次提交更新对应文档；新增页面/控件/补丁时补「函数清单」与「涉及文件」。
- 文档里的路径相对 `sources/mod-template/`；行号不写死，按函数名搜索。
- 架构与设计理由见 [ARCHITECTURE.md](ARCHITECTURE.md)；能力矩阵见 [CAPABILITIES.md](CAPABILITIES.md)。
