## 推荐阅读顺序

1. [框架内核.md](框架内核.md) —— 先理解模块如何注册、什么时候能读 Def。
2. [设置系统.md](设置系统.md) —— 每个模块的开关和配置落在哪里。
3. [水网服务.md](水网服务.md) —— 淋浴、农业共用的底层服务。
4. 按交付节奏读 [淋浴模块.md](淋浴模块.md) → [立体库模块.md](立体库模块.md) → [农业模块.md](农业模块.md) → [蓝图模块.md](蓝图模块.md) → [智能机器人模块.md](智能机器人模块.md) → [6007-机器人-保姆机器人.md](6007-机器人-保姆机器人.md)。
5. [本地化.md](本地化.md)、[构建与发布.md](构建与发布.md) 贯穿始终。
6. 出问题时先看 [调查指南.md](调查指南.md)；选型类问题看 [decisions/Index.md](decisions/Index.md)。

## 状态与维护

- 每个功能的**进度源**是 [README 第 5 节](../README.md#5-任务清单) 的任务清单（M0–M8）；本文档只解释「怎么用、怎么接、函数在哪」。
- 完成一项任务时，同时更新对应文档的「函数或功能完成情况」与索引状态，避免文档领先代码。
- 文档里的代码路径以 `sources/ColonyKit/` 为根；标「规划」的路径在 M0 之后才存在。
- 每个功能文档末尾有「排查入口」页脚，统一指向 [调查指南](调查指南.md) 与 README 任务清单。
- 稳定标识（模块 Id、日志 tag、`defName`、`Scribe` key、Harmony Id）见 [调查指南 §3](调查指南.md#3-稳定标识表)；发布后不改。
- 模板中已经验证过的通用能力（多页签设置、控件库、科技树、构建脚本）见 [mod-template/docs](../../mod-template/docs/ARCHITECTURE.md)；ColonyKit 不重复造。
- 文档自身 UTF-8；XML / C# 片段按仓库约定用 TAB 缩进。
