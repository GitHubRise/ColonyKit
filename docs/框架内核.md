## 简介

ColonyKit 的内核只做四件事：**注册模块、分发生命周期、持有全局状态、统一日志**。六个业务模块（淋浴/立体库/农业/蓝图/机器人/本地化）都只依赖 `Core/`，`Core/` 不反向引用任何模块。

内核目标是把「加载顺序」和「模块隔离」这两件容易写错的事收敛到一处：新增第七个模块时，只加一个 `Modules/<Name>/` 目录并在 `Bootstrap` 注册，不改其他模块。

## 描述

- `IColonyModule` 是模块契约：`Id`、`DisplayName`、`InitOrder`、`OnDefsLoaded()`、`OnGameLoaded(Game)`。
- `ModuleRegistry` 保存有序模块列表；`Register` 按 `InitOrder` 排序；单个模块抛异常只记 `Error`，继续初始化其他模块。
- `ColonyKitMod : Mod` 只负责设置入口和单例，**构造函数里不碰 `DefDatabase`/`DefOf`**（此时 XML 还没解析）。
- `Bootstrap` 带 `[StaticConstructorOnStartup]`：Def 就绪后执行一次 `PatchAll`、注册模块、调用 `OnDefsLoaded()`。
- `ColonyKitGameComponent` 每存档一份：读档/新游戏后调用各模块的 `OnGameLoaded()`，并持有蓝图库等全局状态。
- `ModLog` 统一 `[ColonyKit][<Module>]` 前缀；模块不直接调 `Verse.Log`。
- 模块开关是**软停用**（README §3.4）：Def 仍然加载，只是补丁/Gizmo/Job/设置分节不生效；不承诺运行时卸载内容。

## 绘制调用逻辑图

```text
Assembly.LoadFrom(ColonyKit.dll)
        │
        ▼
ColonyKitMod 构造函数 ── 只读设置，不碰 DefDatabase / DefOf
        │
        ▼
Defs XML 解析 ── Patch 应用 ── Def 反序列化 ── DefOf 绑定
        │
        ▼
Bootstrap [StaticConstructorOnStartup]
        ├─ new Harmony("local.colonykit").PatchAll(...)
        ├─ ModuleRegistry.Register(new HygieneModule())  … 六个模块
        └─ foreach module: module.OnDefsLoaded()   // 可安全读 Def
        │
        ▼
新游戏 / 读档
        ├─ ColonyKitGameComponent 构造 / ExposeData
        └─ foreach module: module.OnGameLoaded(Current.Game)
        │
        ▼
每 tick
        └─ ModuleRegistry.Tick() → 仅做轻量判断，重活走各自计时器
```

## 函数清单

> 规划签名；M0 落地时以实际代码为准。

| 类型 / 函数 | 签名（规划） | 作用 |
|---|---|---|
| `IColonyModule.Id` | `string Id { get; }` | 稳定标识，用于设置分节、日志、开关 |
| `IColonyModule.DisplayName` | `string DisplayName { get; }` | 设置页/日志显示名 |
| `IColonyModule.InitOrder` | `int InitOrder { get; }` | 小者先初始化 |
| `IColonyModule.OnDefsLoaded` | `void OnDefsLoaded()` | Def 就绪后初始化（DefOf、补丁数据） |
| `IColonyModule.OnGameLoaded` | `void OnGameLoaded(Game game)` | 读档/新游戏后注册地图组件、恢复状态 |
| `ModuleRegistry.Register` | `void Register(IColonyModule module)` | 注册并按 `InitOrder` 排序 |
| `ModuleRegistry.InitAll` | `void InitAll()` | 依次调用 `OnDefsLoaded`，单模块异常隔离 |
| `ModuleRegistry.NotifyGameLoaded` | `void NotifyGameLoaded(Game game)` | 分发 `OnGameLoaded` |
| `ModuleRegistry.Tick` | `void Tick()` | 内核级轻量 tick；模块重活自理 |
| `ColonyKitMod.Settings` | `static ColonyKitSettings Settings { get; }` | 全局设置入口 |
| `ColonyKitGameComponent` | `ColonyKitGameComponent(Game game)` | 每存档组件，反射自动实例化 |
| `ModLog.Message/Warning/Error` | `static void (string module, string message)` | 统一前缀日志 |
| `CKDefOf` | `[DefOf] static class` | 共享 Def 引用（水网/核心） |

## 所含功能

- 模块注册、排序、初始化失败隔离；
- Def 就绪后的统一初始化点（`OnDefsLoaded`）；
- 读档/新游戏后的统一入口（`OnGameLoaded`）；
- 每存档全局状态容器（`ColonyKitGameComponent`）；
- 统一日志前缀，按模块过滤；
- 软停用语义的落点（模块开关由设置与注册表共同判断）。
