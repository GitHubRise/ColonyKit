## 简介

`CK_VerticalWarehouse` 是一台 **2×2** 的内部仓库建筑：物品存在建筑内部，不占地图格；容量按「堆」计，默认 **12**，可在设置页调到 1–200。

## 描述

### 建造数值（`Defs/Storage/CK_VerticalWarehouse.xml`）

| 项 | 值 |
|---|---|
| 科技前置 | **二级立体仓库技术** `CK_StorageTier2` |
| 建造分类 | Furniture（家具） |
| 占地 / 旋转 | 2×2 / 不可旋转 |
| 成本 | 150 钢 + 8 零部件 |
| 生命 / 质量 / 工作量 | 400 / 60 / 3000 |
| 美观 / 可燃性 | -10 / 0 |
| 电力 | `CompPowerTrader`，250W |
| 温控 | `CompProperties_TempControl`，`energyPerSecond=-21`（制冷），默认目标 4°C |
| 检视页 | `ITab_VerticalWarehouse` + 原版 `ITab_Storage` |

### 容量与堆叠

- 容量默认 **12 堆**，设置页范围 **1–200**；`Building_VerticalWarehouse.MaxStacks` 每次读取设置，所以对已建/新建仓库都立即生效。
- 调低容量不会丢物品；已有堆数超过新上限时，`CanStore` 不再接收新货。
- 每堆件数上限 = 当前全局 `ThingDef.stackLimit` × `WarehouseThingOwner.EffectiveMultiplier`：
  - 未完成二级：×1；
  - 二级：×3；
  - 三级：×2，合计 ×6；
  - 模块关闭或 Stack XXL 共存：×1。
- 只有 `StorageStackRules.CanMultiply` 允许的物品参与放大；武器/衣物/尸体/最小化建筑等不参与。
- 旧存档默认容量 24 会在 `StorageSettings.ExposeData` 的 `capacityVersion < 1` 迁移中改成 12。

### 研究链

| 研究 | 费用 | 前置 | 效果 |
|---|---:|---|---|
| `CK_StorageTier1` 一级立体仓库技术 | 800 | Electricity | 全局可堆叠物品固定 ×10；设置页倍率滑条隐藏 |
| `CK_StorageTier2` 二级立体仓库技术 | 1600 | 一级 | 解锁立体库；库内每堆 ×3；温控强制 4°C |
| `CK_StorageTier3` 三级立体仓库技术 | 2400 | 二级 | 库内再 ×2（合计 ×6）；温控目标开放 -20～30°C；解锁履带 Def（但建造菜单未挂） |

### 电力与温控

- 250W 只用于温控；**库存存取不依赖电力**。
- 温控每 `TickRare`（250 tick）执行一次；断电时只把 `compTempControl.operatingAtHighPower` 置 false，并停止制冷。
- 目标温度：未完成三级时每 tick 强制 4°C；完成三级后限制在 **-20～30°C**（Def 的 -50/50 会被代码覆盖）。
- 只制冷：`energyPerSecond=-21`，目标温度高于室温时 `ControlTemperatureTempChange` 返回 0，不会加热。
- 仅对**封闭且屋顶达标**的室内房间生效；露天/漏顶房间不制冷。`FindRoom` 先取建筑自身房间，取不到再扫 8 邻格，选最大且非室外的房间。
- 建筑圆环下方显示实时温度（`DrawGUIOverlay`）：常规/近景常驻，拉远后仅在选中时显示；≤0°C 蓝、≥25°C 橙、其余冰白。

### 拆除

- `Destroy` 前调用 `WithdrawAll`，按全局 `stackLimit` 分块把库存放到建筑旁。
- 若物品无法放到旁边，`TryWithdraw` 会把物品强制放回容器并返回 false，`WithdrawAll` 随即停止；随后 `base.Destroy` 可能导致剩余库存丢失。拆前建议先「取出全部」。

```text
研究 CK_StorageTier2

      ├─ CompTempControl（energy=-21，默认 4°C）
      ├─ WarehouseThingOwner（默认 12 堆，设置页 1–200）
      └─ IStoreSettingsParent → 原版 ITab_Storage（过滤/优先级）

  └─ TickRare
        ├─ 无电 → 停温控
        ├─ FindRoom → 无室内房间 → 停温控
        ├─ 目标温度（未 T3 强制 4；T3 后 clamp -20..30）
        └─ room.Temperature += ControlTemperatureTempChange(...)
```

## 所含功能

- 2×2 内部仓库、二级研究解锁、固定成本。
- 12 堆默认容量，设置页 1–200 即时生效。
- 250W 制冷，默认 4°C；三级开放 -20～30°C。
- 断电只停温控，库存存取不受影响。
- 拆除前尝试取出库存。

## 如何使用

1. 完成一级 → 二级研究。
2. 在 **Furniture** 建 2×2 立体库，接电。
3. 打开 **Storage** 页设过滤/优先级；默认已是 Normal。
4. 选中建筑看库存；温度 Gizmo 调目标温度。
5. 三级研究后目标温度可调到 -20～30°C。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 建不了 | 没完成二级研究 | 先研究 `CK_StorageTier2` |
| 不制冷 | 没电、露天/漏顶、房间未封闭、温度已低于目标 | 接电/补屋顶/围墙；它只制冷 |
| 目标温度设了 30 也不暖 | 只有制冷能量，不会加热 | 用加热器或把目标调低 |
| 容量显示 12 不是 24 | 0.0.2 默认已改为 12 | 在设置页调大 |
| 拆了库东西少了 | 取出时找不到落点，剩余库存随建筑消失 | 拆前先「取出全部」并清空周围 |
