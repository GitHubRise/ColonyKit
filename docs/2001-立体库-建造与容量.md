## 简介

`CK_VerticalWarehouse` 是一台 2×2 的高容量仓库建筑：物品存在建筑内部，不占地图格；容量按「堆」计，默认 24，可在设置页调整。

## 描述

- 建筑 2×2；电力 250W 仅用于温控，断电仍可入库/出库，库存不丢。
- 容量：默认 12 堆，可在 **Mod 设置 → 立体库 → 立体库容量** 调到 1–200；对已建和新建仓库立即生效。
- T1/T2/T3 研究提升堆叠倍率（×10 / ×30 / ×60）；容量研究升级尚未实现，当前由设置页控制。
- 内部用 `ThingOwner` 存物品，不占地图格。
- 容量单位是「堆」；Stack XXL 会改变单堆件数，UI 同时显示件数。
- 拆除/被毁的物品掉落规则见 2005。

- 室内/室外与拆除规则（待定）。

## 如何使用

**前提**：研究「立体仓储」；有电、有 2×2 空地。

1. 建 `CK_VerticalWarehouse`，接电。
2. 打开建筑面板设过滤/优先级。
3. 搬运工开始入库；在 ITab 看库存/容量。
4. 研究 T2/T3 后用材料升级，库存保留。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 建了不收货 | 没电、过滤不允许、已满、被禁用 | 看 ITab 状态与 2002 |
| 容量比预期少 | 按「堆」算 + Stack XXL | 看件数，或调过滤 |
| 升级没反应 | 材料/研究没满足 | 看升级按钮的拒绝原因 |
