## 模块一句话

给殖民者加一条**卫生需求**，用**水网 + 淋浴器 + 热水**恢复；脏了会掉心情，洗冷水也会掉心情。

## 快速开始（草案）

1. 研究「卫生设施」。
2. 建水网：水泵 → 管道 → 水箱（见 M1 水网；没有水就没有淋浴）。
3. 建 `CK_Shower`，旁边接管道；需要热水就加 `CK_WaterHeater` 并接电。
4. 殖民者卫生值低于阈值时会自己去洗；也可以选中殖民者用 Gizmo 手动安排。
5. 打开卫生需求条确认恢复；断水/断电时看 Alert。

## 建筑与研究

| 内容 | 说明 |
|---|---|
| `CK_Shower` | 1×1 淋浴器，消耗水；有热水时洗热水澡 |
| `CK_WaterHeater` | 给管网加热水，耗电；没有它或断电就是冷水澡 |
| 研究「卫生设施」 | 解锁淋浴器与热水器 |
| 水网建筑 | 见 M1；淋浴模块不自带水泵/管道 |

## 依赖与兼容

- 依赖 `Core/Water` 水网（M1）。
- 与 DBH 的卫生/淋浴系统重叠：默认策略是检测到 DBH 时**软停用本模块的卫生需求**，只保留清洁/心情效果；具体三选一见 1004。
- 机器人不需要卫生（M6 会从需求里排除）。

## 已知限制 / 待确认

- 需求阈值、每次洗澡耗水、洗澡时长还没定稿，落地后回填 `docs/balance.md`（待建）。
- 洗澡是否脱衣/穿衣、是否影响 apparel 耐久，首版不做。
- 厕所/排泄系统明确不做。
