## 模块一句话

给能洗澡的人形加一条**卫生需求**，用**水网 + 淋浴器/浴缸 + 热水**恢复；脏了、洗冷水、热水用完、如厕被看到都会影响心情，断水/堵塞/排队有 Alert。

## 快速开始

1. 研究「卫生设施」与「高级淋浴」。
2. 建水网：水井 → 水泵 → 水管 → 水箱 → 洁具；水泵需要同网水井。
3. 建 `CK_Shower`（1×1，可独立放）或 `CK_ShowerPower`（2×2，必须通电）。
4. 需要热水时建 `CK_DbhWaterHeater`（自带 100 容量热水罐）；容量不够再建 `CK_HotWaterTank`。
5. 殖民者卫生值低会自动洗澡，也可选中殖民者点「去洗澡」；卫生值低/膀胱急会自动找厕所。
6. 在「卫生」设置页调需求速率、耗水、热水用量、污染概率、DBH 策略与需求豁免。

## 依赖与兼容

- 水网、热水罐与洁具都依赖本模块的 `CompPipe`/`PlumbingNet`；不依赖 DBH。
- 与 DBH 同开：默认 `SoftOff`（检测到 DBH 时停用本模块需求/自动工作）；可在卫生设置页改为「始终并存」或「完全禁用」。
- 机器人、动物不会获得卫生/膀胱需求；具体豁免见 1005。
- 首版不做衣物清洁、地面污渍自动清理、真实排队 Job、独立腹泻/痢疾/霍乱三种疾病。

## 已知限制

- 「淋浴器被长期占用/排队」只做 Alert，不做真正的等待队列；`JobGiver_HaveWash` 找不到空位就改找浴缸或返回 null。
- 肠道感染目前是一种通用 `CK_GutBug`，不是 DBH 的三种疾病分支。
- 马桶占用检测默认关闭（`OccupancyCheck` 未开放开关），洗手池热水消耗没有独立水温念头。
- 供热能力/水温公式已按 DBH 实现，但锅炉功率档位与恒温低功耗循环仍是简化版。
