## 简介

淋浴模块是 ColonyKit 的第一个可玩模块：给能洗澡的人形加一条 `Need_Hygiene`，变脏后去 `CK_Shower` 洗澡，消耗水网的水（可选热水），恢复需求并清掉携带污渍。

它是水网服务的第一个消费者，也是需求注入、Job、念头、Alert 的样板；后续模块按同样结构接入。

## 描述

- `Need_Hygiene`（0–1）：缓慢下降；低于阈值触发「肮脏」念头；洗澡恢复。
- 需求注入：Postfix `Pawn_NeedsTracker.ShouldHaveNeed`，只给能洗澡的人形加，**只加一次**，不重复。
- `CK_Shower`（1×1）：需要水网供水；可选加热器提供热水；断电/断水时停机并给出原因。
- `JobDriver_TakeShower`：预约淋浴间 → 到场 → 脱战 → 洗澡计时 → 消耗水 → 恢复需求、清 `pawn.filth.carriedFilth`。
- 热水：`CK_WaterHeater` 给管网加热；没有热水时洗冷水澡，给心情 debuff。
- 念头：洁净、肮脏、冷水澡、今天洗过澡；阈值与持续时间进 `docs/balance.md`。
- Alert：断水、断电、淋浴被占用。
- DBH 共存：检测 `dubwise.dubsbadhygiene`；默认「独立实现 + 检测到 DBH 时软停用本模块需求」，避免双重 hygiene。

## 绘制调用逻辑图

```text
Need_Hygiene 下降
      │  低于阈值
      ▼
Thought_ Dirty（心情 debuff）+ Alert/提示
      │  玩家右键 / 自动 Job
      ▼
JobDriver_TakeShower
      ├─ 预约 CK_Shower（Reservation）
      ├─ 到场、脱战
      ├─ 检查水网：TryConsume(需求 L) + 热水?
      │        ├─ 无水 → 停机，给出断水原因
      │        └─ 有冷水 → 洗澡 + 冷水澡 debuff
      └─ 完成：Need_Hygiene 恢复，carriedFilth.Clear()
      │
      ▼
Thought_Clean / Thought_ShoweredToday
```
