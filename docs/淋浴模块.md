# 淋浴模块（Hygiene）

> 状态：✅ 已实现（0.0.2；需求/水网/热水/设置/Alert/清理/疾病） · 适用：ColonyKit 0.0.2 · 最后更新：2026-10-25
> 本页是开发向总览；玩家功能说明按「一个功能一个 md」拆在 1001–1009。

## 1. 模块边界

| 层 | 内容 |
|---|---|
| 需求 | `Need_Hygiene`、`Need_Bladder`；需求注入、存档、豁免 |
| 水网 | `CompPipe` / `PlumbingNet`、管道、水箱、水泵、水井、污水 |
| 热水 | `CompWaterHeater`、`CompHeatStore`、`CK_HotWaterTank`、`HeatingCap` |
| 洁具 | 淋浴器（简易/电热）、浴缸、洗手池、马桶 |
| AI | ThinkTree 补丁、`JobGiver_HaveWash` / `JobGiver_UseToilet`、对应 JobDriver |
| 心情 | 洁净/肮脏、热水/冷水、今天洗过、浴室、洗澡/如厕隐私、失禁 |
| UI/提示 | 需求条、Gizmo、卫生设置页、Alert |
| 附加 | 淋浴后清理、肠道感染、堵塞/疏通、DBH 三策略 |

## 2. 运行时链路

```text
Need_Hygiene / Need_Bladder
      ├─ JobGiver_HaveWash → JobDriver_TakeShower → Building_Shower/Bath
      └─ JobGiver_UseToilet → JobDriver_UseToilet → Building_Toilet (+ Basin)

洁具 → CompPipe → PlumbingNet
      ├─ 冷水：PullWater
      ├─ 热水：CompHeatStore.HeaterTemp → PullHotWater
      └─ 污水：PushSewage

完成 → 念头 / 污染检查 / 堵塞检查 / ShowerCleanup / Alert
```

## 3. 模块开关与 DBH

- `HygieneSettings.ShouldRunHygiene`：模块开关 + `SoftOff/AlwaysOn/Disabled`。
- `HygieneSettings.ShouldInject`：人形、非机械体、智力、囚犯/访客/非人形、种族/体型/Hediff 豁免。
- 开关/策略变化调用 `HygieneModule.ResetRuntimeState` → `RefreshAllPawns`，覆盖地图、商队、远行队。
- 已建洁具不删除/不隐藏；停用只影响需求、Job、Gizmo。

## 6. 已知限制

- 淋浴等待 Job 已有，但不是严格 FIFO；多个等待者会竞争同一台淋浴器。
- 肠道感染是通用 `CK_GutBug`，不是 DBH 的三种疾病。
- 洗手池会扣热水但没有独立水温念头。
- 锅炉有低/标准/高三档 + 恒温待机，但不是 DBH 的完整八档曲线。
- 房间占用限制需手动开启；衣物清洁未做。
