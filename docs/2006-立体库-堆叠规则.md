## 简介

立体库的堆叠分两层：

1. **全局层（一级研究）**：把普通可堆叠物品的 `ThingDef.stackLimit` 固定放大 ×10，让所有架子、储存区和地面堆都能堆更多。这一层参照 Stack XXL 的全局 `stackLimit` 做法。
2. **设备层（二级/三级研究）**：只放大**立体库建筑内部**每堆的件数（二级 ×3、三级再 ×2，合计 ×6），不修改 `ThingDef.stackLimit`，因此不会影响库外的任何存储。

## 描述

- 一级研究前：全局倍率取设置页的「堆叠倍率」（1–20×，默认 10×）。
- 完成一级后：全局固定 **×10**，设置页的倍率滑条不再生效（滑条会隐藏并显示提示）。
- 二级完成：立体库内部每堆上限 = 当前全局上限 × **3**；三级完成：× **6**。
- 全局白名单（`StorageStackRules.CanMultiply`）：
  - 包含：原料、食物、药品、成瘾品、纺织品、石块、零部件、普通制成品，以及木头/钢铁等 `IsStuff` 材料。
  - 排除：真正的武器/衣物/科技义体、尸体、掉落即毁、未完成品、最小化建筑。
  - 注意：RimWorld 1.6 原版把木头等材料标了 `isTechHediff=true`（可当假肢/武器），所以不能用 `IsWeapon`/`isTechHediff` 直接排除；只在「不是 `IsStuff`」时排除。
- 只改运行时 `stackLimit`，不写 Def 文件；关闭模块或检测到 Stack XXL 时恢复原版。
- 库内堆可以超过全局上限（例如木头全局 750、库内 4500）；取回时按全局 `stackLimit` 分块，避免超限堆被地图放置逻辑截断。
- 库内倍率由 `WarehouseThingOwner.EffectiveMultiplier` 决定：模块关闭或 Stack XXL 共存时强制为 1；否则按二级/三级研究计算。
- 研究完成时 `Patch_ResearchFinished` 立即重新应用全局上限，不需要重进游戏。

## 绘制调用逻辑图

```text
Bootstrap
  └─ ModuleRegistry.DiscoverFromAssembly
        └─ StorageModule.OnDefsLoaded
              ├─ ColonyKitMod.Settings.GetModuleSettings<StorageSettings>()
              └─ StorageStackLimitManager.Apply(settings)
                    ├─ 检测 Stack XXL → 有则 Restore 并让位
                    ├─ CaptureBaseLimits()   // 首次缓存原版 stackLimit
                    ├─ 一级完成 ? ×10 : 设置倍率
                    └─ foreach eligible ThingDef
                          def.stackLimit = clamp(base * multiplier)

立体库建筑
  └─ WarehouseThingOwner
        ├─ StackLimitFor(def) = def.stackLimit × (二级 3 × 三级 2)
        ├─ TryAdd：按库内上限合并（可超过全局 stackLimit）
        └─ 取出：按全局 stackLimit 分块
```

## 所含功能

- 一级全局堆叠 ×10。
- 二/三级只放大立体库内部每堆。
- 安全恢复原版上限。
- Stack XXL 共存保护。
- 设置页即时应用。
- 库内倍率显示与超限堆分块取出。

## 如何使用

1. 打开 **选项 → Mod 设置 → 殖民地套件 → 立体库**。
2. 勾选「启用堆叠增强」。
3. 一级研究前可拖动「堆叠倍率」；一级后全局固定 ×10。
4. 完成二级/三级后，库内每堆上限自动变为全局的 3×/6×。
5. 如果装了 Stack XXL，本页会提示让位；此时请只保留一个堆叠 Mod。
6. 想恢复原版：取消勾选，或把倍率调到 1×（仅一级前）。

## 常见问题

**Q：为什么普通架子也能堆 750？**
A：一级的全局层就是所有存储共用的；二级/三级不会再把全局上限抬高。

**Q：为什么木头/钢铁以前不参与堆叠？**
A：1.6 原版给木头等材料标了 `isTechHediff=true`，旧判定把它当科技义体排除了；现在只排除非 `IsStuff` 的真正武器/义体。

**Q：库内 4500 的堆怎么取出？**
A：每次按全局上限（如 750）取一块，可多次点「取出」；「取出全部」会循环取到空。

**Q：和 Stack XXL 一起开会怎样？**
A：检测到 Stack XXL 后本模块不修改上限，并只警告一次；库内倍率也按 1 处理。

**Q：调整倍率后已有堆会立刻变多吗？**
A：不会自动把已有堆合并；新生成/搬运合并时按新上限。已经超过新上限的堆不会被截断。

**Q：会影响存档吗？**
A：只改运行时 `ThingDef.stackLimit`，不写 Def 文件；存档里物品数量不变。关闭后恢复原版上限。
