## 简介

在不改原版存储建筑的前提下，把普通可堆叠物品的 `ThingDef.stackLimit` 按倍率放大，让一个格子能放更多同类物品。它是立体库模块的第一层：先解决「堆叠上限」，再叠加仓库核心、入库/出库和传送带。

## 描述

- 默认倍率 **10×**，可在设置页调到 **1–20×**；`1×` 等于原版。
- 只在模块启用且没有安装 Stack XXL 时生效；检测到 Stack XXL 会自动让位，避免倍率叠加。
- 只处理「安全可放大」的物品：
  - 包含：原料、食物、药品、成瘾品、纺织品、石块、零部件、普通制成品等。
  - 排除：武器、衣物、尸体、掉落即毁、未完成品、最小化建筑、科技义体（这些以后由仓库按重量合并）。
- 启动时缓存每个 `ThingDef` 的原始 `stackLimit`；关闭开关或模块时恢复原值，不会把倍率写进 Def 文件。
- 设置页改动立即重算；模块开关的启用/禁用建议重启后完全生效。
- 只改堆叠上限，不改物品重量、市场价值、腐烂速度或存储建筑逻辑。

## 绘制调用逻辑图

```text
Bootstrap
  └─ ModuleRegistry.DiscoverFromAssembly
        └─ StorageModule.OnDefsLoaded
              ├─ ColonyKitMod.Settings.GetModuleSettings<StorageSettings>()
              └─ StorageStackLimitManager.Apply(settings)
                    ├─ 检测 Stack XXL → 有则 Restore 并让位
                    ├─ CaptureBaseLimits()   // 首次缓存原版 stackLimit
                    └─ foreach eligible ThingDef
                          def.stackLimit = clamp(base * multiplier)

设置窗口 → 立体库页
  ├─ 开关/倍率变化 → StorageStackLimitManager.Apply / Restore
  └─ 重新应用 → Apply / Restore
```

## 如何使用

1. 打开 **选项 → Mod 设置 → 殖民地套件 → 立体库**。
2. 勾选「启用堆叠增强」。
3. 拖动「堆叠倍率」到需要的倍数（默认 10×）。
4. 回到游戏，查看物品堆叠数量；新生成的堆会按新上限合并。
5. 如果装了 Stack XXL，本页会提示让位；此时请只保留一个堆叠 Mod。
6. 想恢复原版：取消勾选，或把倍率调到 1×。

## 常见问题

**Q：为什么武器/衣物没有变成 100 堆？**  
A：这些物品按重量/品质管理，直接拉高 `stackLimit` 会造成生成/合并截断；它们留给仓库按重量合并。当前版本不处理。

**Q：和 Stack XXL 一起开会怎样？**  
A：检测到 Stack XXL 后本模块不修改上限，并只警告一次；设置页会显示提示。请不要同时开两个堆叠倍率。

**Q：调整倍率后已有堆会立刻变多吗？**  
A：不会自动把已有堆合并；新生成/搬运合并时按新上限。已经超过新上限的堆不会被截断。

**Q：会影响存档吗？**  
A：只改运行时 `ThingDef.stackLimit`，不写 Def 文件；存档里物品数量不变。关闭后恢复原版上限。

**Q：为什么日志里是 163 个 Def？**  
A：只统计通过白名单的普通可堆叠物品；具体数量随 Mod 列表变化。
