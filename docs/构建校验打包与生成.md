## 简介

模板提供四个 PowerShell 脚本，覆盖「写完代码 → 验证 → 发布 → 复制成新 Mod」：

- `build.ps1`：离线 restore + build（0 错误 0 警告门槛），可选 `-Deploy`；
- `verify.ps1`：packageId、XML、补丁 xpath、程序集静态检查；
- `package.ps1`：verify + build + 只含运行期目录的 zip；
- `new-mod.ps1`：从模板改名生成新工程并首次编译。

## 描述

- 构建使用工作区 `.tools\dotnet` 与 `.tools\nuget`，不依赖全局 SDK/网络；引用 `Krafs.Rimworld.Ref 1.6.4871` + `Lib.Harmony 2.4.3`。
- `build.ps1 -Deploy` 先检查 `RimWorldWin64` 是否在运行（DLL 会被锁），再 robocopy `About/Assemblies/Defs/Patches/Languages/Textures/Sounds`，最后校验 DLL SHA256。
- `verify.ps1` 用「合并本地 Defs」模拟补丁 xpath；指向原版/其他 Mod 的 xpath 只警告，不算失败。
- `package.ps1` 断言 `About/About.xml` 在第一层、没有 `Source/obj/bin`，并手写 zip entry 名保证分隔符是 `/`。
- `new-mod.ps1` 替换三类占位符（`ModTemplate` / `local.modtemplate` / `Mod Template`），重命名目录与文件，再编译一次。
- 所有 `.ps1` 带 UTF-8 BOM（PowerShell 5.1 把无 BOM 脚本当 ANSI，中文会乱码）。

## 绘制调用逻辑图

```text
.\build.ps1 [-Clean] [-Deploy]
  ├─ [Clean] 删 Source\obj / Source\bin / Assemblies
  ├─ restore：缺 obj\project.assets.json 时 --packages .tools\nuget
  ├─ dotnet build -c Release --no-restore
  ├─ 统计 ": error " / ": warning " → 非 0 则 build-error.log + throw
  └─ [Deploy]
        ├─ 检查 RimWorldWin64 进程
        ├─ robocopy 运行期目录 → Mods\ModTemplate
        └─ Get-FileHash SHA256 校验

.\verify.ps1
  ├─ About.xml：packageId 正则 / supportedVersions 含 1.6
  ├─ Defs：根 <Defs>，XML 可解析，合并后供 xpath 检查
  ├─ Patches：根 <Patch>，子节点 <Operation>，xpath 命中本地 Defs
  └─ Assemblies：存在且只有 .dll/.pdb

.\package.ps1 [-SkipBuild] [-SkipVerify]
  ├─ verify → build
  ├─ 复制运行期目录到 TEMP staging
  ├─ 断言 About 在第一层 / 无 Source|obj|bin / Assemblies 无杂项
  └─ zip → dist\ModTemplate-<modVersion>.zip

.\new-mod.ps1 -Name MyMod -PackageId local.mymod -DisplayName "My Mod"
  ├─ 复制模板（排除 .git / Assemblies / dist）
  ├─ 替换占位符 + 重命名目录/文件
  └─ restore + build 验证
```

## 函数清单

| 脚本 / 命令 | 参数 | 作用 |
|---|---|---|
| `build.ps1` | `-Deploy` / `-Clean` / `-Configuration` / `-ModsPath` | 编译、清理、部署 |
| `verify.ps1` | 无 | 静态校验（退出码 0/1） |
| `package.ps1` | `-SkipBuild` / `-SkipVerify` | 校验 + 编译 + 打包 |
| `new-mod.ps1` | `-Name` / `-PackageId` / `-DisplayName` / `-Destination` | 生成新工程 |
| `dotnet build` | `Source\ModTemplate.csproj -c Release --no-restore` | 直接编译（调试用） |
| `Get-FileHash` | `-Algorithm SHA256` | 部署后 DLL 一致性校验 |
