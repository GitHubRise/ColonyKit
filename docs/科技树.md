## 简介

科技树是一套独立窗口，不改原版研究界面：按 `ResearchTabDef` 取 `ResearchProjectDef`，根据 `prerequisites` / `hiddenPrerequisites` 建边、分层、绘制节点和连线。点击节点会把该项目设为当前研究。

`TechTreeService` 提供前置条件的统一管理接口：查询、添加、删除、整体替换、状态查询和变化通知。

## 描述

- 建树：`TechTree.Build(tab, layoutMode)`；过滤该 tab 且未隐藏的项目；只连树内前置，跨 tab 前置留在 Tooltip。
- 两种布局：
  - `PrerequisiteTiers`（默认）：`tier = max(前置 tier) + 1`，同层按 `ResearchViewY` 排序；
  - `VanillaCoordinates`：直接用 `ResearchViewX * 190`、`ResearchViewY * 100`。
- 绘制：先画前置连线（前置已完成变绿），再画节点；已完成深绿、可研究土黄、锁定深灰；当前研究项目黄框；底部按 `ProgressPercent` 画进度条。
- 窗口：`TechTreeWindow` 提供 tab 下拉、布局切换、滚动；订阅 `TechTreeService.Changed`，前置变化后下一帧重建。
- 调试：带 `-modtemplate-techtree` 启动时，`DemoGameComponent.FinalizeInit` 自动打开窗口。
- 前置 API 直接改 `ResearchProjectDef.prerequisites`，因此原版研究树也会同步变化；修改不写存档。

最小用法：

```csharp
// 查询（默认包含 hiddenPrerequisites）
IReadOnlyList<ResearchProjectDef> pre = TechTreeService.GetPrerequisites(project);

// 增删改：自引用/重复/成环会被拒绝
TechTreeService.AddPrerequisite(project, prerequisite);
TechTreeService.AddPrerequisite(project, hiddenPrerequisite, hidden: true);
TechTreeService.RemovePrerequisite(project, prerequisite);
TechTreeService.SetPrerequisites(project, new[] { a, b });

// 构建视图
TechTree tree = TechTree.Build(ResearchTabDefOf.Main, TechTreeLayoutMode.PrerequisiteTiers);
// 打开窗口：Find.WindowStack.Add(new TechTreeWindow());
```

## 绘制调用逻辑图

```text
TechTreeWindow.PreOpen()
  └─ tab = 当前研究?.tab ?? ResearchTabDefOf.Main
  └─ Rebuild(): TechTree.Build(tab, layoutMode)
        ├─ CreateNodes：DefDatabase<ResearchProjectDef> 过滤 tab/隐藏
        ├─ LinkPrerequisites：prerequisites + hiddenPrerequisites
        └─ ComputeLayout：
              ├─ TierOf(node) = max(TierOf(prereq)) + 1（环→警告，按 0）
              ├─ 同层按 ResearchViewY 排序 → Row
              └─ Rect = Tier/Row 或原版坐标；Size = 包围盒

DoWindowContents()
  ├─ DrawToolbar：tab 菜单 / 布局切换 / 节点数
  └─ TechTreeView.Draw(canvas, tree, ref scroll, onClick)
        ├─ BeginScrollView
        ├─ DrawEdges：前置右缘 → 本节点左缘（Widgets.DrawLine）
        ├─ DrawNode：DrawBoxSolid → 状态色 → 黄框 → Label → 进度条 → Tooltip
        └─ ButtonInvisible → onClick(def) → Find.ResearchManager.SetCurrentProject
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `TechTree.Build` | `static TechTree Build(ResearchTabDef tab, TechTreeLayoutMode layoutMode)` | 建树 + 布局 |
| `TechTree.NodeFor` | `TechNode NodeFor(ResearchProjectDef def)` | 查节点 |
| `TechTree.Nodes` / `Size` | `IReadOnlyList<TechNode>` / `Vector2` | 节点与画布尺寸 |
| `TechTreeService.GetPrerequisites` | `static IReadOnlyList<ResearchProjectDef> GetPrerequisites(ResearchProjectDef, bool includeHidden = true)` | 查询前置 |
| `TechTreeService.AddPrerequisite` | `static bool AddPrerequisite(ResearchProjectDef, ResearchProjectDef, bool hidden = false)` | 添加（拒绝自引用/重复/成环） |
| `TechTreeService.RemovePrerequisite` | `static bool RemovePrerequisite(ResearchProjectDef, ResearchProjectDef, bool hidden = false)` | 删除 |
| `TechTreeService.SetPrerequisites` | `static bool SetPrerequisites(ResearchProjectDef, IEnumerable<ResearchProjectDef>, bool hidden = false)` | 整体替换（先校验） |
| `TechTreeService.GetAvailability` | `static TechAvailability GetAvailability(ResearchProjectDef)` | Finished / Available / Locked |
| `TechTreeService.Changed` | `static event Action` | 变化通知 |
| `TechTreeView.Draw` | `static void Draw(Rect, TechTree, ref Vector2, Action<ResearchProjectDef>)` | 画整棵树 |
| `TechTreeWindow` | `sealed class : Window` | tab/布局/滚动/点击 |
