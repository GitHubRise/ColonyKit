## 简介

卫生值、洗浴水温、今天是否洗过、浴室质量、洗澡/如厕是否被看到，通过 `ThoughtDef` / `ThoughtWorker` 影响殖民者心情。该页只管念头；设施不可用与排队提示见 [1008-淋浴-卫生Alert.md](1008-淋浴-卫生Alert.md)。

## 描述

- **洁净/肮脏**：`CK_HygieneDirty` 由 `ThoughtWorker_Hygiene` 按 `Need_Hygiene.CurCategory` 切换阶段，不是计时记忆。
  - `Filthy`（0）−6；`Grimy`（<0.1）−3；`Clean`（0.7–0.9）+3；`Squeaky`（≥0.9）+6。
- **热水澡**：`CK_ShowerHot` +3，持续 0.2 天，最多 1 层；淋浴完成且水温为热时由 `SanitationUtil.WaterTempCheck` 施加。
- **冷水澡**：`CK_ShowerCold` −3，持续 0.1 天，最多 1 层；冷水淋浴或冷水浴缸都会施加。
- **今天洗过澡**：`CK_ShoweredToday` +2，持续 1 天，最多 1 层；仅淋浴完成时施加。
- **洗澡隐私**：`CK_WashPrivacy` −3，持续 0.1 天，最多 6 层；同地图、玩家家、有视线、非恋人、非动物/机械体、异性看到洗澡时施加。
- **如厕隐私**：`CK_ToiletPrivacy` −3，持续 0.1 天，最多 4 层；囚犯/动物/野人/机械体不参与；非恋人、非动物/机械体、有视线即可能触发。`JobDriver_UseToilet` 在开始和结束各检查一次。
- **私人浴室/公共浴室**：`CK_PrivateBathroom` / `CK_PublicBathroom` 按房间 `Impressiveness` 分阶段；私人浴室优先由 `CK_PrivateBathroom` 房间角色或已连接的床判定，公共浴室在 `CK_PublicBathroom` 房间内判定。
- **失禁**：`CK_SoiledSelf` −8，持续 1 天，最多 3 层，由 `Need_Bladder` 的失禁逻辑施加。

## 绘制调用逻辑图

```text
Need_Hygiene.CurCategory
      ├─ Filthy/Grimy → CK_HygieneDirty 负阶段
      └─ Clean/Squeaky → CK_HygieneDirty 正阶段

淋浴完成
      ├─ 热水 → CK_ShowerHot + CK_ShoweredToday
      └─ 冷水 → CK_ShowerCold
      ├─ 浴室房间 → CK_PrivateBathroom / CK_PublicBathroom
      └─ 被看到 → CK_WashPrivacy

上厕所
      └─ 被看到 → CK_ToiletPrivacy
```

## 所含功能

- 卫生等级带来的持续心情变化。
- 热水澡、冷水澡、今天洗过澡的短期记忆。
- 私人/公共浴室评价。
- 洗澡与如厕被看到的隐私惩罚。
- 失禁心情。

## 如何使用

1. 选中殖民者，在「心情」页看 `CK_HygieneDirty` 阶段。
2. 洗澡后看是否出现「热水澡」「冷水澡」「今天洗过澡」。
3. 把淋浴器/马桶放进带门的浴室，或给洁具连接床铺，减少隐私惩罚。
4. 想让厕所算私人浴室：把洁具连接到殖民者的床，或把房间评价做高。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 洗澡后没有热水澡念头 | 淋浴器断电且热水罐温度不足 | 检查热水器/热水罐温度 |
| 一直有「没有热水」 | 热水罐温度耗尽或供热能力不足 | 加建热水罐/热水器，或降低热水用量 |
| 洗澡被看到 | 浴室无门/无墙、异性在视线内 | 建封闭浴室；恋人/同性不触发洗澡隐私 |
| 如厕被看到 | 马桶不在封闭房间，或有人有视线 | 建独立厕所/隔间；囚犯、动物不参与 |
