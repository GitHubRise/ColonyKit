ColonyKit · Robotics Tech Tree

机器人科技树 · 五级技术产物

5 种工厂/充电/维修方案全部追加，不互斥；按 T1→T5 作为五个技术阶段。每个阶段有独立的机器人工厂、机器人等级、维修能力和材料表；旧阶段保留可建造，方便低科技基地和旧存档。

追加原则：不删除旧方案。T1 工坊式 → T2 单元式 → T3 流水线 → T4 现场保障 → T5 全自动；研究逐级前置，建筑和机器人按阶段解锁。可在设置里开启“只显示最高级建筑”减少建造菜单。
旧存档兼容：现有 `CK_NannyBot` 研究映射为 T1；旧一体桩保留为 legacy，现有机器人按 Mk-I 处理，`homeStation` 迁移到 `homeCharger`。

交战规则

  • 只反击：被攻击，或敌人进入 2 格，才启动；不主动巡逻、不主动索敌。
  • 不追击：目标离开 9 格以上，或自身开始撤离，立即脱战。
  • 血量优先：耐久/生命低于 30%，或电量低于 10%，停火撤离。
  • 目标过滤：只打敌对 Pawn；不打友军、中立、建筑、动物（除非动物敌对）。
  • T5 远程限制：需要视线，不穿墙；冷却 2.5 秒；不打断救援/灭火的紧急判断。

RimWorld 实现映射

  • HediffDef + HediffCompProperties_VerbGiver：给 Mk-III+ 加 tools（近战）和 T5 的 verbs（远程）。
  • PawnKindDef.startingHediffs：Mk-III/IV/V 分别带 `CK_RobotDefense_ArcWelder` / `ShockBaton` / `ArcEmitter`。
  • JobGiver_NannyBotDefend：放在 ThinkTree 的 Flee 之前；只在被攻击/近敌时生成 `AttackMelee` 或 `UseVerbOnThing`。
  • CompNannyBot 记录 `lastAttackedTick`；selfDefenseMode 默认 Retaliate，可切 Off。
  • T5 弹丸 `CK_ArcBolt` 用 `Verb_Shoot`；射程 4.9，三连发，冷却 2.5 秒；只选敌对目标。
  • 护甲用 Hediff 的 statOffsets，不改基础 ThingDef；T4/T5 才加。

平衡与风险

  • T3 的 7 伤害只是“能还手”，打不过正规枪手；遇到强敌仍要撤。
  • T5 远程是后期能力，必须限制目标过滤与冷却，避免自动清图。
  • 需要测试：友军误伤、墙后目标、救援中开火、断电/低电、维修期间自卫是否关闭。
