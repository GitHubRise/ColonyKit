## 简介

`NotificationService` 把 `Messages.Message` / `Find.LetterStack.ReceiveLetter` 包成统一 API，并加两件事：**总开关**和**按 key 节流**。设置页新增「通知」页签，带三个测试按钮。

## 描述

- 总开关：`NotificationSettings.enabled`；关闭后所有发送方法直接返回。
- 节流：`ThrottledMessage(key, text, type, cooldownTicks)` 按 key 记录下一次允许的 tick；`cooldownTicks < 0` 用设置里的 `cooldownTicks`（默认 600）。
- `ResetThrottle(key)`：清单个/全部 key，便于事件结束后重新允许。
- 新游戏/读档：`DemoGameComponent.FinalizeInit` 会调 `ResetThrottle()`，避免上一局 tick 较大时压住新局的消息。
- 默认类型：消息用 `MessageTypeDefOf.NeutralEvent`，信件用 `LetterDefOf.NeutralEvent`。
- 空文本/空标签直接忽略，避免产生空消息。
- 设置页「通知」：
  - 行为：启用通知；
  - 节流：冷却滑块（60–6000 tick，60 步进）；
  - 测试：发送消息 / 发送信件 / 测试节流消息。
- 右键菜单「记录该殖民者」也走节流消息，演示业务侧用法。

## 绘制调用逻辑图

```text
业务代码
  ├─ NotificationService.Message(text, type)
  ├─ NotificationService.Letter(label, text, def)
  └─ NotificationService.ThrottledMessage(key, text)
        │
        ▼
  Enabled? ── false → return
        │
        ▼
  ThrottledMessage:
        ├─ now = Find.TickManager.TicksGame
        ├─ nextAllowedTick[key] > now → return
        └─ nextAllowedTick[key] = now + cooldown
        │
        ▼
  Messages.Message(text, type, historical)
  Find.LetterStack.ReceiveLetter(label, text, def, targets)
```

| `NotificationService.Message` | `static void Message(string text, MessageTypeDef type = null, bool historical = false)` | 左上角消息 |

| `NotificationService.ThrottledMessage` | `static void ThrottledMessage(string key, string text, MessageTypeDef type = null, int cooldownTicks = -1)` | 按 key 节流 |
