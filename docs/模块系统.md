## 简介

模块系统把「功能」拆成可开关、可排序、错误隔离的单元：`IModTemplateModule` + `ModuleRegistry`。内核只负责注册与生命周期，具体服务仍是静态类，通过 `ModuleRegistry.IsEnabled(id)` 决定是否工作。

模板内置六个模块：`core`（锁定）、`pawn-menu`、`notifications`、`build-control`、`tech-tree`、`diagnostics`（锁定）。

## 描述

- 契约：`Id`、`DisplayNameKey`、`DescriptionKey`、`InitOrder`、`Locked`、`EnabledByDefault`、`OnDefsLoaded`、`OnGameLoaded`、`ResetRuntimeState`。
- `ModuleRegistry.Register` 按 Id 去重、按 `InitOrder` 排序；`InitAll` 在 Def 就绪后调用（单个模块异常只记 Error）。
- `NotifyGameLoaded(Game)`：新游戏/读档时调用启用模块的 `OnGameLoaded`，并对所有模块调用 `ResetRuntimeState`（即使禁用也清理静态缓存）。
- 开关持久化：`ModuleSettings.disabled` 只保存被禁用的 Id；新模块默认启用；`ModulesSettingsPage` 用禁用态勾选显示锁定模块。
- 服务侧统一判断：`PawnMenuService`、`NotificationService`、`BuildControlService`、`MainButtonService` 都先查 `ModuleRegistry.IsEnabled`。
- 新增模块：实现 `ModTemplateModule` → 在 `Bootstrap.RegisterModules` 注册 → 加中英文 Name/Desc 键 → 需要时在服务里加 `IsEnabled` 判断。
- 锁定模块（`core` / `diagnostics`）不能关闭；设置页勾选框灰显并提示「始终启用」。

## 绘制调用逻辑图

```text
Bootstrap [StaticConstructorOnStartup]
  ├─ PatchAll
  ├─ RegisterModules()：core / pawn-menu / notifications / build-control / tech-tree / diagnostics
  └─ ModuleRegistry.InitAll()
        └─ foreach module（按 InitOrder）
              ├─ IsEnabled? 否 → 跳过
              └─ module.OnDefsLoaded()  // try/catch 隔离

新游戏 / 读档
  DemoGameComponent.FinalizeInit()
    └─ ModuleRegistry.NotifyGameLoaded(Current.Game)
          └─ foreach module
                ├─ IsEnabled? 是 → OnGameLoaded(game)
                └─ ResetRuntimeState()   // 无论开关都清理

运行期
  服务 → ModuleRegistry.IsEnabled("…")
          ├─ 模块不存在 → false
          ├─ Locked → true
          └─ ModuleSettings.IsEnabled(id)
```

|---|---|---|
| `IModTemplateModule.Id` | `string Id { get; }` | 稳定标识 |

| `IModTemplateModule.Locked` | `bool Locked { get; }` | 锁定模块 |

| `ModuleRegistry.Register` | `static void Register(IModTemplateModule)` | 注册/去重/排序 |
| `ModuleRegistry.InitAll` | `static void InitAll()` | 分发初始化 |
