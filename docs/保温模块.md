# 多墙体保温（Insulation）模块

> 状态：✅ 0.0.2 已落地（墙体层数保温、厚墙加厚屋顶、级联冷室）· 适用：RimWorld 1.6.x
> 代码：`Source/Modules/Insulation/` · 设置页：「保温」 · 模块 id：`insulation`

## 1. 这个模块做什么

原版 `RoomTempTracker.WallEqualizationTempChangePerInterval` 只看房间外**第 2 格**的室温：那格是空地还是第二层墙，都按同一个温度结算，所以墙砌几层都一样漏。模块在 Harmony Postfix 里按每面墙实际的**连续墙层数 d** 乘一个保温系数：

```text
f(d) = (1 + r) / (1 + r × d)      d ≤ 1 时 f = 1（与原版一致）
```

默认 `r = 3`：2 层约 57%、3 层 40%、4 层 31%；`r`、最大计入层数可在「保温」页调。

同一套 `f(d)` 也用在屋顶上：当房间最薄一侧外墙达到「加厚屋顶所需墙层」时，薄屋顶漏热按同层数缩放（无顶、厚岩顶不动）。

## 2. 级联冷室（为什么单靠墙厚到不了 -273°C）

空调效率是：

```text
eff = 1 - (热侧温度 - 冷侧温度) / 130
```

热侧在 20°C 时，**单台最多把冷侧压到 -110°C**，再往下 eff 归零、制冷为 0。所以 -273°C 只能靠多台串联：每段冷室都是独立小房间，后一段的热侧就是前一段的冷室。

但 1 格小房间的漏热按「表面积 / 体积」算是最亏的：一排 17 扇门的门廊，每门格每 120 tick 漏 ≈12°C，整排 ≈200°C，而一台空调满效率也只有 ≈42°C / 120 tick。墙厚对它们没用（那圈墙只有 1 层，f(1) = 1）。

**级联冷室**就是为这种结构加的补丁：识别「同向、间隔 2 格、中间夹着四面封死小室」的三台以上空调链，按理想级联结算。

### 2.1 识别条件（缺一不触发）

| 条件 | 说明 |
|---|---|
| 链长 | ≥ 3 台 |
| 朝向 | 全部相同（冷侧指向链内下一台） |
| 间距 | 相邻两台正好隔 2 格，中间那格就是该段冷室 |
| 中间小室 | 四面都被墙 / 空调 / 不通行建筑封死 |
| 冷室大小 | ≤ 32 格（避免把大厅当冷腔） |
| 空调状态 | 全部通电，且每台目标温度 ≤ 该段级联温度 |
| 总开关 | 「保温」页的「启用级联冷室」 |

### 2.2 结算规则

```text
第 k 段冷室目标 T(k) = max(-273.15, 热端温度 - 130 × (k + 1))     k = 0, 1, 2, …
```

- 每 `TickRare` 把各段冷室温度往 `T(k)` 拉最多 6°C；
- 链末端冷室连通的门廊（整段门格）并入同一冷腔，一起拉到最末段目标；
- 链正常工作时，链上冷室（含门廊）的墙体 / 薄顶 / 无顶漏热按 **0** 结算；
- 任一段断电、或把目标温度调高到该段之上，整条链**立即退回原版**（漏热恢复、冷室回温）。

### 2.3 内置「低版本永恒温室」怎么用

41×41 模板的四条十字臂各是一条这样的链（空调间隔 2 格、中间是封死小室、末端接门廊）：

1. 把模板摆下去，用 Debug「蓝图工具 → 全场空调设为 -273」（或逐台调到 -273°C）；
2. 保证全链路通电；
3. 「保温」页确认「启用级联冷室」勾上。

大约 3 个游戏小时（12k tick）后，链末端的门廊会到 -273°C，中间两段分别在约 -110°C、-240°C。大厅（四象限）仍然是热端，不会被冻住——这是设计如此，热必须从大厅排出去。

## 4. 自检

```powershell
$test = 'E:\RimWorld-WorkSpace\temp\test-envs\rimworld'
Start-Process "$test\RimWorldWin64.exe" -ArgumentList @(
  '-quicktest', "-savedatafolder=$test\SaveDataCascade", '-colonykit-cascade-test', '-logfile', '-'
) -RedirectStandardOutput "$test\cascade.stdout.txt"
```

自检会在空地上搭一条「3 空调 + 2 封闭小室 + 6 门门廊」的最小级联，跳过通电判定，跑 40000 tick，日志里每 10000 tick 打一行 `cascade tick=… ambient=… pocketA=… pocketB=… doorFirst=… doorLast=…`，结束时打 `pass=True/False` 并退出游戏。

## 5. 常见问题

| 症状 | 原因 |
|---|---|
| 温度停在 -110°C 左右 | 只有一台空调在工作，或链没被识别（间距不是 2、中间小室漏风、朝向不一致） |
| 到 -273°C 又回温 | 链上某台断电 / 被拆 / 目标温度被调高，级联退回原版 |
| 大厅也变冷了 | 不会；级联只处理链上冷室和链末端门廊，大厅是热端 |
| 摆了 3 台但没反应 | 检查「保温」页的「启用级联冷室」是否勾上，以及模块总开关 |
