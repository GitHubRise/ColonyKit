# 空中力量：抽象空袭 vs 同图飞行单位 vs 载具框架集成

- 状态：提议（G2 构想，未排期）
- 日期：2026-10-25
- 关联任务：8000（G2 构想，已在 0000 索引占位，未排期）；建议排在 1.0（M8）之后评估
- 影响范围：模块 / 存档 / 兼容 / 性能 / 战斗 / 经济 / 美术

## 背景

ColonyKit 现有六个模块都建立在**同一张地图的地面层**上：淋浴、立体库、农业、蓝图、机器人都不涉及高度、空域或航空后勤。玩家提出的下一个构想是引入**空中力量**，至少包括：

1. **无人机**：侦察、校射、自杀/巡飞弹、蜂群。
2. **直升机**：运输、机降、医疗后送、武装型火力支援。
3. **歼击机**：制空、拦截敌方飞机/巡航弹药。
4. **战斗机**：多用途，对地攻击 + 自卫空战。
5. **轰炸机**：重型对地打击，压制阵地/拆毁建筑。
6. **地面防空系统**：雷达、高炮、近防武器、地空导弹、便携防空。

这不是「加六种会飞的单位」，而是三件互相咬合的事：

| 层 | 要解决的问题 | 典型失败 |
|---|---|---|
| **空中单位** | 怎么生成、移动、渲染高度、被选中、被击落、存读档 | 飞机是地面 Pawn 换皮，撞墙、卡寻路、影子在地上 |
| **空战规则** | 谁发现谁、谁能打谁、命中/伤害/迫降/残骸怎么算 | 步枪能打飞机，或飞机无敌；防空炮和普通炮塔没区别 |
| **航空后勤** | 机场/机库/跑道、油、弹、飞行员、维修、架次上限 | 造一架飞机无限飞，空中力量变成自动胜利 |

### 玩家要的四种体验

1. **态势**：无人机/雷达先看到敌人，提前预警、标记目标。
2. **火力支援**：被围攻时呼叫空袭/机炮扫射，打破僵局。
3. **机动**：直升机把人/货从地图一端运到另一端，或快速增援。
4. **制空与防空**：敌人飞机来袭，雷达发现，高炮/导弹/歼击机拦截，掉残骸。

这四种体验对应的工作量差一个数量级；本文先记录调研与选型，不写代码。

### 构想目标（草案，待确认）

> 与 G1 不同，G2 目前只有「六类单位」这一句需求，没有追加硬需求。下面是按六类单位推出的**草案**，确认后才作为验收标准；未确认前只当设计方向。

1. **六类齐全、各有职责**：无人机/直升机/歼击机/战斗机/轰炸机/地面防空都能造、能上场，且不是同一套数值换皮。
2. **可见、可击落**：空中单位有高度感（影子/缩放/飞行姿态），能被防空武器锁定、击落或迫降，留下残骸/飞行员/战果。
3. **防空闭环**：雷达发现 → 预警/分配 → 高炮/近防/导弹拦截 → 击落/漏防 → 战果与残骸；不是「点一下按钮随机掉飞机」。
4. **克制三角**：防空 > 空中 > 地面 > 防空；没有一种单位能通吃。
5. **无 DLC 可运行**：不依赖 Odyssey 的 shuttle/gravship，也不硬依赖 Aerial Framework / Vehicle Framework / CE。
6. **性能上限**：同屏 ≤ 12 架空中单位，3 倍速 10 分钟无 tick 尖峰；无人机蜂群不能靠「一个单位一个 Pawn」硬堆。
7. **经济约束**：一个架次的油弹/维修成本 ≈ 一次小规模袭击收益的 1/3；不能无限刷。
8. **与地面模块协同但可独立**：机库可用立体库的存储、无人机可选用机器人的能量体系、地下室免疫轰炸；但 8000 单独启用也能玩。

> **结论先行**：G2 现在**不排期**，建议 1.0（M8）后评估；若立项，先做「无人机 + 防空」最小闭环，技术路线以 **B（同图飞行单位）为主、A（抽象空袭）为回退**，C 只做兼容，D（世界地图航空）不做。

### 调研结论

- **运输/直升机是成熟区**：SRTS、ELIF 直升机把「起降、装载、往返、旋翼动画」做完了；玩家对「飞过去、装人、飞回来」有明确预期。
- **战斗航空是框架区**：Aerocraft、Aerial Framework、Ancot Library、Vehicle Framework 各自提供一套「飞机怎么动/怎么被打」的底座，单机 Mod 在它们上面加型号；没有一个**Core-only、无 DLC、模块化**的全体系。
- **防空是窄实现**：现有防空 Mod 主要打迫击炮弹/空投仓，或提供高射炮；没有「雷达发现 → 分配 → 拦截 → 战果/残骸」的闭环。Aerial Framework 的 AA 判定是**按武器属性自动分类**，不是专门的防空建筑/雷达网。
- **「Aerial Mode」是最小可行抽象**：一个布尔状态 + 免疫非 AA + 无视地形 + 被击中 stun，就能支撑「飞机 vs 坦克 vs 防空」的三角；但它对全局补丁的侵入性很强，和 CE/载具框架的兼容是主要风险。
- **六类一体的产品在工坊上是空白**：这既是 ColonyKit 的机会，也是风险——没有现成 API 可以直接抄，必须自己定义「空中状态」和「防空判定」。

### 技术结论

原版能提供的积木只有四块：

1. **单次位移**：`PawnFlyer`（跳/空投/短途）。
2. **起降/通场**：`Skyfaller` + `FlyerArrival/Leaving`。
3. **区域轰炸**：`Bombardment` + `OrbitalStrike`。
4. **地面炮塔**：`Building_TurretGun` + `TargetingParameters`。

缺的三块必须自建：

1. **持续飞行的单位**：原版没有「飞机在场上盘旋/巡逻」的实体抽象；`PawnFlyer` 是一次性的。
2. **空对空/地对空判定**：原版没有高度、空域、雷达、锁定、拦截的概念。
3. **航空后勤**：油、弹、飞行员、机库、架次、维修，原版都没有。

## 六类单位与克制

### 克制三角

```text
              地面防空（雷达/高炮/近防/SAM）
                 ↗                     ↘
        空中力量（无人机/直升机/战斗机/轰炸机）
                 ↖                     ↙
                      地面部队/装甲
```

- **防空 > 空中**：防空便宜、射程远、弹药有限；飞机必须规划航线/压制防空。
- **空中 > 地面**：飞机对无防空掩护的地面部队/建筑有压倒性火力；但占不了地。
- **地面 > 防空**：防空阵地怕地面突击、炮击、无人机消耗、SEAD；不能只靠防空赢。
- **无人机**是「消耗品/侦察」，用来耗防空弹药、点灯、诱骗；不负责占领。
- **电子战/SEAD**（后期）打破三角：反辐射导弹打雷达、干扰降低锁定距离。

### 单位定位

| 类别 | 现实对应 | 游戏职责 | 关键机制 | 克制 | 被克制 |
|---|---|---|---|---|---|

## 空战模型（草案）

### 空域与高度

RimWorld 是 2D 地图，没有真实 z 轴。建议用**抽象高度带**而不是真 3D：

| 高度带 | 谁在这个带 | 谁能打 | 表现 |
|---|---|---|---|
| 低空 | 直升机、无人机、攻击机 | 高炮、CIWS、便携防空、步枪（低概率） | 影子大、机身低、可被地形遮挡 |
| 中空 | 战斗机、歼击机 | SAM、高炮（远距）、敌方歼击机 | 影子小、缩放略小 |
| 高空 | 轰炸机、侦察机 | 远程 SAM、歼击机 | 几乎只显示影子和航迹；普通枪械无效 |

实现上只存一个 `AirAltitude` 枚举（低/中/高），影响命中率、可被哪些武器锁定、影子大小；**不做真 z 轴**。

### 探测与预警

- **雷达**：`MapComponent_AirTraffic` + `CompRadar`，`TickRare` 扫描半径内的空中目标；输出「雷达接触」而非直接可见。
- **目视**：殖民者/炮塔在视野内可发现低空目标；高空目标只能靠雷达/数据链。
- **数据链**：塔台/雷达把接触共享给防空炮/歼击机；没有数据链时各打各的。
- **迷雾**：未探测的空中目标不显示具体型号，只显示「未知接触」；接近后识别。
- **预警**：Alert「敌机来袭」+ 大致方位/高度带，不直接给精确格。

### 交战流程

```text
雷达/目视发现
  → 识别（敌我/型号/高度带）
  → 分配（塔台/防空指挥：谁打谁，避免 overkill）
  → 拦截
      ├─ 高炮：直射弹幕，命中率随距离/速度/高度下降
      ├─ CIWS：近程高射速，优先拦截炸弹/导弹/无人机
      ├─ SAM：锁定 3s → 发射 → 命中/被干扰/脱靶
      └─ 歼击机：BVR 导弹 → WVR 机炮；双方掷命中/规避
  → 评估（击落/迫降/逃逸/漏防）
  → 战果（残骸、飞行员、残骸回收、XP）
```

### 空对地

- **机炮扫射**：连续 `Projectile`，单发低伤、压制/点燃；对开阔步兵有效，对掩体/厚墙差。
- **火箭/导弹**：选定目标格/Thing，少量高爆；有最小射程/散射。
- **炸弹**：复用 `Bombardment` 的落点/爆炸逻辑，或自定义 `Skyfaller` 投弹；对建筑/密集阵型强，对分散目标差。
- **燃烧弹**（后期）：点燃地面/建筑；天气/雨会减弱。
- **友伤**：所有对地攻击都可能误伤殖民者/建筑；目标格周围有友军时提示。

### 地对空

- **高炮**：直射、连发、弹速高；对低空/慢速目标命中高，对高空/高速低；弹药消耗大。
- **CIWS**：近程、极高射速；优先拦截进入保护圈的炸弹/导弹/无人机；对有人机伤害低。
- **SAM**：锁定时间、最小射程、最大射程、命中率；被干扰/诱饵欺骗；弹药贵。
- **便携防空**：Pawn 武器，`ckAntiAir=true`；射程短、一次性/少量弹药；适合护送/伏击。
- **射界/遮挡**：防空炮需要视野/射界；厚屋顶/山洞会遮挡（地下室免疫轰炸的联动）。

### 空对空

- **BVR**：雷达导弹，先发现先发射；命中率受雷达/干扰/目标机动影响。
- **WVR**：机炮/红外弹；双方进入缠斗后按速度/机动/飞行员技能掷骰。
- **结果**：击落/击伤（漏油/降速）/逼退；不追求真实飞行模拟。
- **飞行员**：跳伞/弹射 → 落地为殖民者/囚犯/尸体；可救援/俘虏。

### 损失与残骸

- 空中单位 HP 归零 → `Skyfaller` 坠落动画 → 残骸（`ThingDef`）+ 爆炸/火焰 + 可能的飞行员。
- 残骸可拆：零部件/钢铁/合金/弹药（未爆弹）；有爆炸风险。
- 迫降：HP 低但未归零 → 强制飞向最近机场/空地降落；失败则坠毁。
- 战果记录：击落数、架次、损失；可做王牌飞行员/勋章（后期）。

### 天气与夜战

- 雷暴/大风：直升机/无人机停飞或命中率下降；固定翼受影响较小。
- 雨/雪：目视探测距离下降；雷达不受影响。
- 夜间：目视/高炮命中下降；雷达/夜视装备补偿。
- 极端天气：可作为「天然防空」，让玩家有非战斗的应对手段。

## 实现路线（三种主路线 + 一种备选）

### A. 抽象空袭（离图 sortie）

飞机不在地图上持续存在，而是「塔台呼叫 → 地图外飞来 → 目标格效果 → 飞走」：

```text
塔台 Gizmo / 能力
  → 选择目标格/目标 Thing
  → 检查：油量、弹药、飞行员、冷却、天气
  → Sortie 状态（地图外，计时/距离）
  → 到达：Skyfaller 通场 + Bombardment/自定义空袭
  → 防空：每个 AA 站点按距离/高度/射界掷拦截
      ├─ 拦截成功：sortie 中止/被击落（残骸/飞行员）
      └─ 拦截失败：轰炸生效
  → 返航/冷却/补油补弹
```

**优点**：代码量最小；不需要飞行 Pawn/寻路/渲染/目标选择补丁；存档简单（一个 sortie 状态）；可直接复用 `Bombardment`/`Skyfaller`；适合先做出「有空中支援」的玩法。
**代价**：没有持续可见的飞机（只有通场动画）；不能亲自驾驶/狗斗；防空是掷骰，表现力弱；直升机运输仍要另做。
**适合**：MVP 的轰炸机/空袭支援、敌方空袭事件；可作为路线 B 失败后的回退。

### B. 同图飞行单位（Aerial Mode）

飞机是地图上的实体（Pawn 或 Thing），有「空中状态」：

```text
CK_Drone / CK_Helicopter（Pawn 或 Thing）
  ├─ CompAerial / Hediff "AerialMode"
  │    ├─ 移动：直线 waypoint（不走 PathFinder），忽略墙/水
  │    ├─ 渲染：DrawPos + 高度偏移 + 地面影子 + 缩放
  │    ├─ 选中：draft / 攻击 / 跟随 / 起降
  │    └─ 受击：只有 ckAntiAir 武器能命中；HP → 击落/迫降
  ├─ 起降：Skyfaller（FlyerArrival/Leaving）或垂直起降
  └─ 后勤：油/弹/维修/飞行员
```

**优点**：看得见、打得到、可狗斗、可驾驶；六类单位都能落在这套模型上；最接近玩家对「空中力量」的想象。
**代价**：要补移动/渲染/目标选择/伤害/存档；与 CE、Aerial Framework、Vehicle Framework 的补丁可能冲突；性能和美术压力最大。
**参考**：Aerial Framework 的「Aerial Mode」、Aerocraft 的「飞行中免疫近战/爆炸 20%」、Vehicle Framework 的载具 Pawn。

#### B1. Pawn 路线

- 飞机是 `Pawn`（机械体/特殊种族），可 draft、可被炮塔当目标、可用 `Pawn.DrawPos` 做高度偏移。
- 优点：选择/征召/装备/技能/UI 都能复用；缺点：Pawn 有需求/健康/社交/心情，需要屏蔽；寻路要绕开。
- 适合：无人机、直升机、有人机。

#### B2. Thing 路线

- 飞机是 `ThingWithComps`，自定义 `DrawPos`/`Tick`/`Gizmo`；不进入 Pawn 系统。
- 优点：没有需求/健康负担；缺点：不能被 draft、目标选择/炮塔要额外适配、UI 要自建。
- 适合：一次性巡飞弹、纯抽象的空袭单位。

### C. 载具/航空框架集成

检测 Aerial Framework / Vehicle Framework / Aerocraft / Ancot Library / SRTS，按对方 API 加 Defs 或补丁，不复制对方代码。

**优点**：省掉飞行/渲染/碰撞的工程；视觉/物理成熟；玩家可混用。
**代价**：硬依赖（违反「模块独立」）；版本变动/CE 耦合；和本模块的「防空判定」可能双重补丁；无 DLC 环境不一定可用。
**定位**：只做**可选兼容**，不作为 8000 的核心依赖；检测到就提示「建议只保留一套空中系统」。

### 备选 D：世界地图航空（不做）

飞机是世界地图上的 `WorldObject`，任务（侦察/轰炸/运输）在世界地图结算，只有到目标地图才生成战术空袭。

**优点**：战略纵深、远程打击、运输；不要求每张地图都有飞机实体。
**代价**：世界地图 AI/任务系统工作量大；仍要解决战术空袭表现；不满足「看着飞机打」的核心体验。
**定位**：不做 MVP；可作为后期「远程轰炸/空运」扩展。

## 对 ColonyKit 的建议

### 1. 现在不要开 8000

理由与 G1 相同，甚至更强：

- M1 水网、M2 淋浴、M3 立体库都还没落地；1.0 的六个模块尚未交付。
- 空中力量是 ColonyKit **第一次进入战斗/军事系统**，与现有「生活设施」定位差异很大；它应该是一个独立扩展包/1.0 后的新方向，不要混进 1.0 范围。
- 六类单位全做，单人工程量约 **4–6 个月**（粗略：无人机+防空 4–6 周，直升机+后勤 4–6 周，固定翼+空战 6–8 周，SEAD/电子战/王牌 4–6 周，加上调试/兼容/美术/文档）。这会把 1.0 拖到 2027。

**结论：G2 只登记构想，不排期；1.0（M8）之后再评估。**

### 2. 如果要做：先做「无人机 + 防空」最小闭环

这是唯一能用最小代价验证「空中状态 + 防空判定 + 击落/残骸 + 存读档」的切片，也是六类里最容易做的：

- 1 种侦察/自杀无人机（Pawn 或 Thing）。
- 1 种高炮/CIWS（`ckAntiAir` 武器）。
- 1 座雷达（`TickRare` 探测）。
- 1 个敌方无人机空袭事件。
- 击落 → 残骸 + 可能的飞行员/战果。
- 空袭表现先用 `Bombardment`/`Skyfaller`，不要求全六类。

Go 之后再依次加直升机（运输/后勤）、固定翼（歼击机/战斗机/轰炸机）、空对空、SEAD。

### 3. 技术路线优先级

1. **B（同图飞行单位）为核心**：只有 B 能满足「看得见、打得到、可驾驶」；先做 B1（Pawn）的无人机。
2. **A（抽象空袭）为第一版/回退**：如果 B 的补丁/性能/存档在 spike 里失败，退到 A，仍能交「空中支援 + 防空」。
3. **C（框架集成）只做兼容**：检测 Aerial Framework/CE/载具框架，给提示/补丁，不作为依赖。
4. **D（世界地图）不做**：除非以后明确要「远程空运/战略轰炸」。

### 4. 与 G1 地下室的联动

- 地下室「不受天气/空袭」的硬需求天然克制轰炸机；防空必须在地面，不能搬进地下。
- 加固机库（厚岩顶/山体）可挡部分轰炸；但跑道/停机坪必须露天，形成「藏飞机 vs 用飞机」的取舍。
- 这两个构想都涉及「垂直空间/跨层」，但实现完全不同：G1 是地图/层，G2 是单位/空域；不要合并成一个模块。

### 5. 与 Robotics 6000 的边界

- 无人机天然像「机器人」，但 6000 的机器人是**地面工作型**（搬运/清洁/做饭/医疗/战斗），8000 的无人机是**飞行器**（侦察/巡飞/蜂群）。
- 建议：8000 的无人机**可选**复用 6000 的能量/充电 API，但不硬依赖；如果 6000 未启用，无人机用自带的燃料/电池。
- 不要把「飞行无人机」塞进 6000，否则 6000 的范围/验收会被拖垮。

## 经济与平衡（草案）

### 成本原则

1. **一架战斗机 ≈ 一次远征**：飞机是战略资产，不是消耗品；损失要疼。
2. **一个架次 ≈ 一次小袭击收益的 1/3**：油弹/维修让「天天炸」不划算。
3. **防空比飞机便宜数倍**：高炮 800 vs 战斗机 2,500；否则没人造防空。
4. **空中不能占点**：飞机再强，最后还是要地面部队占领/清理；避免「空军通吃」。
5. **敌人也有空中力量**：敌方空袭随财富/科技/玩家空中战绩升级；玩家必须投资防空。

### 平衡旋钮

| 旋钮 | 作用 | 默认草案 |
|---|---|---|
| 架次冷却 | 限制出动频率 | 战斗机 3 天/架次；轰炸机 5 天 |
| 油/弹消耗 | 限制持续作战 | 见型号表；缺油强制返航/迫降 |
| 空中上限 | 限制同屏数量 | 塔台 1 座 = 同时 4 架；升级/多塔台提高 |
| 防空弹药 | 限制防空强度 | 高炮弹链 200 发；SAM 4 枚；打空需补给 |
| 命中/规避 | 让速度/高度有意义 | 高炮对低空 60%、中空 35%、高空 15%（草案） |
| 天气 | 提供非战斗克制 | 雷暴/大风停飞无人机/直升机 |
| 敌方 AA | 防止玩家无脑空军 | 敌方基地/车队带便携防空；后期 SAM |

## 兼容与性能

### 兼容

| 对象 | 策略 |
|---|---|
| **Combat Extended** | README §1 已把 CE 兼容列为范围之外；不承诺数值兼容。若玩家装 CE，需至少不崩：`ckAntiAir` 用自定义字段，不猜 CE 弹药；文档明确「未适配 CE」 |
| **Aerial Framework** | 它的全局 `Aerial Mode` 会和本模块的空中判定**双重生效**；检测到就提示「只保留一套」，或提供设置让本模块让位；不做双重免疫 |
| **Vehicle Framework / Aerial Vehicles** | 不硬依赖；如检测到，可给「防空炮也能打它们的飞行载具」兼容补丁（后期）；默认不保证 |
| **Aerocraft / Ancot Library / SRTS** | 运输/飞行重叠；默认共存但不互相识别；后期可做「AA 可锁定对方飞机」的兼容 |
| **Z-Levels / MultiFloors / RimLayers** | 空中单位只在**地面地图**活动；地下室/其他层免疫轰炸；不做跨层飞行 |
| **Odyssey（若以后装）** | shuttle/gravship 是运输/轨道语义，不替代战斗机；避免重复运输定位；是否让 AA 打 shuttle 由设置决定 |
| **Save Our Ship 2** | 轨道/太空，和大气层内空战不冲突；不做联动 |
| **多人** | 本工程不支持联机（README 范围之外） |
| **存档** | 空中状态/油弹/飞行员/残骸/战果都要 `Scribe`；读档时若飞机在空中，恢复到「返航/盘旋」而不是消失；缺 Def 时安全移除并提示 |

### 性能预算

- **同屏空中单位 ≤ 12**；无人机蜂群用「一个中队 = 一个单位」或分批生成，不一个无人机一个 Pawn。
- **不走 `PathFinder`**：直线/waypoint 移动，O(1) 每单位每 tick；避免全图寻路。
- **雷达/探测 `TickRare`**：250 tick 一次；不要每 tick 扫 `AllThings`。
- **弹幕上限**：同时存在的自定义 projectile ≤ 200；CIWS 用短寿命 `Projectile`/`Mote`，不无限累积。
- **渲染**：离屏剔除；影子用 `Mote`/`Graphic`，不每帧新建材质；同屏飞机 ≤ 12 时 draw call 可控。
- **存档**：只存状态机/列表，不存每 tick 委托；读档重建。

| 风险 | 影响 | 应对 |
|---|---|---|
| **空中状态补丁地狱**（移动/渲染/目标/伤害/存档） | 最高；可能做半年不可玩 | 先 2–3 天 spike；补丁集中在一个 `HarmonyPatches_Air`；失败退路线 A |
| **兼容冲突**（Aerial Framework/CE/载具框架） | 双重免疫/炮塔失效/红字 | 检测 + 设置 + 明确不兼容；不猜对方实现 |
| **平衡失控**（空军无敌或废物） | 玩家要么无脑赢，要么不造 | 防空便宜、架次成本、天气、敌方 AA；M9 后专门调 |
| **美术**（飞机/直升机/旋翼/残骸） | 占位色块破坏体验 | 首版占位几何/剪影；预留美术预算；不承诺写实 |
| **性能**（蜂群/弹幕/雷达） | 3 倍速卡顿 | 上限、TickRare、对象池、离屏剔除；M9-性能验收 |
| **存档**（空中读档） | 飞机消失/卡死/坏档 | 状态机 + 读档回退「返航/降落」；版本化 schema |
| **范围蔓延**（六类全做） | 拖垮 1.0 | 分阶段 Gate；MVP 只做无人机+防空 |
| **DLC 重叠**（Odyssey shuttle/gravship） | 定位重复/数值冲突 | 不做替代；可选兼容；文档写清 |

## Spike 验收（Go/No-Go）

**目标**：证明「1.6 + 无 DLC + Harmony」能做出一个可见、可打、可存读档的空中单位 + 一个能击落它的防空武器，且性能可接受。

**最小原型**（2–3 天）：

1. `CK_Drone`：Pawn 或 Thing，`CompAerial` 状态；从地图边缘直线飞到中心，无视墙/水；`DrawPos` 高度偏移 + 地面影子。
2. `CK_AA_Gun`：`Building_TurretGun` 子类或自定义炮塔；`VerbProperties` 加 `ckAntiAir=true`；能锁定/击落 `CK_Drone`。
3. `CK_Radar`：`MapComponent` + `TickRare` 扫描；Alert「敌机来袭」。
4. `CK_AirRaid`：Incident 在边缘生成 3 架敌方无人机，飞向基地。
5. 击落：`Skyfaller` 坠落 + 残骸 + 可能的飞行员；残骸可拆。
6. DebugAction：生成无人机 / 切换空中状态 / 击落 / 存读档。

**Go/No-Go 标准**（全部满足才继续）：

- [ ] 无人机无视墙体/水飞行，不触发寻路错误/卡死；渲染有高度感 + 地面影子。
- [ ] 普通步枪/近战不能锁定/伤害它；防空炮能锁定并击落；击落后有残骸。
- [ ] 飞行中存读档，位置/状态/目标/油弹恢复；`Player.log` 无 error。
- [ ] 10 架无人机 + 2 座防空 + 1 座雷达，3 倍速 10 分钟无 tick 尖峰（对比同规模地面场景）。
- [ ] 与 Aerial Framework 同装：不双重免疫/不崩；或明确记录「不兼容」。
- [ ] 与 CE 同装（如可用）：不崩；数值不保证。
- [ ] 无 DLC 环境可运行；不出现缺贴图/缺 Def 红字（占位图可接受）。

**任一核心项失败且没有低成本修法 → 停止路线 B，退路线 A（抽象空袭 + 防空掷骰）**，保留无人机/雷达/防空建筑，但飞机不常驻地图。

## 待确认问题

1. **操控方式**：玩家要「亲自驾驶/操控飞机」还是「塔台呼叫支援」？前者必须走 B，后者 A 就够。
2. **单位形态**：飞机是 Pawn（可 draft/有健康）还是载具/Thing？是否需要飞行员/培训/经验？
3. **空对空**：是否要狗斗/拦截，还是只做「空对地 + 地面防空」？空对空会显著增加 AI/平衡工作。
4. **范围**：六类全做，还是先无人机+防空，后续按版本加？是否接受「1.0 后再做」？
5. **敌人空袭**：从什么时候开始？与财富/难度/科技/玩家空中战绩如何挂钩？
6. **燃料/弹药**：用原版化合燃料/钢铁，还是新增「航空燃油/航空弹药」？新增物品会影响存储/配方/汉化。
7. **机场**：需要跑道吗？直升机坪 vs 固定翼跑道 vs 垂直起降；机场占地多大？
8. **与 6000 机器人**：无人机是否复用机器人能量/充电，还是完全独立？
9. **与 Odyssey**：以后装 DLC 时，shuttle/gravship 是否纳入防空目标/运输替代？
10. **电子战/SEAD**：是否在范围内？反辐射导弹/干扰/诱饵会改变克制三角。
11. **美术**：占位几何/剪影可接受，还是要写实飞机贴图？谁出图？
12. **联机/多人**：是否需要（本工程当前不支持联机）？
