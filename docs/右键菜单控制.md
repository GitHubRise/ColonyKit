## 简介

RimWorld 1.6 的右键菜单由 `FloatMenuOptionProvider` 子类自动发现，不需要 Harmony。模板只写一个 Provider，把所有扩展项交给 `PawnMenuService` 注册表，外部代码不用碰原版菜单逻辑。

## 描述

- 自动发现：`FloatMenuMakerMap.Init()` 用 `typeof(FloatMenuOptionProvider).AllSubclassesNonAbstract()` 实例化所有 Provider；`ModTemplatePawnMenuProvider` 因此自动生效。
- Provider 约束：征召/未征召都显示（`Drafted=true`、`Undrafted=true`），单选（`Multiselect=false`），允许右键自己（`CanSelfTarget=true`）。
- 注册表：`PawnMenuService.Register(id, create, applies, priority)`；同 Id 覆盖，priority 大的排前面。
- 设置：`GeneralSettings.enablePawnMenu` 总开关；关闭后 `GetOptions` 直接返回空。
- 异常隔离：`applies`/`create` 抛异常只记 `Error`，不会炸掉整个右键菜单。
- 模板自带两个演示项（只在殖民者上出现）：
  - 「记录该殖民者」：写日志 + 节流通知；
  - 「在附近建造演示墙」：调用 `BuildControlService.PlaceBlueprint` 放一个钢墙蓝图。

## 绘制调用逻辑图

```text
右键点在小人身上
      │
      ▼
FloatMenuMakerMap.GetOptions(selectedPawns, clickPos)
  └─ GetProviderOptions(context)
        └─ ModTemplatePawnMenuProvider.GetOptionsFor(pawn, context)
              └─ PawnMenuService.GetOptions(pawn)
                    ├─ enablePawnMenu == false → 空
                    └─ foreach entry（按 priority 降序）
                          ├─ entry.Applies(pawn) == false → 跳过
                          ├─ option = entry.Create(pawn)   // try/catch
                          └─ yield option
      │
      ▼
原版 FloatMenu 显示追加项
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `PawnMenuService.Register` | `static void Register(string id, Func<Pawn, FloatMenuOption> create, Func<Pawn, bool> applies = null, int priority = 0)` | 注册/覆盖菜单项 |
| `PawnMenuService.Unregister` | `static bool Unregister(string id)` | 取消注册 |
| `PawnMenuService.GetOptions` | `static IEnumerable<FloatMenuOption> GetOptions(Pawn pawn)` | 按开关/条件生成选项 |
| `PawnMenuService.Count` | `static int Count { get; }` | 已注册数量 |
| `ModTemplatePawnMenuProvider` | `sealed class : FloatMenuOptionProvider` | 原版自动发现的入口 |
| `ModTemplatePawnMenuProvider.GetOptionsFor` | `override IEnumerable<FloatMenuOption> GetOptionsFor(Pawn, FloatMenuContext)` | 转交注册表 |

## 所含功能

- 无需 Harmony 的右键菜单扩展；
- 条件（`applies`）与优先级排序；
- 同 Id 覆盖、取消注册；
- 全局开关；
- 异常隔离与前缀日志；
- 演示：记录殖民者、建造演示墙。
