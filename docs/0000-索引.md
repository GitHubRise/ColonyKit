# 0000 索引

> **ColonyKit 文档总入口。** 先读本页，再进各模块索引，最后看具体功能页。
>
> 当前工程由 `mod-template` 0.0.1 复制、已同步 0.0.2 框架修复（M0 完成）；`localization`（开发者菜单汉化）已移植并通过 quicktest 自检，`hygiene` / `storage` / `rjw` 仍为占位。所有「使用说明」在对应功能实现前都是**草案**，实现后以游戏内 UI、Def 数值和本页状态为准。

## 1. 怎么读

1. 先看下面「模块编号」找到要用的模块，点进 `X000-<模块>索引.md`。
2. 模块索引里的「功能地图」按 `X001`、`X002`… 列出每个功能页。
3. 功能页统一按 11 节组织：TOC快速预览 → 简介 → 描述 → 绘制调用逻辑图 → 函数清单 → 函数或功能完成情况 → 涉及文件 → 所含功能 → 如何使用 → 常见问题 → 相关文档。
4. 文档状态标记：

| 标记 | 含义 |
|---|---|
| 规划中 | 只有设计，代码未写；页面内容是按 README 推出的使用草案 |
| 📄 | 功能页/设计文档里的简写，等同「规划中」 |
| 实现中 | 对应里程碑已开工，UI/数值可能变 |
| 可用 | 已实机验证，按页面操作能走通 |
| 变更中 | 正在改机制，页面可能暂时失效 |

## 4. 编号与命名规则

- **0000**：总索引，只放导航、编号表、维护规则。
- **X000**：模块索引，只放模块概览、功能地图、快速开始、依赖与限制。
- **X001–X999**：具体功能页，一页只讲一个功能；文件名 `编号-模块-功能.md`。
- 功能页固定 11 节结构，顺序不要变；模块索引（X000）不套用该结构，只做导航。
- 编号按 1000 递增：淋浴 1000、立体库 2000、农业 3000、蓝图 4000、汉化 5000、机器人 6000；7000 地下室（构想）、8000 空中力量（构想），之后继续预留。
- 功能页之间可以互相链接，但不要跨模块复制同一份说明；跨模块内容放 `框架内核.md` / `水网服务.md` 或对应模块索引。
- 新增功能时：先在模块索引的功能地图里占号，再建功能页，最后回填总索引的文档地图。
- 删除功能时保留编号，页面改成「已移除」并说明替代方案，不要复用编号。

## 5. 维护规则

1. **状态同步**：功能进入实现/可用时，同时改总索引、模块索引、功能页三处的状态。
2. **数值以 Def 为准**：文档里的数值都是默认值/草案；实际以 `Defs/` 和游戏内 tooltip 为准，调平衡后回填。
3. **UI 名称以游戏内为准**：本文档用「研究」「建造」「Gizmo」等通用词；具体按钮名以 Keyed 文本为准。
4. **不写空链接**：引用尚未创建的文档时写「待建」，不要留死链。
5. **实现后补截图/日志**：功能可用后，在功能页补一张截图或一段 `Player.log` 关键行，方便回归。
6. **README 与文档集同步**：模块范围、里程碑、数值口径变化时，先改 README，再改本目录。
