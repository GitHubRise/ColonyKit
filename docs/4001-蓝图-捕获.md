## 简介

用「捕获蓝图」设计器拉一个矩形，把范围内**玩家建造的建筑**存成一条蓝图记录，放进当前存档的蓝图库。

## 描述

- 只收玩家建造的建筑；跳过蓝图（未施工）、框架、物品；地形可选（M5-1 定稿）。
- 记录 `defName`、材质 `stuff`、朝向 `rot`、相对坐标；不记录耐久/品质（按新建处理）。
- 多格建筑按原点 + 朝向记录，避免旋转错位。
- 捕获不消耗材料、不暂停游戏；大范围可能短暂卡顿。
- 单张蓝图尺寸上限 M5-0 定稿；超过拒绝并提示。
- 捕获不改变地图上的建筑。

## 绘制调用逻辑图

```text
Designator_BlueprintCapture
        │ 鼠标拉框
        ▼
遍历矩形内 Thing
        ├─ Building 且玩家建造 → 收集
        ├─ Blueprint/Frame/Item → 跳过
        └─ 地形（可选）→ 记录 defName
        │
        ▼
BlueprintRecord（尺寸/坐标系/条目/版本）
        │
        ▼
BlueprintLibrary.Add(record) → 存档
```

## 所含功能

- 拉框选择范围。
- 收集玩家建筑、跳过其他。
- 记录材质/朝向/相对坐标。
- 地形可选。
- 尺寸上限与提示。
- 存入每存档蓝图库。

## 如何使用

**前提**：研究「蓝图管理」；范围有已建好的建筑。

1. 点「捕获蓝图」。
2. 拉框选中范围。
3. 看摘要（数量/尺寸/材料），命名。
4. 保存后到蓝图库确认。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 捕获后少了几栋 | 那些是蓝图/框架/物品/非玩家建筑 | 先建完再捕获 |
| 多格建筑错位 | 原点/朝向记录问题 | 记录 bug；避免旋转多格建筑 |
| 捕获没反应 | 研究没解锁/设计器不可用 | 检查研究 |
