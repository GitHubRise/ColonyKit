## 简介

用「捕获蓝图」设计器拉一个矩形，把范围内**玩家建造的、已完工且可见的建筑**存成一条蓝图记录，放进当前存档的蓝图库。捕获只记录建筑，不改地图、不消耗材料。

## 描述

- 只收**玩家阵营**的建筑；跳过未施工蓝图、框架、矿物、自然岩石、物品和其他阵营建筑。
- 拖框范围内的**雾格/未探索格**不参与捕获；只要多格建筑有占用格落在框内可见格中就会被收进来（即使它的原点在框外）。
- 记录 `defName`、材质 `stuffDefName`、朝向 `rot`、相对坐标 `x/z`；不记录耐久/品质，复刻后按新建处理。
- 一条记录的坐标原点 = **捕获到的建筑占用矩形的包围盒左下角**，不是拖框左下角；因此拖框四周的空白边距会被裁掉，`sizeX/sizeZ` 是实际建筑范围。
- 多格建筑记录的是建筑 `Position` 相对原点的偏移，同时保存朝向；放置时按占用矩形反推新位置。
- `maxSide` 先按**拖框宽高**检查；`maxEntries` 按**实际收集到的建筑数**检查。两者都在设置页调整。
- 库满（`records.Count >= maxRecords`）时捕获入口直接拒绝；`maxRecords` 默认 256。
- 捕获不暂停游戏、不消耗材料、不改变地图；超大范围会遍历较多格子，可能有短暂卡顿。

## 绘制调用逻辑图

```text
蓝图页「捕获蓝图」
        │ 关闭标签页并选中设计器
        ▼
Designator_BlueprintCapture
        ├─ 拖框高亮：可见且在界内的格子（FilledRectangle）
        ├─ DesignateMultiCell(cells)
        │     ├─ 库未就绪 → NoLibrary
        │     ├─ 库已满 → LibraryFull
        │     └─ BlueprintRecord.Capture(map, rect, ...)
        │           ├─ 拖框超 maxSide → TooBig
        │           ├─ 逐格收集：可见、界内、玩家完工建筑（去重）
        │           ├─ 没有建筑 → NoBuildings
        │           ├─ 超过 maxEntries → TooMany
        │           └─ 以建筑包围盒为尺寸/原点生成条目
        ▼
library.NextDefaultName() → library.Add(record)
        ▼
消息提示 → 打开蓝图页并选中新记录
```

## 所含功能

- 拉框选择范围，只接受界内、可见格子。
- 收集玩家完工建筑，跳过蓝图/框架/矿物/自然岩石/物品/其他阵营。
- 记录材质、朝向、相对坐标与实际建筑包围盒尺寸。
- 尺寸、建筑数、库数量上限与提示。
- 默认命名、自动入库、打开蓝图页并选中。

## 如何使用

**前提**：已进入有地图的存档；蓝图模块未软停用；库里还有空位。

1. 底部「蓝图」→ 右上角「捕获蓝图」。
2. 在已建好的建筑上拉框（蓝色高亮 + 尺寸读数）；框内空白边距不会进入蓝图。
3. 松手后自动入库，名字默认为「蓝图 N」。
4. 蓝图页自动打开并选中；可「重命名」或直接「放置」/「另存为模板」。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 捕获后少了几栋 | 那些是蓝图/框架/物品/其他阵营/未完工/雾格/范围外 | 先建完、探开再捕获 |
| 蓝图尺寸比拖框小 | 尺寸取实际建筑包围盒，空白边距被裁掉 | 正常行为；需要留空就放些建筑占位 |
| 捕获没反应 | 范围内没有可捕获建筑、库已满、拖框超 `maxSide` | 看提示消息；清库或调设置 |
| 想连地板一起存 | 当前不含地形/地板 | 放置后手动铺地板 |
| 捕获会消耗材料吗 | 不会 | 只读地图建筑，不改地图 |
