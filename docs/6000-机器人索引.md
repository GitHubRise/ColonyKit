## 五种型号

| 型号 | 默认工作 | 备注 |
|---|---|---|
| 搬运机器人 | `Haul` | 高携带、移速略高 |
| 清洁机器人 | `Clean` | 清洁速度加成 |
| 做饭机器人 | `Cook` | 烹饪技能高 |
| 医疗机器人 | `Doctor` | 照顾病人；手术待定 |
| 战斗机器人 | 无工作，只能 draft | 射击/近战、可穿护甲；不自动充电 |

## 能源口径（草案）

| 项目 | 数值 | 换算 |
|---|---|---|
| 满电行动 | 12 小时 | 30000 tick，活跃耗电 `1/30000`/tick |
| 休眠快充 | 4 小时充满 | 10000 tick，`1/10000`/tick，4000W |
| 普通对接 | 8 小时充满 | 20000 tick，`1/20000`/tick，2000W |
| 低电阈值 | 25% 自动充电 / 5% 强制休眠 / 0% 停机 | 0% 是 downed，不是死亡 |

## 快速开始（草案）

1. 研究「机器人学」。
2. 在机械加工台/精密装配台制造对应型号。
3. 建 `CK_ChargingPod`（1×2）并接电；4000W 快充，电网要提前扩容。
4. 机器人低于 25% 自己去充电；也可以手动 Gizmo「去充电 / 休眠快充 / 唤醒」。
5. 在 Work 页确认型号工作；默认锁定，设置可解锁。
6. 战斗机器人手动 draft；0% 停机后搬到充电桩恢复。

## 依赖与兼容

- 需要电力，不需要水网、不需要食物/床。
- 不依赖 Biotech；本机未装 DLC，机器人走独立实现。
- 不参与社交/恋爱/生育/心情；没有睡眠需求，但休眠快充会被当作「睡觉」。
- 与 DBH/RJW 无直接重叠；若它们修改 Pawn 需求/工作，需要在 M8-4 冒烟。

## 已知限制 / 待确认

- **M6-0 先验证 Pawn 架构**（humanlike vs mech-like），本文的 UI/工作细节可能随结论调整。
- 普通充电 8h/2000W 是草案；用户只指定了「休眠 4h 充满」「满电 12h 行动」。
- 数量上限/控制台、维修/残骸、自动防御均待确认。
- 4000W 充电桩对电网冲击很大，这是刻意约束；多机器人同时快充要排队。
