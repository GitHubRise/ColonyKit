## 能源口径（草案）

| 项目 | 数值 | 换算 |
|---|---|---|
| 满电行动 | 12 小时 | 30000 tick，按容量百分比耗电 |
| 充电 | 4 小时充满 | 10000 tick，4000W |
| 电池容量 | 默认 4000W | 设置页可调 1000–20000W |
| 低电阈值 | 默认 25% 自动回桩 | 设置页可调 5%–95% |
| 0% | 停止工作，不会死亡 | 需玩家接电/维修/拆解 |
| 耐久 | 1000 | 只有受伤才损耗；0 报废为 40 钢 + 3 零部件 |

## 快速开始（已落地部分）

1. 研究「家政机器人」（前置：机械加工）。
2. 在建筑师「机器人」菜单建 `CK_NannyBotStation`（1×1，150 钢 + 8 零部件）并接电。
3. 工作站建成后自动组装一台保姆机器人。
4. 打开 **设置 → 机器人**，开关家务并调整充电/加燃料阈值、电池容量、工作半径/区域。
5. 底部 **机器人 → 工作管控**：每台机器人逐项排 1–8 优先级（0 关闭），列头可整列开关；**机器人状态**页查看电量/耐久/任务/工作站。
6. 选中机器人：可暂停/继续、召回、前往、点选污渍优先清理、改名、涂装；电量低于阈值自动回桩。
7. 耐久为 0 会报废；殖民者会自动维修（建造）。损毁后工作站 1 天冷却重装。
8. 工作站可定位/召回绑定机器人。

## 依赖与兼容

- 需要电力充电，不需要水网、食物/床。
- 不依赖 Biotech；机器人走独立 `ToolUser` 机械族实现（`CK_NannyBotBody`）。
- 不参与社交/恋爱/生育/心情；没有睡眠需求。
- 与 DBH/RJW 无直接重叠。

## 已知限制 / 待确认

- 首版只有保姆机器人；搬运/做饭/医疗/战斗型号未实现。
- 充电桩固定不可搬运；机器人损毁后固定 1 天冷却，不消耗材料。
- 机器人不能手动移动/征兆，也没有 Work 页；只通过三项家务开关和「去充电」干预。
- 4000W 充电对电网冲击很大，这是刻意约束；多机器人同时快充需要扩容。
- 长期存读档、4000W 充电电网、停机后救援尚未实机覆盖。
