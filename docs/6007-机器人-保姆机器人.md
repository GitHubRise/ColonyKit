## 简介

保姆机器人（`CK_RobotNanny`）是 M6 智能机器人模块的首个落地型号。它是玩家阵营的机械族 Pawn，不吃饭、不睡觉、不社交，只消耗内置电量；会自动扫地、清洁、搬运、灭火、屠宰、加燃料、给囚犯送餐、维护卫生，并在发现殖民地人员倒地时优先救援。

它不是原版 Work 页里的殖民者，但有独立的 **底部「机器人」→ 工作管控** 页：每台机器人逐项排 1–4 优先级，0 关闭。家务总开关在 **设置 → 机器人**；选中机器人后可暂停、召回、前往、点选污渍、改名、涂装。

## 所含功能

- 不吃饭、不睡觉、不社交、不生育的玩家机械族工人。
- 扫地（家内）、清洁（家外）、搬运（立体库优先）、灭火、屠宰、发电机加燃料、囚犯送餐、卫生维护、优先救援。
- 1000 耐久，只有受到伤害时才损耗；殖民者维修；0 报废成钢和零部件。
- 容量制电量（默认 4000W）、充电阈值、加燃料阈值、工作半径/区域、危险规避。
- 充电桩自动组装/重装、50W/4000W 功耗、充电光效、定位/召回。
- 手动指令：暂停/继续、召回、前往、点选污渍、改名、8 种涂装。
- 底部「机器人」页：工作管控（类似原版工作页的优先级列表，列头可整列开关）+ 机器人状态（电量/耐久/任务/工作站）。
- 中英文 Keyed / DefInjected。

## 如何使用

**前提**：完成「机械加工」研究；研究「家政机器人」；有 150 钢 + 8 零部件；工作站接电。

1. 建筑师 → 机器人 → 保姆机器人工作站；放在电力覆盖范围内。
2. 建成后自动出现一台「保姆机器人 N」。
3. 打开 **设置 → 机器人**，按需要开关家务、调整充电/加燃料阈值、电池容量、工作半径或区域。
4. 选中机器人：
   - 三个快捷开关：扫地/清洁/搬运；
   - **暂停 / 继续**、**召回充电桩**、**前往指定位置**、**优先清理**、**改名**、**涂装**、**去充电**。
5. 电量低于阈值会自动回桩；0% 停机但不会死亡。
6. 机器人耐久为 0 会报废；殖民者会自动接「维修保姆机器人」工作（建造），也可以手动优先。维修会打断充电和家务，维修完成后机器人才会重新去充电。
7. 底部「机器人」→「工作管控」：左键降低优先级、右键提高优先级，0 为关闭；列头复选框可整列开关。这里的优先级会真正影响机器人先做哪项家务。
8. 底部「机器人」→「机器人状态」：查看所有机器人并跳转；工作站可定位/召回绑定机器人。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 机器人不干活 | 设置页对应家务关了 / 单机开关关了 / 暂停 / 电量为 0 / 附近有敌人 | 看设置页、Gizmo 与检查面板 |
| 不充电 | 充电桩没电/被拆/距离不可达 | 接电、重建或手动「去充电」 |
| 只扫地不清洁基地外 | 设置页或单机的「清洁」关了 | 打开「清洁」 |
| 不搬尸体 | 设计如此 | 尸体仍由殖民者搬运 |
| 不屠宰 | 没有屠宰台/没有屠宰账单 | 建屠宰台并添加屠宰工作 |
| 不给发电机加燃料 | 燃料高于阈值 / 没燃料 / 发电机没开自动加燃料 | 调低阈值、准备木柴/化合燃料 |
| 不给囚犯送餐 | 囚犯不饿 / 没食物 / 送餐开关关了 | 检查食物与设置 |
| 机器人不见了 | 被摧毁或停机 | 工作站可重装；停机需维修/拆解 |
| 建造菜单没有工作站 | 研究没完成 | 先研究「家政机器人」 |
| 机器人不掉耐久 | 日常工作本来就不掉耐久，只有受伤才掉 | 正常现象 |
