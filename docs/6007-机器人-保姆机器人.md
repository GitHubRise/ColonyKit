## 简介

保姆机器人（`CK_RobotNanny`）是 M6 智能机器人模块的首个落地型号。它是玩家阵营的机械族 Pawn，不吃饭、不睡觉、不社交，只消耗内置电量；会自动扫地、清洁和搬运，电量低时回充电桩。

它不是 Work 页里的殖民者：没有工作优先级，也不需要玩家逐项分配。选中后可用三个 Gizmo 分别开关家务。

## 所含功能

- 不吃饭、不睡觉、不社交、不生育的玩家机械族工人。
- 三项家务：扫地（家内）、清洁（家外）、搬运。
- 满电 12 小时、充电 4 小时、25% 自动回桩、0% 停机。
- 充电桩自动组装一台机器人；损毁后 1 天冷却重装。
- 充电功耗动态从 50W 切到 4000W。
- 中英文 Keyed / DefInjected。

## 如何使用

**前提**：完成「机械加工」研究；研究「家政机器人」；有 150 钢 + 8 零部件；工作站接电。

1. 建筑师 → 机器人 → 保姆机器人工作站；放在电力覆盖范围内。
2. 建成后自动出现一台「保姆机器人 N」。
3. 选中机器人：
   - **扫地**：清理家区域内的污渍；
   - **清洁**：清理家区域外的污渍；
   - **搬运**：把物品搬进库存区。
4. 电量低于 25% 会自动回桩；也可以点「去充电」。
5. 机器人损毁后，选中工作站等待冷却结束，点「组装保姆机器人」。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 机器人不干活 | 三项家务都关了 / 没有可达目标 / 电量为 0 | 看 Gizmo 与检查面板 |
| 不充电 | 充电桩没电/被拆/距离不可达 | 接电、重建或手动「去充电」 |
| 只扫地不清洁基地外 | 「清洁」开关关了 | 选中机器人打开「清洁」 |
| 不搬尸体 | 设计如此 | 尸体仍由殖民者搬运 |
| 机器人不见了 | 被摧毁或停机 | 工作站可重装；停机需后续救援/拆解 |
| 建造菜单没有工作站 | 研究没完成 | 先研究「家政机器人」 |
