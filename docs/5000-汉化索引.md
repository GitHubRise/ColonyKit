## 模块一句话

汉化模块分两层：

1. **开发者菜单汉化（0.0.2 已移植）**：把 Dev Mode 的 Debug 菜单/动作标签替换成中文，外置翻译表 + 可切换翻译方案。
2. **本 Mod 全文本本地化（规划）**：六个模块的 `Keyed` / `DefInjected`、术语表、`check-l10n`、中文排版。

> 编号说明：6000 是指定的智能机器人；汉化集合使用 5000。

## 0.0.2 已落地：开发者菜单汉化

| 项 | 内容 |
|---|---|
| 翻译表 | `Translations/DevMenuLabels.xml`（约 72 KB，来自 `sources/devmenu-zh`） |
| 替换点 | Harmony Postfix `LudeonTK.DebugActionNode.LabelNow`；Debug 窗口 tooltip Transpiler |
| 翻译方案 | 极简 / 常用 / 全量，可新建/删除/改名/全选/全不选/恢复默认，最多 10 个 |
| 设置入口 | 游戏选项 → Mod 设置 → 殖民地套件 → 常规设置 → 翻译方案 |
| 冲突处理 | 检测到原 `DevMenuChinese` 时两个补丁都运行；本模块仍按当前方案翻译全部 34 个菜单组，建议只保留一个 |
| 源码位置 | `Source/Modules/Localization/`、`Source/Settings/Pages/GeneralSettingsPage.cs`、`Dialog_LocalizationSchemes.cs` |

**使用**：

1. 打开开发者模式，进入游戏。
2. 选项 → Mod 设置 → 殖民地套件 → 常规设置：在「翻译方案」里确认开关并编辑方案。
3. 点「编辑翻译方案」选择要翻译的菜单；或直接用默认「全量」。
4. 重新打开 Debug 菜单；标签应显示中文。
5. 改 XML 后点「重新加载翻译表」，或重启游戏。

**限制**：只翻译开发者菜单/部分 tooltip，不改建筑、物品、研究、Gizmo 等游戏文本；这部分走各模块 `Languages/`。

## 覆盖范围（全 Mod 目标）

- 六个模块的 `Keyed` + `DefInjected`：建筑、研究、念头、提示、设置、拒绝原因、Alert、Gizmo、蓝图库、仓库 ITab、机器人状态。
- 语言：英文（基准）+ 简体中文；繁体中文可选。
- 定义：`Languages/English/`、`Languages/ChineseSimplified/`、`Languages/ChineseTraditional/`。
