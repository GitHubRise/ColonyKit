## 简介

战斗机器人可以 draft、装备武器/护甲、射击/近战；所有机器人都会遇到断电、EMP、0% 停机和受伤/损坏的问题。

## 描述

- 战斗机器人：draft 后指挥移动/射击/近战；可穿护甲；技能以射击/格斗为主。
- draft 中不自动充电；≤5% 强制解除 draft（6004）。
- 战斗机器人不自动防御/巡逻（首版只能手动 draft）。
- 断电：充电停止，电量继续掉；按 6004 处理。
- EMP：眩晕 + 额外掉电（可选，M6-7）；是否生效取决于 FleshType/Patch。
- 0%：停机 downed，不是死亡；搬到充电桩恢复。
- 受伤：HP 下降；不流血/无疼痛（架构待定）；维修规则 M6-8。
- 被毁：留残骸/直接消失待定；首版先按可修。

## 绘制调用逻辑图

```text
Draft（战斗机器人）
      ├─ 装备武器/护甲
      ├─ 指挥移动/射击/近战
      └─ 低电 ≤5% → 强制解除 draft → 充电/停机
                │
                ▼
故障：断电 / EMP / 受伤 / 0%
      ├─ 断电 → 停充，电量继续掉
      ├─ EMP → 眩晕 + 掉电（可选）
      ├─ 受伤 → HP 下降
      └─ 0% → downed → 搬运到桩 → 恢复
```

## 所含功能

- 战斗机器人 draft/装备/战斗。
- EMP/断电/0% 故障。
- 受伤/维修/残骸（待定）。
- 自动防御（待定）。
- 与 6004 停机恢复衔接。

## 如何使用

1. 选中战斗机器人点「征召」。
2. 装备武器/护甲，指挥战斗。
3. 低电会强制解除 draft；及时充电。
4. EMP/断电/受伤后按 6004 处理；维修规则见 M6-8。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 战斗机器人不打 | 没 draft/没武器/没电 | 检查状态与电量 |
| EMP 后不动 | 眩晕/掉电 | 等或搬去充电 |
| 受伤不会好 | 自修未实现/没充电 | 看 M6-8 规则 |
