## 简介

`ModLog` 从「统一前缀」升级成结构化日志：**级别 + 分类 + 去重 + 节流 + 最近日志缓冲**。`Diagnostics` 把版本、设置、各服务状态和最近日志写成 `Config/ModTemplate-diagnostics.txt`，玩家不用翻几万行 `Player.log`。

## 描述

- 级别：`Debug < Info < Warn < Error`，由 `LoggingSettings.logLevel` 控制（日志页「框架日志级别」下拉框）。
- 输出格式：`[前缀][分类] 消息`；Debug/Info 走 `Log.Message`，Warn 走 `Log.Warning`，Error 走 `Log.Error`。
- 分类：`Bootstrap`、`GameComponent`、`Settings`、`Menu`、`Build`、`TechTree`、`Diag`、`Selftest` 等，便于按功能筛。
- 去重：`Once(key, level, category, message)` 同一个 key 只输出一次。
- 节流：`Throttled(key, cooldownTicks, level, category, message)` 同一 key 在冷却内只输出一次。
- 最近日志：环形缓冲 50 条，诊断报告会带上级别、分类、tick 和截断后的消息。
- 重置：`ResetRuntimeState()` 清空去重/节流/最近日志；`DemoGameComponent.FinalizeInit` 在新游戏/读档时调用，同时清空 `NotificationService` 的节流表。
- 诊断：`Diagnostics.Dump()` 写文件并绕过级别过滤输出路径；报告包含版本/packageId、日志级别/前缀、三组设置、菜单/建造/通知/主按钮/研究树/计数、最近日志。
- 设置页「日志」新增「诊断」分区：输出诊断报告、清空日志去重/节流。
- 旧调用 `Message/Warning/Error(string)` 保留为 Core 分类的兼容包装，外部旧代码不用改。

## 绘制调用逻辑图

```text
业务代码
  ├─ ModLog.Info("Menu", "…")
  ├─ ModLog.Once("key", Warn, "Build", "…")
  └─ ModLog.Throttled("key", 300, Info, "GameComponent", "…")
        │
        ▼
  level < Level ? ── 是 → 丢弃
        │ 否
        ▼
  Once/Throttled：查表（lock）→ 未到点 → 丢弃
        │
        ▼
  WriteCore：拼 [前缀][分类] → Log.Message / Warning / Error
        └─ 追加到最近日志环形缓冲（50 条）

诊断:
  Diagnostics.Dump()
    ├─ BuildReport()：版本/设置/服务状态/最近日志
    ├─ File.WriteAllText(Config/ModTemplate-diagnostics.txt)
    └─ ModLog.Force("Diag", "diagnostics report written to …")

新游戏/读档:
  DemoGameComponent.FinalizeInit()
    ├─ ModLog.ResetRuntimeState()
    └─ NotificationService.ResetThrottle()
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `ModLog.Debug/Info/Warn/Error` | `static void (string category, string message)` | 按级别输出 |
| `ModLog.Error`（异常重载） | `static void Error(string category, string message, Exception exception)` | 附带堆栈 |
| `ModLog.Once` | `static void Once(string key, ModLogLevel level, string category, string message)` | 只输出一次 |
| `ModLog.Throttled` | `static void Throttled(string key, int cooldownTicks, ModLogLevel level, string category, string message)` | 冷却内只输出一次 |
| `ModLog.Force` | `static void Force(string category, string message)` | 绕过级别过滤 |
| `ModLog.ResetRuntimeState` | `static void ResetRuntimeState()` | 清空去重/节流/最近日志 |
| `ModLog.Level` / `Prefix` / `Recent` | 属性 | 当前级别、前缀、最近日志快照 |
| `ModLogEntry` | `readonly struct` | Level/Category/Message/Tick |
| `Diagnostics.Dump` | `static void Dump()` | 写报告 + 日志输出路径 |
| `Diagnostics.DumpToFile` | `static string DumpToFile()` | 写文件，失败返回 null |
| `Diagnostics.BuildReport` | `static string BuildReport()` | 生成报告文本 |
| `LoggingSettings.logLevel` | `ModLogLevel` | 框架日志级别（持久化） |
