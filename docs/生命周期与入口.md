## 简介

Mod Template 的入口只有两个：`ModTemplateMod`（`Mod` 子类，负责设置窗口与单例）和 `Bootstrap`（`[StaticConstructorOnStartup]`，负责 `PatchAll` 与依赖 Def 的初始化）。其余文件都是被它们调用的零件。

最重要的时序只有一句：**`Mod` 构造函数在 Def 解析之前，`Bootstrap` 在 Def/DefOf 就绪之后**。

## 描述

- `ModTemplateMod(ModContentPack content)`：给 `Instance` 赋值，提前触发一次 `GetSettings<ModTemplateSettings>()`，把设置读取错误暴露在启动阶段；这里**不能**读 `DefDatabase` / `DefOf`。
- `Bootstrap` 静态构造函数：
  - `new Harmony("local.modtemplate").PatchAll(typeof(Bootstrap).Assembly)`；
  - 读取 `ModTemplateDefOf.Default` 做一次自检日志；
  - 整个包在 `try/catch` 里，异常带 `[ModTemplate]` 前缀写入日志，不静默。
- 游戏内逻辑通过 `DemoGameComponent`（每存档）和 Harmony Postfix 接入，见对应文档。
- 设置窗口是懒加载：第一次 `DoSettingsWindowContents` 时才创建 `SettingsController`。
- `Settings` 属性在 `Instance` 赋值前返回 null，调用方必须判空。

## 绘制调用逻辑图

```text
Assembly.LoadFrom(ModTemplate.dll)
        │
        ▼
ModTemplateMod 构造函数（Def 尚未解析）
        ├─ Instance = this
        └─ GetSettings<ModTemplateSettings>()   // 只读设置
        │
        ▼
Defs XML 合并 → Patch → 反序列化 → DefOf 绑定
        │
        ▼
Bootstrap [StaticConstructorOnStartup]（Def 就绪，主线程）
        ├─ new Harmony("local.modtemplate").PatchAll(...)
        └─ ModLog.Message("loaded; greeting=…, note=…")
        │
        ▼
新游戏 / 读档
        ├─ DemoGameComponent 构造 / ExposeData
        └─ Harmony Postfix 开始处理 Pawn.SpawnSetup
        │
        ▼
每 tick → DemoGameComponent.GameComponentTick()
        │
        ▼
首次打开设置 → new SettingsController(Settings) → Draw
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `ModTemplateMod` | `ModTemplateMod(ModContentPack content)` | Mod 入口，设置单例 |
| `ModTemplateMod.Instance` | `static ModTemplateMod Instance { get; }` | 全局单例 |
| `ModTemplateMod.Settings` | `static ModTemplateSettings Settings { get; }` | 设置入口（可能为 null） |
| `ModTemplateMod.SettingsCategory` | `override string SettingsCategory()` | 设置页分类名 |
| `ModTemplateMod.DoSettingsWindowContents` | `override void DoSettingsWindowContents(Rect)` | 懒建控制器并绘制 |
| `Bootstrap` | `static Bootstrap()` | `PatchAll` + Def 自检 |
| `ModLog.Message/Warning/Error` | `static void (string)` | 统一前缀日志 |

- Mod 入口与全局单例；
- 设置读取的启动期自检；
- Def 就绪后的统一初始化点；
- Harmony 补丁安装；
- 懒加载设置窗口；
- 统一日志出口。
