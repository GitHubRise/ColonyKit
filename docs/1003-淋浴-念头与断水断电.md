## 简介

卫生值高低、洗澡水温、今天是否洗过，通过 `ThoughtDef` / `ThoughtWorker` 影响殖民者心情；断水、断电、淋浴器被占用时给出可读提示。

## 描述

- 至少四类念头：洁净、肮脏、冷水澡、今天洗过澡。
- 念头阈值/心情值/持续时间 M2-4 定稿，统一进 `docs/balance.md`（待建）。
- 断水/断电/占用由 Alert 提示，不自动修复；断水根因在水网。
- 机器人没有心情，不参与这些念头。
- Alert 点击可跳转到出问题的淋浴器/水网。

## 绘制调用逻辑图

```text
Need_Hygiene 当前值
      │
      ├─ 低于肮脏阈值 → Thought_Dirty（-心情）
      ├─ 洗澡完成（热水）→ Thought_Clean / Thought_ShoweredToday（+心情）
      ├─ 洗澡完成（冷水）→ Thought_ColdShower（-心情）
      └─ 长时间未洗 → 可选额外念头（M2-4）

水网/电力状态
      ├─ 无水 → Alert_WaterOutage
      ├─ 无电 → Alert_PowerOutage（热水器）
      └─ 淋浴器被占 → 排队/提示
```

## 所含功能

- 洁净/肮脏/冷水澡/今天洗过澡念头。
- 断水、断电、占用 Alert。
- 念头阈值与持续时间配置。
- 与需求条/Gizmo 的联动提示。

## 如何使用

**前提**：已建淋浴器/水网/热水器。

1. 选中殖民者看需求条与念头列表。
2. 卫生值低 → 出现「肮脏」；洗澡后转为「洁净」/「今天洗过」。
3. 洗冷水澡 → 出现「冷水澡」debuff。
4. 断水/断电时看右侧 Alert，点击跳转到问题建筑。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 洗澡后心情没变 | 念头有延迟/被其他念头覆盖 | 看念头剩余时间 |
| 一直提示断水 | 水箱空/泵没电/管道断 | 修水网，见 M1 |
| 有人洗冷水澡 | 热水器没开/没电/管网未加热 | 检查热水器与电网 |
