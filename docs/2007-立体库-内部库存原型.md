## 简介

`CK_VerticalWarehouse` 是一个 3×3 的室内仓库建筑：物品存放在建筑内部的 `ThingOwner` 里，不占地图格；选中建筑后可在检视面板查看库存并逐堆取出，或用 Gizmo 收集附近物品/全部取出。

它是 M3 的**最小可运行原型**，用来验证「内部库存 + 存读档 + 电力 + UI」这条链路；不是最终版自动仓库。

## 描述

- 建筑：3×3，`CK_VerticalWarehouse`，建在 Furniture 分类，无需研究。
- 容量：**24 堆**；每堆仍受当前 `ThingDef.stackLimit` 限制（堆叠规则默认 10×）。
- 电力：250W；未通电时不能存入/取出。
- 库存：`ThingOwner<Thing>`，随建筑存读档；拆除时把库存掉到建筑旁。
- UI：
  - 检视面板 `ITab_VerticalWarehouse`：容量、件数、逐堆「取出」。
  - Gizmo「收集附近物品」：把周围 8 格内未禁用的物品直接收入（原型调试，不是搬运 Job）。
  - Gizmo「取出全部」：把库内物品放到建筑旁。
- 当前不处理：过滤/优先级、入库/出库 Job、原版账单、温度/腐烂、T2/T3 升级、Stack XXL 重量合并。

## 绘制调用逻辑图

```text
建造 CK_VerticalWarehouse（Furniture）
  └─ Building_VerticalWarehouse : Building, IThingHolder
        ├─ Container = ThingOwner<Thing>(this)
        ├─ ExposeData → Scribe_Deep(innerContainer, owner=this)
        ├─ HasPower ← CompPowerTrader.PowerOn
        └─ MaxStacks = 24

选中建筑
  ├─ ITab_VerticalWarehouse.FillTab
  │     ├─ 显示 UsedStacks / MaxStacks / UsedItems
  │     ├─ 未通电提示
  │     └─ 逐堆「取出」→ TryWithdraw
  └─ GetGizmos
        ├─ 收集附近物品 → CollectNearby(8) → TryStore
        └─ 取出全部 → WithdrawAll → GenPlace.TryPlaceThing

拆除
  └─ Destroy → WithdrawAll → base.Destroy
```

## 所含功能

- 3×3 内部仓库建筑。
- 24 堆容量。
- 250W 电力门控。
- 检视面板逐堆取出。
- 收集附近/全部取出 Gizmo。
- 存读档、拆除掉落。

## 如何使用

1. 进游戏，在 **Furniture**（家具）分类找到「立体库」，建一个 3×3。
2. 接电；未通电时面板会提示，且不能存取。
3. 选中建筑：
   - 右侧检视面板看「库存 x/24 堆，共 y 件」；
   - 点「收集附近物品」把周围 8 格物品收进去（原型调试）；
   - 点「取出全部」把物品放到建筑旁。
4. 检视面板里每一堆有「取出」按钮。
5. 拆除建筑时，库内物品会先掉到旁边。

## 常见问题

**Q：为什么小人不会自动把货送进去？**  
A：当前是原型，只有 Gizmo 直接收集；自动入库/出库 Job 是 M3-2/M3-3。

**Q：为什么只能存 24 堆？**  
A：原型固定 24 堆（T1 容量）；T2/T3 研究升级还没接。

**Q：断电后库内物品会丢吗？**  
A：不会；只是不能存取。

**Q：能过滤只收某种物品吗？**  
A：还不能；过滤/优先级是 M3-4/M3-5。

**Q：和 Stack XXL 一起用？**  
A：堆叠规则检测到 Stack XXL 会让位；仓库容量按「堆」计算，不按重量。

**Q：拆除时物品去哪？**  
A：先 `WithdrawAll` 放到建筑旁，再拆除。
