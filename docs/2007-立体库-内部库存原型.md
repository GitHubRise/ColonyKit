## 简介

`CK_VerticalWarehouse` 是一个 **2×2** 的室内仓库建筑：物品存放在建筑内部的 `WarehouseThingOwner` 里，不占地图格；选中建筑后可在检视面板查看库存并逐堆取出，或用 Gizmo 收集附近物品/全部取出。当前是 0.0.2 的可用版本，不是最终自动仓库。

## 描述

### 建筑与解锁

- 2×2，`Furniture`（家具）分类，不可旋转；**二级立体仓库技术**解锁。
- 成本 150 钢 + 8 零部件；400 HP / 60 质量 / 3000 工作量；美观 -10、可燃性 0。
- `CompPowerTrader` 250W；`CompTempControl` 默认目标 4°C；`tickerType=Rare`；`drawGUIOverlay=true`。

### 内部库存

- 容器：`WarehouseThingOwner : ThingOwner<Thing>`；不在地图 `ListerThings` 中，不占地图格。
- 容量：默认 **12 堆**，设置页 1–200（`MaxStacks` 即时读取，对已建/新建都生效）；调低不会丢物品。
- 每堆上限：全局 `ThingDef.stackLimit` × `EffectiveMultiplier`（二级 ×3、三级 ×6；模块关闭/Stack XXL 时 ×1）；只有 `StorageStackRules.CanMultiply` 的物品参与。
- 合并：`TryAdd` 先并进未满的同类堆，再开新堆，最多 `MaxStacks` 堆；库内堆可超过全局上限，但普通地图堆本身 ≤ 全局上限。
- 存档：`ExposeData` 用 `Scribe_Deep` 保存 `innerContainer`、`storeSettings` 和 `settingsVersion`；旧版普通 `ThingOwner` 读档后原地升级为 `WarehouseThingOwner`，已有堆不截断。

### 过滤/优先级

- 实现 `IStoreSettingsParent`，原版 **Storage** 页自动出现；`storeSettings.Priority` 默认 **Normal**。
- 默认过滤：Foods 分类、草药、干草、木头、植物类、麦芽；显式禁止腐烂；`Accepts` 还拒绝尸体/非物品/最小化建筑。
- 过滤影响自动入库、履带送入和「收集附近物品」；不会自动清出已存的不合格物品。
- 没有「禁止入库」Gizmo/禁用清单；用过滤/优先级控制。

### 温控

- 默认目标 **4°C**；未完成三级时 `TickRare` 每 250 tick 强制回 4°C；完成三级后目标 clamp 到 **-20～30°C**。
- `energyPerSecond=-21`：只制冷，不加热；室温高于目标时降温，低于目标时不变。
- 只对**封闭且屋顶达标**的房间生效；`FindRoom` 先取自身房间，取不到再扫 8 邻格，选最大且非室外房间；露天/漏顶不制冷。
- 断电只停温控，库存/存取/取出仍可用。
- 建筑圆环下方实时温度浮字：`DrawGUIOverlay`，`-0.27` 格偏移；常规/近景常驻，拉远后仅在选中时显示；≤0°C 蓝、≥25°C 橙、其余冰白；格式 `F1`。

### UI

- 检视面板 `ITab_VerticalWarehouse`（360×460）：库存 x/N 堆、y 件；库内倍率；未通电提示；检索框 + 滚动列表 + 逐堆「取出」（每点取一个全局上限块）。
- 原版 **Storage** 页：过滤/优先级；由 `inspectorTabs` 挂 `RimWorld.ITab_Storage`。
- 底部主菜单 **立体库**（`MainTabWindow_StorageManagement`，760×620）：检索仓库/物品，显示位置、堆数/件数、通电状态，选中并跳转。
- Gizmo：
  - 「收集附近物品」：8 格内未禁用、未持有的物品直接 `TryStore`；返回值/消息按成功**堆数**计（文案写「件」）。
  - 「取出全部」：循环 `TryWithdraw` 到空或失败。
- 资源列表：`Patch_ResourceCounter` 把库内 `CountAsResource`、未腐烂、未雾藏物品计入底部资源条。

### 自动搬运

- 入库：`WorkGiver_HaulToWarehouse`（Hauling，priority 14）+ 原版 `HaulToContainer`；普通库存区能放且优先级不低于仓库时让位。
- 出库：`WorkGiver_WithdrawFromWarehouse`（Hauling，priority 16）+ `CK_WithdrawFromWarehouse`；只有存在更高优先级目标库存格时才搬，按全局上限分块。
- 详细见 2002/2003。

### 拆除

- `Destroy` 前 `WithdrawAll`：按全局上限分块放到 `InteractionCell`，失败放附近；落点失败会回滚并停止。
- 若停止后仍有库存，`base.Destroy` 可能让剩余物品消失；拆前建议先「取出全部」。

## 绘制调用逻辑图

```text
建造 CK_VerticalWarehouse（Furniture，T2）
  └─ Building_VerticalWarehouse : Building, IThingHolder, IStoreSettingsParent
        ├─ Container = WarehouseThingOwner(this)
        ├─ storeSettings = RimWorld.StorageSettings(this)（默认 Normal + 默认过滤）
        ├─ ExposeData → innerContainer / storeSettings / settingsVersion
        ├─ HasPower ← CompPowerTrader.PowerOn
        └─ MaxStacks ← 设置页容量（默认 12）

选中
  ├─ ITab_VerticalWarehouse
  │     ├─ UsedStacks / MaxStacks / UsedItems
  │     ├─ EffectiveMultiplier（×3/×6）
  │     ├─ 未通电提示
  │     └─ 逐堆「取出」→ TryWithdraw → 全局上限块
  ├─ ITab_Storage
  │     ├─ 优先级下拉
  │     └─ ThingFilterUI → storeSettings.filter
  └─ GetGizmos
        ├─ 收集附近物品 → CollectNearby(8) → TryStore
        └─ 取出全部 → WithdrawAll

每 250 tick
  └─ TickRare
        ├─ 无电 → 停温控
        ├─ FindRoom → 无室内房间 → 停温控
        ├─ 目标温度（T3 前 4；T3 后 -20..30）
        └─ room.Temperature += ControlTemperatureTempChange(energy=-21*4.166)

浮字
  └─ DrawGUIOverlay
        ├─ 温度 = CurrentRoomTemperature()（室内房间温度 / 室外温度）
        ├─ 缩放 > Middle 且未选中 → 不画
        └─ 圆环下方 -0.27 格，描边 + 颜色
```

## 所含功能

- 2×2 内部仓库、T2 解锁。
- 默认 12 堆，设置页 1–200。
- 过滤/优先级（原版 Storage 页）。
- 250W 制冷，T3 目标 -20～30°C。
- 实时温度浮字、资源列表、管理页。
- 自动入库/出库（条件见 2002/2003）。
- 收集附近/全部取出、拆除前取出。

## 如何使用

1. 完成二级研究，在 **Furniture** 建 2×2 立体库。
2. 接电（只为制冷；不接电也能存取）。
3. 选中建筑：
   - 检视面板看库存/倍率/温度，逐堆取出；
   - **Storage** 页设过滤/优先级；
   - 温度 Gizmo 调目标；
   - 「收集附近物品」「取出全部」。
4. 底部 **立体库** 管理页检索/跳转。
5. 自动入库/出库按 2002/2003 的优先级规则工作。

## 常见问题

**Q：为什么小人不会自动把货送进去？**  
A：会，但只在普通库存区放不下/没有库存区，或仓库优先级高于库存区时；仓库默认 **Normal**。

**Q：库内物品会自动出去吗？**  
A：会，但目标库存区优先级必须**高于**仓库且能放下；否则用检视面板手动取出。

**Q：容量能改吗？**  
A：能。**Mod 设置 → 立体库 → 立体库容量** 1–200（默认 12）；对已建/新建立即生效，调低不丢物品。

**Q：断电后库内物品会丢吗？**  
A：不会；存取/取出不依赖电，断电只停制冷。

**Q：为什么 28°C 降不到 4°C？**  
A：检查是否通电、房间是否封闭/有屋顶、目标是否高于室温（本建筑只制冷）。0.0.2 曾把 `energyPerSecond` 写成正数导致只加热，已在 2026-10-26 修正为 `-21`。

**Q：温度浮字为什么拉远就没了？**  
A：缩放大于 `Middle` 且未选中时隐藏，避免小图上文字互相压住；选中后会显示。

**Q：和 Stack XXL 一起用？**  
A：检测到 Stack XXL 后全局规则让位，库内倍率按 1 处理；容量按「堆」不按重量。

**Q：拆除时物品去哪？**  
A：先 `WithdrawAll` 放到交互格/附近；落点失败会回滚并停止，剩余可能随建筑消失。拆前先「取出全部」。
