## 简介

`CK_VerticalWarehouse` 是一个 3×3 的室内仓库建筑：物品存放在建筑内部的 `ThingOwner` 里，不占地图格；选中建筑后可在检视面板查看库存并逐堆取出，或用 Gizmo 收集附近物品/全部取出。

它是 M3 的**最小可运行原型**，用来验证「内部库存 + 存读档 + 电力 + UI」这条链路；不是最终版自动仓库。

## 描述

- 建筑：3×3，`CK_VerticalWarehouse`，建在 Furniture 分类，无需研究。
- 四向接口：北/东/南/西各有一个外侧端口；自动入/出库必须至少接一条 1×1/2×2 履带，端口格由履带占用。
- 仓库互联：8 向相邻的立体库组成一张网络；**只要网络中任意一台接了履带，全网络都能自动入/出库**。
- 无履带网络时：建筑上方每 30 tick 闪烁一次红色履带警告图标（类似断电提示），检视面板同时提示。
- 容量：**24 堆**；每堆仍受当前 `ThingDef.stackLimit` 限制（堆叠规则默认 10×）。
- 电力：250W；未通电时不能存入/取出。
- 温控：`CompTempControl`，默认 **4°C**，像原版空调一样用 Gizmo 调温（±10/±1/重置），按房间温度工作。
- 库存：`ThingOwner<Thing>`，随建筑存读档；拆除时把库存掉到建筑旁/履带端口。
- 默认过滤：**不允许腐烂物品、尸体、堆块**；可在原版 Storage 页重新打开。
- 研究页：底部研究菜单新增 **立体库** 页签和「高密度仓储」项目（Electricity 前置；第一代仓库不强制研究）。
- UI：
  - 检视面板 `ITab_VerticalWarehouse`：容量、件数、**检索框 + 滚动条**、逐堆「取出」。
  - 原版 **Storage** 页 `ITab_Storage`：过滤/优先级/搜索；由建筑实现 `IStoreSettingsParent` 后自动出现。
  - 底部主菜单新增「立体库」管理标签页：列出本图全部立体库，支持按仓库/物品检索、选中跳转。
  - Gizmo「自动输出到履带」：默认开启，每 250 tick 把库内第一堆物品放到已连接履带端口；可关闭。
  - Gizmo「收集附近物品」：把周围 8 格内未禁用的物品直接收入（原型调试，不是搬运 Job）。
  - Gizmo「取出全部」：把库内物品放到建筑旁或已连接的履带端口。
- 原版资源读条：`ResourceCounter.UpdateResourceCounts` Postfix 把库内 `CountAsResource` 物品计入底部资源列表。
- 当前不处理：原版账单直接取料、T2/T3 升级、Stack XXL 重量合并、腐烂策略。

## 绘制调用逻辑图

```text
建造 CK_VerticalWarehouse（Furniture）
  └─ Building_VerticalWarehouse : Building, IThingHolder, IStoreSettingsParent
        ├─ Container = ThingOwner<Thing>(this)
        ├─ storeSettings = RimWorld.StorageSettings(this)（filter 默认允许全部）
        ├─ ExposeData → Scribe_Deep(innerContainer, owner=this)
        ├─ ExposeData → Scribe_Deep(storeSettings)
        ├─ HasPower ← CompPowerTrader.PowerOn
        └─ MaxStacks = 24

选中建筑
  ├─ ITab_VerticalWarehouse.FillTab
  │     ├─ 显示 UsedStacks / MaxStacks / UsedItems
  │     ├─ 未通电提示
  │     └─ 逐堆「取出」→ TryWithdraw
  ├─ ITab_Storage.FillTab（原版）
  │     ├─ 优先级下拉
  │     └─ ThingFilterUI → storeSettings.filter
  └─ GetGizmos
        ├─ 收集附近物品 → CollectNearby(8) → TryStore → Accepts → filter.AllowedToAccept
        └─ 取出全部 → WithdrawAll → GenPlace.TryPlaceThing

拆除
  └─ Destroy → WithdrawAll → base.Destroy

自动入库（库存区满/无库存区时）
  └─ WorkGiver_HaulToWarehouse → JobDefOf.HaulToContainer
        └─ JobDriver_HaulToContainer → ThingOwner

自动出库（库存区优先级更高时）
  └─ WorkGiver_WithdrawFromWarehouse → CK_WithdrawFromWarehouse
        └─ JobDriver_WithdrawFromWarehouse
              ├─ 预约仓库 + 目标格
              ├─ Container.Take 一整堆
              └─ 搬到目标库存格并放下
```

## 所含功能

- 3×3 内部仓库建筑。
- 24 堆容量。
- 250W 电力门控。
- 检视面板逐堆取出。
- 原版 Storage 页过滤/优先级。
- 自动入库（库存区满/无库存区时）。
- 自动出库（库存区优先级更高时）。
- 收集附近/全部取出 Gizmo。
- 存读档、拆除掉落。

## 如何使用

1. 进游戏，在 **Furniture**（家具）分类找到「立体库」，建一个 3×3。
2. 接电；未通电时面板会提示，且不能存取。
3. 选中建筑：
   - 右侧检视面板看「库存 x/24 堆，共 y 件」；
   - **Storage** 页设置过滤/优先级；
   - 点「收集附近物品」把周围 8 格物品收进去（原型调试）；
   - 点「取出全部」把物品放到建筑旁。
4. 检视面板里每一堆有「取出」按钮。
5. 拆除建筑时，库内物品会先掉到旁边。

## 常见问题

**Q：为什么小人不会自动把货送进去？**  
A：会，但只在普通库存区放不下/没有库存区，或仓库优先级高于库存区时；立体库默认 **Normal** 优先级。想强制入库可把仓库优先级调高或先把库存区填满。

**Q：库内物品会自动出去吗？**  
A：会。把库存区优先级调到高于仓库（仓库默认 **Normal**），搬运工会自动把物品从库里送到库存区。账单取料仍未接。

**Q：为什么只能存 24 堆？**  
A：原型固定 24 堆（T1 容量）；T2/T3 研究升级还没接。

**Q：断电后库内物品会丢吗？**  
A：不会；只是不能存取。

**Q：能过滤只收某种物品吗？**  
A：可以。选中建筑后打开原版 **Storage** 页，设置过滤和优先级；`Accepts` 会按过滤器拒收。自动搬运 Job 还没有，所以目前只影响 Gizmo 收集和后续入库。

**Q：和 Stack XXL 一起用？**  
A：堆叠规则检测到 Stack XXL 会让位；仓库容量按「堆」计算，不按重量。

**Q：拆除时物品去哪？**  
A：先 `WithdrawAll` 放到建筑旁，再拆除。
