# 设置语言切换

> 状态：✅ 已在实机验证（英文游戏下切到简中设置界面）　适用：Mod Template 0.0.2（RimWorld 1.6.4871）　最后更新：2026-10-25
> 本文件说明如何只让本 Mod 的设置窗口在中英文之间切换，而不改游戏全局语言。

## 简介

常规页「语言」提供 `自动 / English / 简体中文`。选择后只影响本 Mod 的设置窗口：页签、分区、控件标签、提示、诊断按钮等立即切换；游戏本体和其他 Mod 仍跟随游戏语言。

## 描述

- 模式：`ModLanguage.Auto`（跟随游戏）/ `English` / `ChineseSimplified`，持久化在 `GeneralSettings.language`。
- 翻译入口：`ModLoc.Translate(key, args)`；设置界面统一用扩展方法 `"Key".Loc()` 调用。
- 字典：首次使用时从 `Languages/English/Keyed/ModTemplate.xml` 与 `Languages/ChineseSimplified/Keyed/ModTemplate.xml` 读取，按 XML 元素名建表。
- 回退：所选语言缺键 → 回退游戏 `Translate`；key 为空 → 空串。
- 切换时机：下拉/循环/打勾控件选中后写 `data.language`，下一帧所有 `.Loc()` 立即使用新语言。
- 不覆盖：`DefInjected`（Def 的 label/description）、右键菜单/通知/研究树等其他 UI 仍由游戏语言决定；`Dialog_ModSettings` 自带的 Close 按钮也属于原版 UI。
- 语言选项本身也走 `SettingsWidgets`，所以会跟随当前选项控件模式（下拉/循环/打勾）。

## 绘制调用逻辑图

```text
设置页控件
  └─ "ModTemplate.Xxx".Loc(args)
        └─ ModLoc.Translate(key, args)
              ├─ language == Auto → key.Translate(args)        // 游戏语言
              ├─ language == English/ChineseSimplified
              │     ├─ EnsureLoaded()：读取两个 Keyed XML
              │     ├─ dictionary.TryGetValue(key)
              │     │     ├─ 命中 → string.Format(args)
              │     │     └─ 缺键 → key.Translate(args)        // 回退
              │     └─ 返回
              └─ 空 key → ""

常规页选择语言
  └─ data.language = ...
        └─ 下一帧所有 .Loc() 使用新字典
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `ModLanguage` | `enum { Auto, English, ChineseSimplified }` | 设置语言 |
| `GeneralSettings.language` | `ModLanguage` | 持久化字段（key `language`） |
| `ModLoc.Translate` | `static string Translate(string key, params object[] args)` | 按模式取翻译 |
| `ModLocExtensions.Loc` | `static string Loc(this string key, params object[] args)` | 设置界面扩展入口 |
| `GeneralSettingsPage` | `DoContents` | 「语言」下拉/循环/打勾入口 |
| `GeneralSettings.Validate` | `bool Validate()` | 非法枚举回退 Auto |

## 所含功能

- 本 Mod 设置窗口的中英文切换；
- `Auto` 跟随游戏；
- Keyed 字典运行时加载；
- 缺键回退；
- 与三种选项控件模式兼容；
- 不修改游戏全局语言；
- 明确不覆盖 DefInjected/原版 Close 按钮。
