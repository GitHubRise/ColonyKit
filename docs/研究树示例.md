## 简介

不新增底部菜单按钮。原版底部仍只有 **Research**；进入原版 Research 窗口后，会多出一个 `MT_ResearchTab`「示例研究」页签，用 15 个 `ResearchProjectDef` 覆盖 6 类最小测试项。

## 描述

页签 `MT_ResearchTab`（label `示例研究 / Demo research`）下的测试矩阵：

| # | 测试项 | defName / 前置 |
|---|---|---|
| 1 | 原版研究作为前置 | `MT_Research_VanillaPrereq` → `Electricity` |
| 2 | 独立研究（无前置） | `MT_Research_Independent` |
| 3 | 一条线晋级 | `Linear_1` → `Linear_2` → `Linear_3` |
| 4 | 一条线晋级后分叉 | `Branch_1` → `Branch_2` → `Branch_3` → `Branch_Left` / `Branch_Right` |
| 5 | 分叉后一个带额外前置、一个不带 | `Fork_1` → `Fork_2` → `Fork_WithExtra`（+ `Independent`）/ `Fork_WithoutExtra` |
| 6 | 生产物品的研究 | `MT_Research_Production` → 解锁 `MT_Make_ComponentIndustrial` |

补充：

- 所有示例都在 `MT_ResearchTab`，`researchViewX/Y` 已排布，原版页签内能看到节点。
- **第 1 项是跨页签前置**：`Electricity` 在 `Main` 页签；原版 Research 面板会显示前置条件，但 `TechTreeWindow` 的连线只画同一页签内的前置，所以树里该项显示为根 + Tooltip。
- 生产研究 `MT_Research_Production` 通过 `RecipeDef.researchPrerequisite` 解锁配方；配方在 `TableMachining` 制作 `ComponentIndustrial`（10 钢 → 1 组件）。
- 访问：原版底部 **Research** → 「示例研究」页签；独立 `TechTreeWindow` 仍可从设置「关于」或 `-modtemplate-techtree` 打开，用于看同页签的前置分层。

## 绘制调用逻辑图

```text
原版 Research 窗口
  └─ ResearchTabDef MT_ResearchTab（新增页签）
        ├─ MT_Research_VanillaPrereq  ← Electricity（跨 tab 前置）
        ├─ MT_Research_Independent
        ├─ Linear_1 → Linear_2 → Linear_3
        ├─ Branch_1 → Branch_2 → Branch_3 → Branch_Left / Branch_Right
        ├─ Fork_1 → Fork_2 → Fork_WithExtra（+ Independent）
        │                    └→ Fork_WithoutExtra
        └─ Production（前置 Linear_2）
              └─ Recipe MT_Make_ComponentIndustrial
                    └─ researchPrerequisite = Production
```

## 函数清单

| 类型 / 字段 | 作用 |
|---|---|
| `ResearchTabDef MT_ResearchTab` | 原版 Research 窗口的新页签 |
| `ResearchProjectDef.prerequisites` | 线/分叉/跨页签前置 |
| `ResearchProjectDef.tab` | 全部指向 `MT_ResearchTab` |
| `ResearchProjectDef.researchViewX/Y` | 页签内节点坐标 |
| `RecipeDef.researchPrerequisite` | 生产研究解锁配方 |
| `RecipeDef.products` | `<ComponentIndustrial>1</ComponentIndustrial>` |
| `RecipeDef.recipeUsers` | `TableMachining` |
