## 简介

`BuildControlService` 把「能不能在这里建造」和「放一个蓝图」收成两个入口：`CanPlace` 走原版校验并叠加自定义规则，`PlaceBlueprint` 校验通过后调用原版 `PlaceBlueprintForBuild`。规则通过 Harmony Postfix 挂在真正的校验方法上，不替换原逻辑。

## 描述

- `CanPlace(def, center, map, rot, stuff)`：调用 `GenConstruct.CanPlaceBlueprintAt`；规则由 Postfix 追加。
- 规则：`RegisterRule(id, allow, reason)`；`allow` 返回 false 时用 `reason` 作为拒绝原因；同 Id 覆盖。
- Patch：打在 `GenConstruct.CanPlaceBlueprintAt_NewTemp`（外层 `CanPlaceBlueprintAt` 会委托到它），只改 `AcceptanceReport`。
- `PlaceBlueprint(...)`：先 `CanPlace`，失败发 `RejectInput` 消息并返回 null；成功调 `GenConstruct.PlaceBlueprintForBuild(..., Faction.OfPlayer, stuff)`。
- 规则异常隔离：`allow`/`reason` 抛异常记 `Error`，按「跳过该规则」处理，不炸整个放置流程。
- 演示：右键殖民者「在附近建造演示墙」→ 在脚边一格放钢墙蓝图；格子越界或校验失败会发通知。

## 绘制调用逻辑图

```text
BuildControlService.PlaceBlueprint(def, center, map, rot, stuff)
        │
        ▼
GenConstruct.CanPlaceBlueprintAt(...)
        └─ CanPlaceBlueprintAt_NewTemp(...)
              ├─ 原版校验（地形/占用/研究/材料/水域…）
              └─ Postfix → BuildControlService.ApplyRules(...)
                    ├─ current.Accepted == false → 原结果
                    └─ foreach rule
                          ├─ allow == true → 下一条
                          └─ false → new AcceptanceReport(reason)
        │
        ├─ 拒绝 → NotificationService.Message(reason, RejectInput) → null
        └─ 通过 → GenConstruct.PlaceBlueprintForBuild(def, center, map, rot, Faction.OfPlayer, stuff)
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `BuildControlService.CanPlace` | `static AcceptanceReport CanPlace(BuildableDef def, IntVec3 center, Map map, Rot4 rot, ThingDef stuff = null)` | 原版校验 + 规则 |
| `BuildControlService.PlaceBlueprint` | `static Blueprint_Build PlaceBlueprint(BuildableDef def, IntVec3 center, Map map, Rot4 rot, ThingDef stuff = null)` | 校验并放玩家蓝图 |
| `BuildControlService.RegisterRule` | `static void RegisterRule(string id, Func<BuildableDef, IntVec3, Map, Rot4, ThingDef, bool> allow, Func<... , string> reason = null)` | 注册规则 |
| `BuildControlService.UnregisterRule` | `static bool UnregisterRule(string id)` | 删除规则 |
| `BuildControlService.ClearRules` | `static void ClearRules()` | 清空规则 |
| `BuildControlService.RuleCount` | `static int RuleCount { get; }` | 规则数量 |
| `Patch_GenConstruct_CanPlaceBlueprintAt` | `[HarmonyPostfix]` on `CanPlaceBlueprintAt_NewTemp` | 把规则叠加到 `AcceptanceReport` |
| `BuildRule` | `sealed class` | `Id` / `Allow` / `Reason` |

## 所含功能

- 原版放置校验的统一入口；
- 自定义建造规则（多规则、可解释拒绝原因）；
- 规则异常隔离；
- 程序化放置玩家蓝图；
- 失败通知而不是抛异常；
- 右键菜单演示项；
- 不改变原版施工/材料逻辑。
