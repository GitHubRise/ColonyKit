## 简介

取水点是水网里的一个公共水龙头：自带 150 L 小水箱，殖民者可以在这里喝水、洗手，也能用水桶接水带走。检视页可以设置「取水次数」，小人会自动拿水桶去同网水井打水倒回来；同网有工作的水泵时打水快，没有水泵只能手动慢慢打。

## 描述

- 建筑 `CK_WaterPoint`：1×1，钢铁 50 + 零部件 1，800 工作，研究「卫生设施」解锁，建造菜单「卫生」页。
- 组件：`CompPipe`（Water）+ `CompWaterStorage`（150 L）。它本身是水网里的一个水箱，水泵会像灌普通水箱一样把它灌满。
- 饮水/洗手：`Building_WaterPoint : Building_Basin`，复用 `CK_DrinkFromBasin` / `CK_WashHands`；`TryUseWater` 只取常温水，不消耗热水。喝水 0.04 L/tick、洗手 0.04 L/tick（4 L/次）。
- 水桶 `CK_WaterBucket`：普通物品，容量 60 L，钢铁 20 + 500 工作，手工点制作；可放在物品栏或地上。
- 打水：右键水井、取水点、水箱都能「用水桶打水 / 用脸盆打水」；水井抽地下水，不消耗水箱；取水点/水箱从同网 `PullWater`。
- 打水速度：同网有工作的水泵（`CompWaterPumpingStation.WorkingNow`）时 0.30 L/tick；没有水泵时水井 0.05、取水点/水箱 0.12 L/tick。60 L 水桶分别约 200 / 1200 / 500 tick。
- 水质：水井按未处理；取水点/水箱按 `PlumbingNet.PullWater` 给出的水质（有净水设备时为已处理）；混水按最脏的一档记录在 `CompBasinWater.Contamination`，喝完后走 `SanitationUtil.ContaminationCheckDrinking`。
- 随身喝水：`JobGiver_DrinkWater` 先看物品栏里有没有带水的容器；有就派 `CK_DrinkFromCarried`，不用跑回洗手池。每 tick 消耗 0.02 L、恢复 0.006 口渴。
- 取水次数：`targetDraws` / `deliveredDraws`，上限 99；检视页 `ITab_WaterPoint` 提供 -1/+1/+5/清空，Gizmo 的滑条也能设置。达到次数后自动停止，水箱满了会暂停，等水被用掉再继续。
- 自动派活：`WorkGiver_FillWaterPoint`（Hauling，优先级 35）在满足「有未完成次数 + 水箱空间 ≥ 20 L + 同网有可达水井 + 能找到没满的水桶」时派 `CK_FillWaterPoint`。
- 取水 Job：捡水桶（如果在地上）→ 去水井打满 → 回取水点倒进水箱 → `deliveredDraws++`。一次取水 = 一桶（最多 60 L）；倒进去不足 20 L 时不算一次，剩下的水留在桶里。
- 倒水复用：水桶可以右键水盆「倒入水盆」（水质按桶里的算），也可以右键水箱「倒入水箱」。

## 绘制调用逻辑图

```text
设置取水次数（ITab / Gizmo 滑条）
      │ targetDraws > deliveredDraws
      ▼
WorkGiver_FillWaterPoint（Hauling）
      ├─ 取水点：有未完成次数、空间 ≥ 20 L、未被禁用
      ├─ 同网水井：FindWellForDraw() 最近且可达
      └─ 水桶：背包优先，其次地上没满的水桶
      │
      ▼
CK_FillWaterPoint
      ├─ 地上捡水桶（背包已有则跳过）
      ├─ 去水井，按 FillRate(fromWell, pumped) 打满
      │    有水泵 0.30 L/tick；无水泵 0.05 L/tick
      ├─ 回取水点，AddWater(桶里全部)
      └─ poured ≥ 20 L → NotifyBucketDelivered()

喝水/洗手：取水点 = Building_Basin
      ├─ JobGiver_DrinkWater → 随身容器有水的先喝 CK_DrinkFromCarried
      └─ 否则找最近 Building_Basin（含取水点）→ CK_DrinkFromBasin
```

## 所含功能

- 取水点自带 150 L 水箱，接入水网后可由水泵自动补水；水箱/热水条等水网 UI 同样适用。
- 喝水、洗手、用水桶/脸盆接水三种取用方式。
- 「取水次数」：设置后自动派小人拿水桶去水井打水倒回来；次数到、没水桶、没水井、水箱满都会正确停下。
- 水桶 60 L，可随身携带、直接喝、倒进水盆/水箱；水质按来源记录并在喝水时判定。
- 同网水泵工作时打水明显更快；无水泵时水井最慢、取水点/水箱稍快。

## 如何使用

1. 研究「卫生设施」，在「卫生」页建 `CK_WaterPoint`，用 `CK_DbhWaterPipe` 接到水井/水泵/水箱所在的同一张水网。
2. 建好水井后，选中取水点打开「取水」页，用 -1/+1/+5 或 Gizmo 滑条设置要打几桶水；小人会自动拿水桶去井边打水。
3. 手工点做一只 `CK_WaterBucket`（钢铁 20）；没有水桶时取水次数不会派活。
4. 想直接喝/洗手：选中殖民者右键取水点即可；口渴且随身带着水桶时会自动喝桶里的水。
5. 想给水盆补水：右键水盆「倒入水盆」；想给水箱补水：右键水箱「倒入水箱」。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 设置了次数但没人去 | 没有水桶、同网没有水井、水箱已满（< 20 L 空间）、小人 Hauling 关闭/不可达 | 看取水点检视页的水井/水箱状态；做水桶；检查工作优先级 |
| 打水很慢 | 同网没有工作的水泵 | 建水泵并通电，或接受手动速度（井 0.05 L/tick） |
| 水桶装不满 | 水井/取水点不可达，或取水点水箱空了 | 检查路径与水箱水量 |
| 水桶里的水显示未处理 | 从水井打的，或同网没有净水设备 | 建净水设备后从取水点接水 |
| 次数停在 2/5 | 水箱 150 L 已满，等水被喝掉/用掉后继续 | 正常行为；或把次数设小一点 |
| 取水点不能洗手/喝水 | 水箱没水、没接水网、被禁用 | 接水网/等水泵补水；检查是否被禁用 |
