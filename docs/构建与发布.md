## 简介

ColonyKit 的构建流程直接继承模板，不重新发明：`build.ps1` 编译、`verify.ps1` 静态校验、`package.ps1` 打包、`-Deploy` 部署到本机 `Mods\ColonyKit`。要求 **0 错误 0 警告** 才继续。

脚本已经在本机验证过（模板与多个衍生工程），M0 只做改名和路径适配。

## 描述

- `build.ps1`：
  - 用工作区 `.tools\dotnet` + `.tools\nuget` 离线 restore/build；
  - 统计 `: error` / `: warning`，失败写 `build-error.log`；
  - `-Clean` 清 `Source\obj`、`Source\bin`、`Assemblies`；
  - `-Deploy` 复制 `About/Assemblies/Defs/Patches/Languages/Translations/Textures/Sounds/Blueprints` 到 `Mods\ColonyKit`，并校验 DLL SHA256。
- `verify.ps1`：
  - `About/About.xml` 存在、`packageId` 合规、`supportedVersions` 含 1.6；
  - `Defs` / `Patches` / `Languages` 的 XML 可解析；
  - `Defs` 根元素 `<Defs>`、`Patches` 根元素 `<Patch>` 且子节点 `<Operation>`；
  - 补丁 `xpath` 能在本地 Defs 命中（跨 Mod 的只警告）；
  - `Assemblies/` 只有 `.dll` / `.pdb`。
- `package.ps1`：
  - 先 verify 再 build；
  - 只复制运行期目录（排除 `Source/obj/bin/dist`）；
  - 断言 `About/About.xml` 在第一层；
  - 手写 zip entry 名，保证分隔符是 `/`；
  - 产物 `dist/ColonyKit-<modVersion>.zip`。
- `-Deploy` 前检查 `RimWorldWin64` 进程，运行中拒绝覆盖 DLL。
- 发布前另跑本地化校验（`check-l10n`，M7-5 接入 verify）。

## 绘制调用逻辑图

```text
.\build.ps1
  ├─ [可选] -Clean：删 Source\obj、Source\bin、Assemblies
  ├─ restore（缺 obj\project.assets.json 时，--packages .tools\nuget）
  ├─ dotnet build -c Release --no-restore
  ├─ 统计 error / warning → 非 0 则写 build-error.log 并退出
  └─ [可选] -Deploy
        ├─ 检查 RimWorldWin64 是否在运行
        ├─ robocopy About/Assemblies/Defs/Patches/Languages/Translations/Textures/Sounds/Blueprints
        └─ 校验 DLL SHA256

.\verify.ps1
  ├─ About.xml（packageId / supportedVersions / 名称）
  ├─ XML 可解析 + 根元素
  ├─ 补丁 xpath 命中（本地）
  └─ Assemblies 内容

.\package.ps1
  ├─ verify → build
  ├─ 复制运行期目录到临时 staging
  ├─ 断言 About 在第一层 / 无 Source|obj|bin
  └─ zip → dist\ColonyKit-<version>.zip
```

## 函数清单

> 脚本与命令；M0 迁入后路径以 `sources/ColonyKit/` 为准。

| 脚本 / 命令 | 参数 | 作用 |
|---|---|---|
| `build.ps1` | `-Clean` / `-Deploy` / `-Configuration` / `-ModsPath` | 编译、清理、部署 |
| `verify.ps1` | — | 静态校验（退出码 0/1） |
| `package.ps1` | `-SkipBuild` / `-SkipVerify` | 校验 + 编译 + 打 zip |
| `tools/check-l10n.ps1` | `-Strict` | 本地化对账（M7-5 接入） |
| `dotnet build` | `Source\ColonyKit.csproj -c Release` | 直接编译（调试用） |
| `Get-FileHash` | `-Algorithm SHA256` | 部署后 DLL 一致性校验 |
