## 简介

机器人自己管理电量：低于 25% 找充电桩，低于 5% 强制休眠快充，0% 原地停机；停机后可以被搬运到充电桩恢复。

## 描述

| 电量 | 行为 |
|---|---|
| > 25% | 正常工作 |
| ≤ 25% | `JobGiver_SelfCharge` 找最近的空闲充电桩，排队/前往 |
| ≤ 5% | 强制休眠快充（不再接新工作） |
| 0% | 停机（downed），不能行动；等待搬运/充电 |

- 战斗机器人被 draft 时不自动充电；≤5% 强制解除 draft 并去充（或停机）。
- 没有可用桩：继续工作到 0% 停机；给 Alert。
- 桩被占：排队；排队太久可能先停机。
- 0% 是 downed，不是死亡；是否掉装备 M6-7 定稿。
- 停机能否被救援取决于 Pawn 架构/体重（M6-0）。

## 绘制调用逻辑图

```text
Need_RobotEnergy
      ├─ > 25% → WorkGiver/Job 正常
      ├─ ≤ 25% → JobGiver_SelfCharge
      │           ├─ 找空闲桩 → JobDriver_Charge
      │           └─ 无桩 → 继续工作/Alert
      ├─ ≤ 5%  → 强制 JobDriver_DormantCharge
      └─ 0%    → downed（停机）
                    │
                    ▼
          搬运/救援到充电桩 → 充电 → 恢复
```

## 所含功能

- 25%/5%/0% 阈值。
- 自动找桩/排队。
- draft 限制/强制解除。
- 0% 停机与救援恢复。
- Alert 提示。

## 如何使用

1. 建足够充电桩并接电；建议 3–5 台机器人至少 2 台桩。
2. 正常不用管；看能量条/Gizmo。
3. 手动干预：选中机器人 →「去充电」/「休眠快充」。
4. 0% 停机后让殖民者搬到桩，或修电后等恢复。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 低电还在干活 | 没找到桩/工作优先级压过充电 | 建桩、检查 Job |
| 一堆机器人抢一个桩 | 桩太少 | 加桩/错峰 |
| 停机后没人搬 | 没救援工作/路径不通 | 手动优先搬运 |
