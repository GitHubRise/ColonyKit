## 简介

淋浴和农业都要用水，所以水网下沉到 `Core/Water/`，两个模块只做「消费者」，不各自维护水箱与管道。单位统一用升（`L`），内部 `float`，UI 取整。

这是 ColonyKit 唯一的跨模块共享服务；模块之间不直接引用，需要协作时走它。

## 描述

- `MapComponent_WaterNetwork` 持有本图的 `WaterNet` 集合；地图加载后按建筑重建拓扑，建筑增删时增量更新。
- `WaterNet` 按管道连通性分组，缓存总容量、存量、产出、消耗、断水原因。
- 四类 Comp：
  - `CompWaterPipe`：连接件；
  - `CompWaterPump`：耗电产水（L/s 或 L/tick）；
  - `CompWaterTank`：容量；
  - `CompWaterConsumer`：需求、优先级、停机原因。
- 结算：稳态每 250 tick 一次；先算产出，再按优先级分配，最后扣存量；不足时消费者停机并记录原因。
- 存档：只存每个网的存量 + 建筑状态；读档后按建筑重建拓扑，不存图结构。
- 断水：消费者停机、Gizmo/Alert 给出可读原因；恢复供水后自动重启。
- 热水（淋浴用）是水网的一个可选属性：`CompWaterHeater` 给网加热，温度随结算更新；农业不关心温度。

## 绘制调用逻辑图

```text
泵(耗电) ──▶ 管道 ──▶ 水箱(容量) ──▶ 消费者(淋浴/喷灌)
   │            │           │              │
   └─ 产水 L ───┴─ 连通 ────┴─ 存量 L ─────┴─ 需求 L + 优先级

每 250 tick:
  WaterNet.Tick()
    ├─ 汇总 pump.Produce()
    ├─ 汇总 consumer.Demand()
    ├─ 按优先级分配 → 扣 tank.Stored
    └─ consumer.SetRunning(是否满足, 停机原因)

建筑增删 / 读档:
  MapComponent_WaterNetwork.Rebuild()
    └─ 按管道连通性重建 WaterNet → 重新挂接 comps
```

## 函数清单

> 规划签名；M1 落地时以实际代码为准。

| 类型 / 函数 | 签名（规划） | 作用 |
|---|---|---|
| `MapComponent_WaterNetwork` | `class : MapComponent` | 每图水网容器，负责重建与结算 |
| `WaterNet` | `class` | 一个连通网：容量/存量/产出/消耗 |
| `WaterNet.AddPump` / `AddTank` / `AddConsumer` | `void (…)` | 挂接设备 |
| `WaterNet.Tick` | `void Tick()` | 250 tick 结算一次 |
| `WaterNet.TryConsume` | `bool TryConsume(float liters, out string reason)` | 按优先级取水 |
| `CompWaterPump.Produce` | `float Produce()` | 本 tick 产水 |
| `CompWaterTank.Stored` | `float Stored { get; set; }` | 存量（存档） |
| `CompWaterConsumer.Demand` | `float Demand { get; }` | 需求 |
| `CompWaterConsumer.IsRunning` | `bool IsRunning { get; }` | 是否满足 |
| `CompWaterHeater.Temperature` | `float Temperature { get; }` | 热水温度（淋浴） |

## 所含功能

- 管道连通分组与增量重建；
- 产水/容量/存量/消耗统计；
- 按优先级分配与断水原因；
- 热水温度（供淋浴）；
- 存档只存状态，读档重建拓扑；
- 调试动作与断水 Alert；
- 供淋浴、农业共同消费。
