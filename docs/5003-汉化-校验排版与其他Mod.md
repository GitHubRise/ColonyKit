## 简介

用脚本检查翻译完整性，处理中文排版问题，并说明「其他 Mod 汉化补丁」是否属于本模块。

## 描述

- 计划工具：`tools/check-l10n.ps1`（M7-5 创建）。
- 检查：源码/XML 用到的 `ColonyKit.*` Keyed 是否有定义；Defs 的 `defName` 是否有 DefInjected；各语言键集合是否一致。
- 简中缺失直接失败；英文缺失也失败。
- 中文排版：长句换行、标点、字体回退、数字/单位；只在实测有问题时加补丁。
- 其他 Mod 汉化补丁：默认不做；要做单列任务/目录（M7-7），先确认授权。
- 校验接入 `verify.ps1`，打包前自动跑。

## 绘制调用逻辑图

```text
源码 "ColonyKit.*" 字符串 / Defs defName
        │
        ▼
check-l10n.ps1
        ├─ 收集 Keyed 使用/定义
        ├─ 收集 DefInjected 覆盖
        ├─ 对比 English / ChineseSimplified
        └─ 输出缺失/多余清单
        │
        ├─ 0 缺失 → verify 通过
        └─ 有缺失 → 失败，按清单修
```

## 如何使用

```powershell

.\tools\check-l10n.ps1
.\verify.ps1
```

1. 看缺失清单，按文件/键修。
2. 修完重跑直到 0 缺失。
3. 进游戏看设置页/研究页/蓝图库/仓库 ITab/机器人能量条。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 校验报「多余键」 | 删了功能没删键 | 清理或标记保留 |
| 中文溢出按钮 | 文本太长 | 缩短或改 UI 宽度 |
| 其他 Mod 汉化冲突 | 同一 DefInjected 键 | 调整加载顺序/只留一份 |
