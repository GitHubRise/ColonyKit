## 简介

蓝图模块把玩家建造的一片建筑「拍」成一条可重放的记录：名称、尺寸、每个建筑的 `defName`/材质/朝向/相对坐标。库随存档保存；跨存档复用通过 XML 模板（玩家模板 + Mod 内置模板）完成。

它不改建造系统：放置时仍走 `GenConstruct.CanPlaceBlueprintAt` 校验、`GenConstruct.PlaceBlueprintForBuild` 生成原版施工蓝图；上帝模式才直接 `ThingMaker.MakeThing` + `GenSpawn.Spawn` 成完工建筑。

## 描述

- `BlueprintRecord`：`id`、`version`、`name`、`sizeX/sizeZ`、`createdTick`、`pinned`、`group`、`tags`、`entries`；`BlueprintEntry` 含 `defName`、`stuffDefName`、`rot`、相对 `x/z`。
- 捕获：`Designator_BlueprintCapture` 拉框，只收**玩家阵营、已完工、可见**的建筑；跳过未施工蓝图/框架/矿物/自然岩石/物品；不含地形。
- 库：`BlueprintLibrary` 每存档一份，由 `BlueprintGameComponent` 持有；`MainTabWindow_Blueprints` 负责列表、置顶/分组/标签、编辑、删除、材料统计、放置与模板区。
- 放置：`Designator_BlueprintPlace` 幽灵预览；Q/E 旋转、B 镜像；逐条校验（Def/材质/研究/边界/地形/占用/水域/互动点）；缺 Def 跳过，其余任一失败整张拒绝。
- 材料：三档策略（原材质优先 / 就地取材 / 最便宜）；缺料只红色提示、不阻止落地；只有选不出可用材质才拒绝。
- 模板：玩家模板写 `Config/ColonyKit/Blueprints/*.xml`；内置模板随 Mod 发布在 `Blueprints/*.xml`，只读，同名玩家模板优先。
- 上帝模式：跳过研究检查、以 godMode 调用原版校验，落地直接生成完工建筑。
- 调试工具：Debug 菜单「蓝图工具 → 全场空调设为 -273」，批量把玩家空调目标温度拉到最低。
- 后续（可选）：JSON 导入/导出、包含地形/物品、创意工坊分享、落地撤销。

## 架构与数据

```text
BlueprintModule（启动/软停用）
        │
BlueprintGameComponent（每存档）
        └─ BlueprintLibrary
              ├─ records: List<BlueprintRecord>
              ├─ nextId
              └─ schemaVersion = 1

BlueprintRecord
        ├─ id / version / name / sizeX / sizeZ / createdTick
        ├─ pinned / group / tags
        └─ entries: List<BlueprintEntry>
              └─ defName / stuffDefName / rot / x / z

BlueprintTemplateStorage
        ├─ 玩家目录：Config/ColonyKit/Blueprints/*.xml
        └─ 内置目录：<Mod>/Blueprints/*.xml（只读）
```

- 存档键：库 `ck_blueprint_library`；记录 `ck_blueprint_id/version/name/sizeX/sizeZ/createdTick/pinned/group/tags/entries`；条目 `ck_blueprint_def/stuff/rot/x/z`。
- 读档 `PostLoadInit`：删除空记录、逐条 `Normalize`、按最大 `id` 修正 `nextId`、schema 升到 1。
- `Normalize`：空名称 →「蓝图 0」；分组去首尾空白（最长 32）；标签去空/去重（最多 8 个、每个 24 字符）；清掉空条目；尺寸缺失时按条目最大 `x/z + 1` 反推；`version` 至少为 1。
- `Clone` 会把 `id` 置 0，并复制 `pinned/group/tags`；`BlueprintLibrary.Add` 统一重新分配 `id`。
- 坐标原点 = 捕获到的**建筑包围盒左下角**；条目 `x/z` 是建筑 `Position` 相对原点的偏移，不是占用矩形左下角。

## 捕获

- 设计器只接受界内、未雾格；拖框样式复用原版 `FilledRectangle`，带尺寸读数。
- `Capture` 先检查拖框宽高是否超过 `maxSide`，再逐格收集可见的玩家完工建筑并去重。
- 一条记录的实际尺寸取**建筑占用矩形包围盒**，拖框空白边距会被裁掉。
- 收集顺序按 `z` 再 `x` 排序，保证同区域多次捕获的条目顺序稳定。
- 没有可捕获建筑 → 拒绝；建筑数超过 `maxEntries` → 拒绝；库已满（`maxRecords`）→ 拒绝。
- 成功后自动命名「蓝图 N」、入库、打开蓝图页并选中；捕获不消耗材料、不改地图。

## 放置与旋转

- 预览以鼠标格为中心：`anchor = 鼠标 - (旋转后尺寸 - 1) / 2`；旋转 90° 交换外框宽高。
- 条目位置：先取原朝向下的 `GenAdj.OccupiedRect`，按镜像/旋转变换整个矩形，再用新朝向的占用矩形反推 `Position`。
- 镜像：B 键先把 East/West 对调，再叠加旋转；非方形多格建筑的镜像朝向是近似。
- 校验顺序：Def 存在且可建造 → 材质策略 → 需要材质但无可用材质 → 研究（上帝模式跳过）→ 界内 → `CanPlaceBlueprintAt`。
- 缺 Def：标记 `missingDef` 并跳过，不阻塞整张；面板显示「将跳过 X 个建筑」。
- 其他失败：`canPlace = false`，记录第一条失败原因；左键拒绝。
- 落地：`PlaceAll` 逐条 `GenSpawn.WipeExistingThings`（Deconstruct）→ 上帝模式直接生成完工建筑，否则 `PlaceBlueprintForBuild`。
- 设计器放置后保留，可连续复刻；右键/ESC 退出。
- 预览有缓存：鼠标格/旋转/镜像/材料策略/地图变化才重算。

## 材料策略

| 策略 | 行为 |
|---|---|
| 原材质优先 `PreferSource` | 原材质仍可用于该 Def 就用（不看库存）；否则有库存的最便宜 → 全局最便宜 |
| 就地取材 `Available`（默认） | 原材质有库存就用；否则有库存的最便宜 → 全局最便宜 |
| 最便宜 `Cheapest` | 始终选该 Def 可用的最便宜材质 |

- 候选池：`stuffProps` 能用于该 Def 的材质；优先 `canSuggestUseDefaultStuff`，没有才放开全部。
- 排序：`BaseMarketValue` 升序 → `commonality` 降序 → `defName`。
- 「有库存」先要求 ≥ 单件 `CostStuffCount`，不够则退到任何库存 > 0。
- 材料统计 = `CostStuffCount` + `CostList`；缺料红色；库存不足不阻止放置。
- 材质被替换时记录 `BlueprintSubstitution`，蓝图页显示「原 X → Y」。
- 候选列表按建筑 Def 缓存，Def 重载/换局时 `ResetCache`。

## 库与模板 UI

- 页面尺寸 920×650；顶部标题、`已保存 X/Y`、三档材料策略按钮、右上「捕获蓝图」。
- 左侧 300 px 列表：顶部筛选框（名称/分组/标签，`#` 只搜标签）+ 分组标题；每条显示 ★置顶、名称、`尺寸×尺寸，N 个建筑`、`#标签`；首条自动选中；滚动。
- 组织规则：置顶记录统一在最前（「置顶」标题）；其余按分组名 `OrdinalIgnoreCase` 排序；未分组最后。分组/标签只影响显示与筛选，不影响放置。
- 右侧：名称、`尺寸 · 建筑数 · 捕获 tick`、分组、标签、放置/编辑/置顶/删除/另存为模板、材料区、模板区。
- 编辑对话框 `Dialog_BlueprintProperties`：名称、分组、标签（逗号/分号分隔）、置顶；标签去重并截断到上限。
- 右键点击左侧记录：置顶/取消置顶、编辑属性。
- 材料区可滚动；不足红色；替换项单独列出。
- 模板区：刷新、载入、删除；模板行显示 `[分组]` 与 `#标签`；内置模板灰色「内置」标记 + tooltip，只能载入；坏文件红色显示错误。
- 模板合并：玩家目录先加载，内置目录按显示名去重后追加；最终按 `OrdinalIgnoreCase` 排序；同名玩家模板优先。
- 模板保存：文件名清洗、最长 64 字符、同名自动 ` (2)`，不覆盖；模板载入会克隆并重名追加 ` (2)`。
- 模板会保存 `group`/`tags`（可选元素），载入后恢复分组与标签；`pinned` 不写入模板，载入后默认不置顶。

## 设置与调试工具

- 设置页「蓝图」：
  - 材料策略（默认就地取材）；
  - 单张最大边长 8–200（默认 80）；
  - 单张最大建筑数 50–10000（默认 3000）；
  - 每存档库上限 16–2048（默认 256）；
  - 调试日志开关（记录捕获/放置明细）。
- 非法设置 `Validate()` 时回默认值。
- Debug 菜单「蓝图工具 → 全场空调设为 -273」：把当前地图所有玩家 `Building_Cooler` 的 `CompTempControl.TargetTemperature` 设为 -273°C，并提示数量；用于快速搭建深冷库/温室。

## 绘制调用逻辑图

```text
捕获:
  Designator_BlueprintCapture 拉框
      ├─ 过滤：界内/未雾、玩家阵营、完工建筑
      ├─ 跳过：蓝图/框架/矿物/自然岩石/物品
      └─ BlueprintRecord.Capture → 建筑包围盒 → 条目（z/x 排序）

库:
  BlueprintLibrary
      ├─ Add(record) / Remove(record) / Import(template)
      ├─ NextDefaultName / UniqueName
      └─ 随 BlueprintGameComponent.ExposeData 存档

放置:
  Designator_BlueprintPlace
      ├─ EnsurePlacements（缓存）
      │     └─ BlueprintPlacementUtility.Build
      │           ├─ Def/材质/研究/边界/CanPlaceBlueprintAt
      │           └─ 缺 Def → 跳过
      ├─ 幽灵预览 + footprint（绿/红）
      └─ 左键 → PlaceAll
            ├─ WipeExistingThings
            ├─ 上帝模式 → MakeThing + Spawn（完工）
            └─ 普通 → PlaceBlueprintForBuild（施工）

模板:
  MainTabWindow_Blueprints
      ├─ Save → Config/ColonyKit/Blueprints/<name>.xml
      └─ LoadAll → 玩家 + 内置 → 排序/去重 → 载入/删除
```

## 所含功能

- 布局捕获（玩家阵营、完工、可见建筑；跳过蓝图/框架/矿物/自然岩石/物品）。
- 记录 schema、材质、朝向、相对坐标与实际建筑包围盒尺寸。
- 每存档蓝图库（`BlueprintGameComponent`）。
- 库 UI（列表/置顶/分组/标签/筛选/编辑/删除/材料统计/三档策略）。
- 放置预览（旋转/镜像/逐条校验/缺 Def 跳过）。
- 原版施工；上帝模式直接建成。
- 缺 Def/缺 Mod 跳过与提示。
- 材料需求对比、缺料高亮、材质替换说明。
- 玩家模板 + 内置模板（只读、同名玩家优先）。
- Debug 工具：全场空调设最低温。

## 已知限制

- 不含地形/地板、物品、耐久/品质/艺术/染色；复刻后需要另铺地板。
- 捕获按建筑包围盒记录，拖框空白边距不保留；雾格不参与捕获。
- 多格建筑镜像/旋转对非方形建筑是近似，门朝向可能需手动修正。
- 研究未完成整张拒绝（上帝模式除外）；缺料不拒绝但会等料。
- 模板载入不检查库上限；蓝图页有筛选但没有分页，分组标题不能折叠。
- 置顶不写入模板；模板载入后默认不置顶。
- 模板 XML 的 `schema` 属性目前只写出，不做版本迁移。
- 没有落地撤销；放置后按原版拆除。
- 未实现包含地形/物品、JSON 导入导出、创意工坊分享。
