## 简介

蓝图模块把玩家建造的一片建筑「拍」成一条可重放的记录：名称、尺寸、朝向、每个格子的 `defName`/材质/旋转/可选地形。库随存档保存，之后可以预览、旋转、镜像、按材料重建。

它不改建造系统，最终仍走 `GenConstruct.PlaceBlueprintForBuild`，所以研究、材料、地形校验都沿用原版规则。

## 描述

- `BlueprintRecord`：`Name`、`Size`、`Version`、`Entries`；每条 `BlueprintEntry` 含 `defName`、`stuffDefName`、`rot`、相对坐标、可选地形。
- 捕获：`Designator_BlueprintCapture` 拉框，只收**玩家建造的建筑**（跳过蓝图/框架/物品），可选「包含地形」。
- 库：`BlueprintLibrary` 每存档一份，由 `ColonyKitGameComponent` 持有；`Dialog_BlueprintLibrary` 列表、重命名、删除、材料统计、放置。
- 放置：`Designator_BlueprintPlace` 带幽灵预览，Q/E 旋转、镜像、逐格红绿校验（地形/占用/水域/研究/材料）。
- 施工：逐条 `GenConstruct.PlaceBlueprintForBuild`，保留材质与朝向；支持一次放置多个蓝图，取消可回滚。
- 材料清单：放置前显示总需求 vs 地图现有，缺料高亮。
- 存档：库随存档保存，schema 带版本号；缺 Mod/缺 Def 时跳过并给出警告清单，不静默。
- 后续（可选）：JSON 导入/导出、跨存档共享、包含地形/物品、创意工坊分享。

## 绘制调用逻辑图

```text
捕获:
  Designator_BlueprintCapture 拉框
      ├─ 过滤：玩家建筑、非蓝图/框架、可选地形
      └─ BlueprintRecord.FromCells(cells, name)

库:
  BlueprintLibrary
      ├─ Add(record) / Rename / Remove
      └─ 随 ColonyKitGameComponent.ExposeData 存档

放置:
  Designator_BlueprintPlace
      ├─ 幽灵预览（Q/E 旋转、镜像）
      ├─ 逐格校验：地形/占用/水域/研究/材料
      └─ 确认 → foreach entry: GenConstruct.PlaceBlueprintForBuild(...)
                        └─ 原版施工/材料逻辑
```

## 函数清单

> 规划签名；M5 落地时以实际代码为准。

| 类型 / 函数 | 签名（规划） | 作用 |
|---|---|---|
| `BlueprintRecord` | `class : IExposable` | 布局记录（名称/尺寸/版本/条目） |
| `BlueprintRecord.FromCells` | `static BlueprintRecord FromCells(IEnumerable<IntVec3>, string)` | 捕获 |
| `BlueprintEntry` | `struct` | `defName`/`stuff`/`rot`/相对坐标/地形 |
| `BlueprintLibrary` | `class : IExposable` | 每存档库 |
| `BlueprintLibrary.Add/Remove/Rename` | `bool (…)` | 库操作 |
| `Designator_BlueprintCapture` | `class : Designator` | 捕获设计器 |
| `Designator_BlueprintPlace` | `class : Designator` | 放置设计器 + 预览 |
| `Dialog_BlueprintLibrary` | `class : Window` | 库 UI |
| `BlueprintMaterialReport` | `class` | 总需求 vs 现有材料 |
| `BlueprintSettings` | `class : ICKModuleSettings` | 开关、是否含地形、库上限 |

## 所含功能

- 布局捕获（只收玩家建筑）；
- 记录 schema 与版本；
- 每存档蓝图库；
- 库 UI（列表/重命名/删除/材料统计）；
- 放置预览（旋转/镜像/逐格校验）；
- 原版施工 + 取消回滚；
- 缺 Def/缺 Mod 跳过与警告；
- 材料需求对比；
- 可选 JSON 导入导出。
