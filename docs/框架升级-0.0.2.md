# 框架升级 0.0.2

> 状态：✅ 已同步（2026-10-25） · 来源：`sources/mod-template` tag `v0.0.2` · 当前 Mod：ColonyKit 0.0.2

## 1. 来源与范围

- 上游：`sources/mod-template`，tag `v0.0.2`（commit `be35fcc`）。
- ColonyKit 的基线是 0.0.1 的复制 + 改名 + 自动发现/汉化；**不是** git merge 关系（上游文件叫 `ModTemplate`，本仓库叫 `ColonyKit`）。
- 本次采用「按 diff 手工移植」：只取框架修复与构建改进，不引入模板的 demo 内容。

## 2. 已同步

| 0.0.2 改动 | ColonyKit 落点 | 说明 |
|---|---|---|
| `build.ps1` 默认 `-t:Rebuild` | `build.ps1` | 避免增量构建漏警告 |
| 警告视为失败 | `build.ps1` | error/warning 都写 `build-error.log` |
| `-NoRebuild` | `build.ps1` | 日常增量构建用 |
| 部署 `/MIR` | `build.ps1` | 清理源里已删除的陈旧 Def/Worker |
| 结束重置 `LASTEXITCODE` | `build.ps1` | 避免 robocopy 成功码被误判 |
| 无 `.tools` 时回退 PATH dotnet | `build.ps1` | CI/其他机器可用 |
| `NotificationService` 空 Game 守卫 | `Source/Notifications/NotificationService.cs` | `Current.Game == null` 不碰 TickManager |
| `SettingsWidgets.Dropdown` 空 options 守卫 | `Source/Settings/Widgets/SettingsWidgets.cs` | `null` / 空列表直接返回 |
| `MainButtonService.ApplyOrder` 反射守卫 | `Source/UI/MainButtonService.cs` | 字段缺失/类型不符用 `ModLog.Once` 警告 |
| 版本号 0.0.2 | `About/About.xml`、`ColonyKit.csproj` | Mod 版本同步 |

`ModLoc` 的 `CS0618` 已在 0.0.1 阶段用 `string.Format` 方案修掉，本次不重复改。

## 5. 下次升级流程

1. 在 `sources/mod-template` 确认新 tag，`git -C sources/ColonyKit fetch upstream --tags`。
2. 建分支：`git switch -c upgrade/framework-0.0.x`。
3. 对比：`git -C sources/mod-template diff v0.0.2..v0.0.x -- Source build.ps1`。
4. 只把**框架修复**映射到 ColonyKit；模板 demo 内容按本文件的「未同步」原则判断。
5. 改版本号、`CHANGELOG`、本文件。
6. `build.ps1 -Clean` → `verify.ps1` → `package.ps1` → quicktest。
7. 合并 `main`，打 `colonykit-v0.0.x` tag。
