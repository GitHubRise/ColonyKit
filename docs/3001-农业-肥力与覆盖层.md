## 简介

在每格原地形 `fertility` 之上叠加一层可存档的肥力网格（0–2）。喷灌、施肥改的是网格值；覆盖层显示最终肥力，作物生长按它计算。

## 描述

- 网格范围 0–2；最终肥力 = 原地形 fertility × 系数 + 网格加成（公式 M4-0 定稿）。
- 只影响种植/生长，不改地形本身；卸载 Mod 回到原版。
- 网格随地图存档；读档按建筑重建喷灌覆盖。
- 覆盖层只读，不能直接用鼠标改；改肥力必须靠喷灌/施肥。
- `FertilityGrid.CalculateFertilityAt` 调用频繁，需脏格/缓存（M4-0 压测）。

## 绘制调用逻辑图

```text
地形 fertility（原版）
        +
MapComponent_FertilityGrid（0–2，存档）
        │
        ▼
Patch_CalculateFertilityAt（Postfix）
        │
        ▼
原版 FertilityGrid → 作物生长/产量
        │
        ▼
SectionLayer_FertilityGrid（覆盖层渲染）
        +
ITab/Gizmo：显示当前格肥力/来源
```

## 如何使用

**前提**：研究「灌溉」或「堆肥」；有喷灌机/肥料。

1. 建喷灌机或准备施肥。
2. 打开肥力覆盖层看颜色/数值。
3. 对比原地形肥力，确认叠加结果。
4. 用喷灌/施肥提升目标地块。
5. 存读档后确认网格保留。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 覆盖层全是一个颜色 | 还没喷灌/施肥，或图层没开 | 先建喷灌机；确认开关 |
| 数值和地形不一样 | 显示的是叠加后的值 | 看 tooltip 的基础值/加成 |
| 读档后肥力丢了 | 网格未存档/建筑未重建 | 记录存档和日志，属 bug |
