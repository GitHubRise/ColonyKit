## 简介

农业模块在「原地形肥力」之上叠一层可存档的肥力网格：喷灌机耗水耗电把半径内的肥力抬到目标值，堆肥机把有机废料变成肥料，施肥设计器把肥料施到地块并随时间衰减。

技术核心是 Postfix `FertilityGrid.CalculateFertilityAt`，让原版种植/生长直接吃到网格值，而不是另写一套生长逻辑。

## 描述

- `MapComponent_FertilityGrid`：每格 0–2 的附加肥力，叠加在原地形 `fertility` 上；脏格队列更新，分区渲染（`SectionLayer`），随存档保存。
- 肥力生效：Postfix `FertilityGrid.CalculateFertilityAt`，返回 `原版值 + 网格附加值`。
- 灌溉：`CK_Sprinkler` 耗水网 + 电力，半径 5 格把肥力抬到目标值；断水/断电自动停。
- 堆肥：`CK_Composter` 消耗有机废料（食物残渣/尸体，可配置）产出 `CK_Fertilizer`。
- 施肥：`Designator_ApplyFertilizer` + Job 把肥料施到地块，短期大幅提升肥力并衰减。
- UI：肥力 overlay（开关/图例）、喷灌机 Gizmo（半径/水量/状态）。
- DBH 共存：检测到 DBH 的灌溉/肥力网格时，默认软停用本模块的肥力网格或喷灌，避免双重加成。

## 绘制调用逻辑图

```text
水网 + 电力 ──▶ CK_Sprinkler（半径 5）
                     │ 每 250 tick
                     ▼
          MapComponent_FertilityGrid.SetDirty(cells)
                     │
                     ▼
          SectionLayer_FertilityGrid.Regenerate()  // 只重画脏区

原版种植:
  FertilityGrid.CalculateFertilityAt(cell)
        │ Postfix
        ▼
  return 原版肥力 + 网格附加肥力
        │
        ▼
  Plant 生长速率 / 产量

堆肥:
  有机废料 ──▶ CK_Composter ──▶ CK_Fertilizer ──▶ Designator_ApplyFertilizer
                                                   └─ Job 施肥 → 提升肥力 → 随时间衰减
```
