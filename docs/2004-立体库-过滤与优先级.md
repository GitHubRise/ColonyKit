## 简介

立体库通过 `IStoreSettingsParent` 复用原版 **Storage** 页：用一个 `RimWorld.StorageSettings` 管过滤和优先级，决定收什么、不收什么、和普通库存区相比谁优先。

## 描述

- 复用组件：`RimWorld.StorageSettings`（不是自定义 `CompWarehouse`），由 `Building_VerticalWarehouse` 实现 `IStoreSettingsParent` 后自动出现在原版 Storage 页。
- 默认优先级：**Normal**（与普通库存区一致）。
- 默认过滤（新建筑/旧档迁移）：
  - 先 `SetDisallowAll()`；
  - 允许 `Foods` 分类、草药 `MedicineHerbal`、干草 `Hay`；
  - 追加木头 `WoodLog`、植物类 `PlantMatter`、麦芽 `Wort`；
  - `AllowRotten` 显式禁止。
- `Accepts` 额外硬性拒绝：非 `ThingCategory.Item`、尸体 `IsCorpse`、`MinifiedThing`；其余交给 `storeSettings.AllowedToAccept`。
- 过滤影响：自动入库（`CanStore`）、履带送入（`TryStoreInNetwork`）、Gizmo「收集附近物品」；**不会**把已存但不合格物品自动丢出。
- 优先级影响：自动入库让位规则、自动出库目标选择；比较使用原版 `StoragePriority`（Low/Normal/Preferred/Important/Critical）。
- 没有「禁止入库」Gizmo/禁用清单；要临时停收，用过滤取消勾选或把优先级调到最低并配合库存区规则。
- 多仓库可以分别设置不同过滤/优先级，但自动入库/出库按 lister 顺序取第一个可用仓库，不保证选最优。
- 过滤/优先级随建筑 `storeSettings` 存读档；旧档 `settingsVersion < 4` 会迁移默认优先级（Low→Normal）、目标温度（21→4）和过滤；`v4` 只追加木头/植物类/麦芽，保留玩家自定义过滤。

## 绘制调用逻辑图

```text
选中立体库
  └─ 原版 ITab_Storage
        ├─ 优先级下拉 → storeSettings.Priority
        └─ ThingFilterUI → storeSettings.filter

入库/收集/履带
  └─ CanStore / TryStoreInNetwork / CollectNearby
        └─ Accepts
              ├─ 非 Item / 尸体 / MinifiedThing → 拒绝
              └─ storeSettings.AllowedToAccept → 通过/拒绝

自动入库让位
  └─ 找到可放库存格
        └─ 仓库优先级 ≤ 库存区优先级 → 让给原版
```

## 所含功能

- 原版过滤/优先级 UI。
- 默认食物/草药/干草/木头/植物类/麦芽，禁止腐烂。
- 过滤对入库、履带、收集生效。
- 多仓库独立配置。
- 旧档过滤/优先级迁移。

## 如何使用

1. 选中立体库，打开 **Storage** 页。
2. 勾选允许的物品/类别；默认只放食物类、草药、干草、木头、植物类、麦芽。
3. 设置优先级：入库/出库都按这个优先级和普通库存区比较。
4. 多个仓库可用不同过滤分工（自动任务不保证选最优仓库）。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 某物品不进来 | 过滤没勾/是尸体或最小化建筑 | 在 Storage 页勾选；尸体/最小化无法入库 |
| 改了过滤库存没变 | 不会自动清出 | 手动取出 |
| 搬运工不优先放这里 | 优先级不高于普通库存区 | 调高仓库优先级或填满库存区 |
| 没有「禁止入库」按钮 | 未实现 | 用过滤/优先级代替 |
| 旧存档过滤变了 | `settingsVersion<4` 迁移 | 重新检查 Storage 页 |
