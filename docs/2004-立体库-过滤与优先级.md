## 简介

用原版 `StorageSettings` 那套过滤/优先级，决定立体库收什么、不收什么、比别的库存区优先多少。

## 描述

- 过滤同时影响入库与「是否继续保留」判断；改过滤不立刻丢出不合格物品，出库/清理时才处理。
- 优先级与普通库存区共用一套比较。
- 质量/耐久度过滤沿用原版存储设置（如果原版提供）。
- 「禁止入库」只停新入库，不影响已有库存/出库。
- 多个立体库可用不同过滤分工。
- 过滤设置随存档保存。

## 绘制调用逻辑图

```text
玩家改过滤/优先级
      │
      ▼
StorageSettings（allowed / priority / forbid）
      │
      ├─ 入库：WorkGiver 比较目标库优先级/过滤
      ├─ 已存物品：过滤变化只影响后续出库/清理
      └─ Gizmo「禁止入库」：临时停收
      │
      ▼
ITab 显示当前过滤/优先级/填充度
```

## 所含功能

- 允许/禁止物品过滤。
- 优先级（低/普通/偏好/重要/关键）。
- 质量/耐久度过滤（若原版支持）。
- 禁止入库 Gizmo。
- 多库分工。

## 如何使用

**前提**：库已建好并通电。

1. 选中库，打开过滤设置。
2. 勾选允许物品/类别，先只放一类测试。
3. 设置优先级，和普通库存区比较。
4. 需要临时拒收点「禁止入库」。
5. 多个库用不同过滤分工。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 某物品不进来 | 过滤没勾/被禁用 | 检查过滤与 Gizmo |
| 搬运工不优先放这里 | 优先级低于目标库存区 | 调高优先级 |
| 改了过滤库存没变 | 不会自动清出 | 手动取出/清理 |
