## 简介

本页讲**硬件与供水/供热**：1×1 可独立放置的淋浴器、2×2 电热水淋浴器、浴缸、洗手池、马桶，以及水井/水泵/水管/水箱/热水器/热水罐。`Need_Hygiene` 本身见 1001。

## 描述

### 水网

- 水网由相邻 `CompPipe` 连接：`CK_DbhWaterPipe` 可铺墙下、可拖拽；`CK_DbhWaterTank`（2000 L）、`CK_DbhWaterTankGiant`（8000 L）储水。
- `CK_DbhWaterWell` 提供 2000 L/天地下水；`CK_DbhWaterPump` 1500 L/天、250 W，**必须同网有水井**才产水。
- 管网每 tick 计算存量、泵送能力、井容量；产水按「每网一次」推入，不会因多水箱成倍产水。
- 水箱水质默认 `Untreated`；地图水体被污染时变为 `Contaminated`，会走脏水污染判定（见 1005/1007）。

### 洁具

| 建筑 | 尺寸/耗水 | 电力 | 行为 |
|---|---|---|---|
| `CK_Shower` | 1×1；0.13 L/tick × 耗水倍率，标称 50 L × 倍率 | 75 W 可选 | 通电为热水；断电回退热水罐，否则冷水；可独立放 |
| `CK_ShowerPower` | 2×2；0.4 L/tick，清洗 0.004/tick | 必须通电 | 电加热，洗得更快、耗水更多 |
| `CK_Bath` | 1×2；190 L × 倍率 | 无 | 先放水（1 L/tick）再泡 1800 tick；冷水/热水按罐温 |
| `CK_Basin` | 2×2；4 L × 倍率 | 无 | 洗手 100 tick；上完厕所后自动排队 |
| `CK_Toilet` | 1×1；14 L × 倍率 | 无 | 冲水 + 污水管网；没水不可用 |

### 热水模型（DBH 式）

- 热水器 `CK_DbhWaterHeater`：250 W，供热能力 250，自带 100 容量热水罐；热水罐 `CK_HotWaterTank` 可加建，100 容量/台。
- 每台热水罐保存 0–1 的 `HeaterTemp`；管网每 tick：
  ```text
  BoilerCapacitySum = Σ 运行中热水器供热能力
  HeatStoreCapacitySum = Σ 热水罐 StoreCapacity
  HeatingCap = clamp01(BoilerCapacitySum / HeatStoreCapacitySum)
  ```
- 热水罐每 tick 按 `MoveTowards(HeaterTemp, HeatingCap, RiseRate/FallRate)` 升降温；热水罐 `RiseRate=0.0024`、`FallRate=0.00001`。
- 淋浴/浴缸/洗手池每次取热：
  ```text
  draw = HeatUsedPerTick × 热水消耗倍率
  所有 HeaterTemp > 0 的热水罐平均分摊 draw
  ```
- 热水罐温度耗尽后下一 tick 转冷水；淋浴 Job 每 tick 更新 `cold`。
- 阀门关闭的热水罐 `GetStoreCapacity=0`，不参与加热也不可供热。

## 绘制调用逻辑图

```text
水井 → 水泵 → 水管 → 水箱 → 洁具
                         │
热水器(250) + 热水罐(100/台) → HeatingCap
                         │
                         ▼
HeaterTemp(0–1) → PullHotWater(draw) → 淋浴/浴缸/洗手池

淋浴器通电 → 电加热（不取热水罐）
淋浴器断电 → 取热水罐；取不到 → 冷水
```

## 所含功能

- 水网建造、连通、产水与储水。
- 淋浴器/浴缸/洗手池/马桶的水量与电力检查。
- DBH 式热水罐温度、供热能力、按 tick 消耗。
- 断电/断水/堵塞时的降级与不可用判断。

## 如何使用

1. 研究「卫生设施」「高级淋浴」。
2. 建水井 → 水泵（接电）→ 水管 → 水箱 → 洁具。
3. 建 `CK_DbhWaterHeater` 接电；需要更多热水时加建 `CK_HotWaterTank`。
4. 把洁具接到水网；选中洁具看「供水」「热水/冷水」和热水罐温度。
5. 堵塞时选中洁具点「疏通堵塞」。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 洁具显示没水 | 没接水网、水箱空、泵没电/没井 | 检查水网与水泵；水泵必须有水井 |
| 一直是冷水 | 热水罐温度 0、热水器断电、供热能力不足 | 加建热水器/热水罐，或降低热水用量 |
| 洗到一半变冷 | 热水罐温度耗尽 | 增加供热能力/热水罐，或降低热水消耗 |
| 水网突然断开 | 管道被拆/阀门关闭/泵故障 | 检查管道与阀门；水泵故障需维修 |
| 洁具被堵塞 | 随机堵塞 | 点「疏通堵塞」Gizmo |
