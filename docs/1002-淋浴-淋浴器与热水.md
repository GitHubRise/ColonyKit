## 简介

`CK_Shower` 是 **1×1** 淋浴器，可独立放置（不再要求贴墙）；接水网后供殖民者洗澡。首版水网为相邻连通的水井/水泵/水箱/水管，水管像电缆一样不阻挡移动、可铺在墙下并支持按住左键拖动布线。淋浴器自身接 75 W 电，通电为热水澡；断电时若同网有运行中的热水器也能洗热水澡，否则洗冷水澡（仍可使用）。

## 描述

- 淋浴器需要水网供水；1×1，可独立放置，不再使用 `Placeworker_AttachedToWall`，也不需要靠墙。
- 淋浴器有 `CompPowerTrader`（75 W）+ 开关：通电即热水；断电时检查同网热水器；两者都没有就是冷水澡，但不会阻止使用。
- 电热水淋浴器 `CK_ShowerPower` 仍必须通电才能工作。
- 热水器需要电力；只加热管网中的水，不单独储水。
- 水网建筑：1×1 水管（可拖拽、可铺墙下）、1×1 水箱（2000 L）、2×2 巨型水箱（8000 L）、1×1 水泵（1500 L/天，需水井）、1×1 水井（2000 L/天）、1×1 热水器（250 W）。
- 淋浴器同时只被一个 Pawn 预约；排队由 Job 系统处理。
- 断水/拆卸会中断正在进行的洗澡；断电只降级为冷水（电热水淋浴器除外）。
- 水温/季节是否影响热水效果，待定。
- 机器人不需要淋浴，不会使用。

```text
        │                         └─ 有水 → 进入洗澡 Job

        └─ 都断电/关闭：冷水澡（心情 debuff，仍可使用）

        ▼

```

## 如何使用

**前提**：研究「卫生设施」；水网已通；电网容量够。

1. 在浴室/生活区建 `CK_Shower`，确认接到水网。
2. 需要热水时建 `CK_WaterHeater` 并接电。
3. 选中淋浴器查看水网、通电、预约状态。
4. 让小人洗澡；断电/关热水器会洗冷水澡。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 淋浴器不能用 | 没接水网 / 水箱空 / 没电 | 看 Gizmo 状态与 Alert |
| 一直是冷水澡 | 没热水器、热水器断电、管网没热水 | 建/开热水器，检查电网 |
| 建了但没人用 | 卫生值不低、被禁用、路径不通 | 手动 Gizmo 测试 |
