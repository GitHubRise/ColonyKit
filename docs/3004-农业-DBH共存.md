## 简介

DBH 已有灌溉喷头、肥力网格、施肥设计器和 `SectionLayer_FertilizerGrid`。两边同时启用会出现双重灌溉/双重肥力，产量异常。本页定义检测与共存策略。

## 描述

三种策略（M4-6 定稿）：

| 策略 | 做法 | 适合 |
|---|---|---|
| 软停用本模块 | 检测到 DBH 时关闭本模块肥力网格/喷灌，保留堆肥机 | 以 DBH 为主 |
| 共存但分家 | 两套网格不叠加，各管各的 | 想同时用两套设备 |
| 替代 | 声明不兼容 DBH，只装本模块 | 想用完整本 Mod 农业 |

- 当前草案默认：软停用本模块肥力网格/喷灌。
- 检测 `dubwise.dubsbadhygiene`；提示并关闭效果，不删除已建设备。
- DBH 与本模块都在 `CalculateFertilityAt` 上做 Postfix；双重 Patch 是主要风险。
- DBH 给排水与本模块水网不互通。

## 绘制调用逻辑图

```text
ModsConfig.IsActive("dubwise.dubsbadhygiene")
        ├─ 否 → 本模块网格/喷灌正常
        └─ 是 → AgricultureSettings.DbhPolicy
                 ├─ SoftOff → 不叠加本模块肥力，保留堆肥
                 ├─ Coexist → 两套网格独立（需实测）
                 └─ Replace → 不兼容声明
                          │
                          ▼
             Patch_CalculateFertilityAt 顺序/开关检查
```

## 如何使用

1. 同开 DBH 和 ColonyKit，看设置页「农业」分节。
2. 选策略（默认软停用）。
3. 软停用：确认覆盖层不再叠加本模块网格。
4. 共存：确认同一格不双重加成（需实测）。
5. 看 `[ColonyKit][Agriculture] DBH detected` 日志。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 产量高得离谱 | 两套肥力同时生效 | 切软停用，或只留一套 |
| 覆盖层不显示 | 本模块网格被停用 | 看设置页开关 |
| 喷灌机不工作 | 接的是 DBH 水网/没接本模块水网 | 检查管道归属 |
