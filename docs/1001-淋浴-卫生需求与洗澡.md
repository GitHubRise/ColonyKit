## 简介

卫生需求是淋浴模块的核心：给能洗澡的人形加一条 `Need_Hygiene`（0–1），变脏后自动或手动去淋浴器，恢复需求并清掉身上携带的污渍。需求速率、豁免和 DBH 策略在 [1005-淋浴-卫生设置.md](1005-淋浴-卫生设置.md) 中配置。

## 描述

- `Need_Hygiene` 范围 0–1，默认每 150 tick 结算一次；基础下降 `5e-6 × CK_HygieneRateMultiplier × 设置速率 × 环境倍率`。
- 阶段：`Filthy`（0）、`Grimy`（<0.1）、`Fine`（0.1–0.7）、`Clean`（0.7–0.9）、`Squeaky`（≥0.9）；`CK_HygieneDirty` 念头按阶段切换（见 1003）。
- 需求注入：`Patch_NeedsTracker_Hygiene` Postfix 私有的 `Pawn_NeedsTracker.ShouldHaveNeed`，只给通过 `HygieneSettings.ShouldInject` 的人形；不会重复添加。
- 注入判断：模块开关、DBH 策略、人形/非机械体、`NeedDef.minIntelligence`、囚犯/访客/非人形开关、种族/体型/Hediff 豁免。
- 自动洗澡：`JobGiver_HaveWash` 已通过 ThinkTree 补丁加入 `SatisfyBasicNeeds` 与 `MainColonistBehaviorCore`；卫生值低于阈值时优先最近可用的淋浴器，找不到再找浴缸；淋浴器被占用且没有空浴缸时进入等待 Job。
- 手动洗澡：任何殖民者选中后都有「去洗澡」Gizmo（模块运行且存在可用淋浴器时）。
- 洗澡流程：预约淋浴器 → 走到 Touch 格 → 1000 tick 计时（卫生刷满可提前结束）→ 每 tick 扣水/扣热 → 完成。
- 洗后结算：只有卫生真正刷满才清携带污渍、清污染标记、施加浴室/水温/今天洗过念头、检查堵塞、执行淋浴后清理（见 1006）；断水/断电/征兆/精神崩溃中断不结算。
- 排队：没有空淋浴器时 `CK_WaitForShower` 在门口等待，占用者结束后自动接手；不是严格 FIFO（见 1008）。
- 需求存档：`Need_Hygiene` 自身保存 `Contamination`、`ticksAtZero`；`Need_Bladder` 单独见 1009。

## 绘制调用逻辑图

```text
Need_Hygiene 下降
      │ 低于阈值
      ▼
JobGiver_HaveWash（9.25）
      ├─ 找最近可用淋浴器（水网、堵塞、供电、水量）
      ├─ 找不到 → 找浴缸
      └─ 都找不到 → null
      │
      ▼
JobDriver_TakeShower
      ├─ 预约 CK_Shower
      ├─ 走到淋浴器
      ├─ 每 tick：PullWater + PullHotWater + need.clean
      └─ 卫生 >= 1：completed
      │
      ▼
洗后结算：carriedFilth.Clear / 念头 / 清污染 / 堵塞检查 / ShowerCleanup
```

## 所含功能

- 卫生需求注入、衰减、恢复与存档。
- 自动/手动洗澡 Job，预约与中断。
- 洗后清携带污渍、清污染标记。
- 与热水、念头、淋浴后清理、Alert 的联动。

## 如何使用

**前提**：研究「卫生设施」；建好水网并接到淋浴器。

1. 确认水箱有水、淋浴器接水；需要热水时建热水器/热水罐。
2. 卫生值低于阈值会自动去洗；也可以选中殖民者点 Gizmo「去洗澡」。
3. 洗完后看需求条恢复、念头变化。
4. 断水/堵塞/断电/排队时看右侧 Alert（见 1008）。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 小人不去洗澡 | 没水、没电、被预约、路径不通、DBH 策略停用 | 看 Alert 与设置页 DBH 策略 |
| 洗了还是脏 | 只清携带污渍，不清地面/衣物 | 地面清洁用原版清洁；衣物清洁未做 |
| 洗到一半停止 | 水箱空、堵塞、电热水淋浴器断电 | 检查水网/电力；中断不会给洗后念头 |
| 不显示卫生条 | 需求注入失败/该种族被豁免/开了 DBH | 看 `[ColonyKit][Hygiene]` 日志与设置页豁免 |
