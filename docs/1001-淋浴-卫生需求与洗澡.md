## 简介

卫生需求是淋浴模块的核心：给能洗澡的人形加一条 `Need_Hygiene`（0–1），变脏后去淋浴器洗澡，恢复需求并清掉身上携带的污渍。

它是本工程第一个「自定义需求 + 自动 Job + 心情联动」的样板，后续机器人能量、仓库/农业的 UI 状态也会复用同一套需求注入与 Job 结构。

## 描述

- `Need_Hygiene` 范围 0–1，缓慢下降；低于阈值触发「肮脏」念头。
- 需求注入：Postfix `Pawn_NeedsTracker.ShouldHaveNeed`，只给能洗澡的人形加，**只加一次**，不重复。
- 洗澡：`JobDriver_TakeShower` 预约淋浴器 → 到场 → 消耗水 → 恢复需求 → 清 `pawn.filth.carriedFilth`。
- 热水：有 `CK_WaterHeater` 且通电时洗热水澡，否则冷水澡（见 1002/1003）。
- 机器人、动物、不能洗澡的种族不注入该需求。
- 地面污渍、衣物清洁不在本功能内。

## 绘制调用逻辑图

```text
Need_Hygiene 下降
      │ 低于阈值
      ▼
Thought_Dirty（心情 debuff）+ Alert/提示
      │ 玩家手动 / 自动 Job
      ▼
JobDriver_TakeShower
      ├─ 预约 CK_Shower（Reservation）
      ├─ 到场、脱战
      ├─ 检查水网：TryConsume(需求 L) + 热水?
      │        ├─ 无水 → 停机，给出断水原因
      │        └─ 有冷水 → 洗澡 + 冷水澡 debuff
      └─ 完成：Need_Hygiene 恢复，carriedFilth.Clear()
      │
      ▼
Thought_Clean / Thought_ShoweredToday
```

## 所含功能

- 卫生需求注入与只加一次保护。
- 需求衰减、洗澡恢复、存档。
- 自动/手动洗澡 Job、预约与中断。
- 洗净后清空 `carriedFilth`。
- 需求条与 Gizmo 入口。

## 如何使用

**前提**：研究「卫生设施」；建好水网并接到淋浴器。

1. 确认水箱有水、淋浴器通电/接水。
2. 殖民者卫生值低于阈值会自动去洗；也可以选中殖民者点 Gizmo「去洗澡」。
3. 洗澡完成后看需求条恢复、念头变化。
4. 断水/断电/被占用时看 Alert 和 Job 失败原因。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 小人不去洗澡 | 没水、没电、淋浴器被预约、路径不通 | 看 Alert 和 Job 失败原因 |
| 洗了还是脏 | 只洗了人，没有清理地面/衣物 | 首版不管地面；衣物清洁后续 |
| 不显示卫生条 | 需求注入失败或该种族被排除 | 看 `Player.log` 的 `[ColonyKit][Hygiene]` |
