## 简介

蓝图放置前会按当前材料策略逐条选材质，汇总「需要多少 / 地图现有多少」，缺料红色高亮；当前 Mod 列表里不存在的建筑会被跳过并在面板/消息里报数量，不会静默丢失。

## 描述

- 材料按「当前 Def + 条目里的 `stuffDefName` + 当前策略」重新计算；Mod 改配方后数字会变。
- 三档策略（默认「就地取材」）：
  - **原材质优先**：原材质仍能用于该 Def 就直接用（不看库存）；否则选「有库存的最便宜」→「全局最便宜」。
  - **就地取材**：原材质有库存就用；否则选「有库存的最便宜」→「全局最便宜」。
  - **最便宜**：始终选该 Def 可用的最便宜材质。
- 「最便宜」先按 `BaseMarketValue` 升序，再按 `commonality` 降序、`defName` 兜底；候选只取 `stuffProps.canSuggestUseDefaultStuff`（木头/钢铁/石块等），没有推荐项时才放开到全部可用材质；候选按建筑 Def 缓存。
- 「有库存」先要求地图库存 ≥ 单件 `CostStuffCount`；一件都不够时退到「有任何库存」；完全没有库存时退回全局最便宜（放下等料）。
- 材料成本 = `CostStuffCount`（材质）+ `CostList`（固定材料）；按建筑逐条累加，按数量降序显示。
- 缺料**不阻止放置**：预览仍可绿、可以落地，施工等料；只有「需要材质但完全选不出可用材质」才会整张拒绝（`CK.Blueprint.Place.NoStuff`）。
- 缺 Def 的条目直接跳过，不计入材料；面板黄色显示「将跳过 X 个建筑」，落地后消息再报一次。
- 材质被替换时，蓝图页列出「原 X → Y」，放置面板显示替换条数；上帝模式仍按策略选材质，但跳过研究检查，也不因缺料阻塞（普通模式同样不因缺料阻塞）。

## 绘制调用逻辑图

```text
BlueprintRecord.entries
        │ 逐条
        ▼
ThingDef（defName 缺失 → 跳过 + missingDef）
        │
        ▼
BlueprintMaterialPolicy.Resolve(def, stuffDefName, mode, map)
        ├─ def 不需要材质 → null
        ├─ 原材质可用？ → 按策略决定是否直接用
        ├─ 有库存的最便宜（先够单件，再任何库存）
        └─ 全局最便宜（按 BaseMarketValue/commonality/defName）
        │
        ▼
BlueprintPlacementUtility.AddCost
        ├─ CostStuffCount → 材质数量
        └─ CostList → 固定材料
        │
        ▼
TotalCost（放置面板）/ CostSummary（蓝图页）
        ├─ 需求 vs CountOnMap → 缺料红色
        └─ 原材质 ≠ 实际材质 → BlueprintSubstitution
```

## 所含功能

- 三档材料策略（原材质优先 / 就地取材 / 最便宜），默认就地取材。
- 总材料需求 vs 地图现有，缺料红色。
- 材质替换说明（原 X → Y）。
- 缺 Def 跳过与计数提示。
- 库存不足不阻塞落地。
- 上帝模式直接建成。

## 如何使用

1. 蓝图页顶部或设置页选择材料策略；顶部按钮会立即写入 Mod 设置。
2. 选中蓝图，右侧材料区看「材料 ×需求（现有 N）」；红色 = 缺料。
3. 放置模式看左下角面板：策略、缺 Def 数、失败原因、前 4 项材料。
4. 缺料可以先放等料，或先去补料/换策略。
5. 出现「缺少建筑」提示时，确认缺哪个 Mod；该条会被跳过，其余建筑照常落地。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 材料数比预期多 | 多格建筑逐条计数、Mod 配方变化、材质替换 | 看逐项清单与策略 |
| 材质变了 | 原材质不可用/无库存，被策略替换 | 换「原材质优先」或补原材质 |
| 提示「找不到可用材料」 | 该 Def 需要材质，但候选池为空 | 检查材质类别/Mod 数据 |
| 缺料却是绿预览 | 库存不影响可放置判定 | 放下后等料 |
| 缺了几栋 | 缺 Def 被跳过 | 看黄色提示与消息，补 Mod |
| 上帝模式还要材料吗 | 不需要；直接建成，但仍按策略选材质 | 需要特定材质时先调策略 |
