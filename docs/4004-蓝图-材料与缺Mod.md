## 简介

放置前给出总材料需求 vs 地图现有清单，缺料高亮；蓝图里如果有当前 Mod 列表不存在的建筑，跳过并给警告清单，不静默丢。

## 描述

- 材料按「当前 Def + 捕获时材质」重新计算；Mod 改配方后数字会变。
- 缺 Def 的条目跳过，不生成占位建筑；警告清单可复制。
- 材质保留；该材质 Def 也不存在时退回默认或跳过（M5-6 定稿）。
- 地形不参与材料统计（首版不含地形）。
- 材料不够也可以放，施工会等料。
- 导入/导出 JSON 排到 M5-7；首版只在本存档内使用。

## 绘制调用逻辑图

```text
BlueprintRecord
      │
      ▼
逐条解析 defName / stuff
      ├─ Def 存在 → 计入材料
      └─ Def 缺失 → 跳过 + 警告清单
      │
      ▼
材料清单（需要 vs 地图现有）
      │
      ├─ 缺料 → 红色高亮，仍可放
      └─ 充足 → 正常放置
      │
      ▼
PlaceBlueprintForBuild
```

## 所含功能

- 总材料需求 vs 现有。
- 缺料高亮/提示。
- 缺 Def 跳过 + 警告。
- 材质缺失回退。
- 导入/导出（后续）。

## 如何使用

1. 放置模式看材料清单「需要 / 现有」。
2. 红色 = 缺料；可先放等料，或去补料。
3. 看「缺失建筑」警告，确认缺哪个 Mod。
4. 导入/导出等 M5-7 实现后再用。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 材料数比预期多 | 多格/材质/Mod 配方变化 | 看逐项清单 |
| 放了缺几栋 | 缺 Def 被跳过 | 看警告清单，补 Mod |
| 材质变了 | 原材质缺失，退回默认 | 记录并手动改 |
