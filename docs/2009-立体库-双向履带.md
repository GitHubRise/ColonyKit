## 简介

`CK_ConveyorBelt` 是便宜的 **1×1 双向履带**：只支持正向/反向，不转向。需要转向时用 1×1 的 `CK_ConveyorHub` 转向盘；两者相邻时可以互相接货，铺成直线传送。

## 描述

- 占地：**1×1**；`rotatable=true`，旋转改变正向。
- 成本：**15 钢 + 1 零部件**，100 HP；适合战斗后临时铺一段。
- 只支持正向/反向：没有中央转盘，不处理转向。
- 每 **30 tick** 把物品向建筑朝向的出口推一格。
- 出口格如果是另一条 1×1 履带或转向盘，物品会交接过去；如果是地面，就落地。
- `maxItemsInCell=1`：每格允许放一堆物品，普通掉落/搬运可以放上去。
- 选中后「反向运行」Gizmo 切到对侧，仍然只沿一条直线。
- 方向推断：站在立体库正中端口的履带默认朝外（输出）；下游履带沿用上游流向；只有单轴邻居时横向朝东、纵向朝北。
- 端口语义：端口履带默认朝仓库（入库）；反向 Gizmo 后朝外（出库）。方向未对准时仓库会提示。`n- 端口几何按 `GenAdj.OccupiedRect` 计算；3×3 仓库的 `Position` 是中心格，不能再用 `Position + size`。
- 贴图 128×128，静态竖直履带/中央转轴；方向箭头在**选中或有货物**时由 `DrawAt` 叠加，空闲未选中不显示；旋转 90° 后跟随建筑方向。

## 绘制调用逻辑图

```text
1×1 履带
  └─ ThingDef CK_ConveyorBelt
        ├─ size (1,1)
        ├─ thingClass=Building_BidirectionalConveyor
        ├─ tickerType=Normal / drawerType=RealtimeOnly
        ├─ maxItemsInCell=1
        └─ passability=PassThroughOnly

每 30 tick
  └─ Building_ConveyorBase.Tick
        └─ MoveItems
              ├─ 当前格有物品
              ├─ next = Position + OutputDirection.FacingCell
              ├─ 下一格是履带 → 交接
              └─ 下一格是地面 → 落地

直线
  [1×1] → [1×1] → [1×1] → 地面
     每格 30 tick；相邻履带自然接货
```

## 所含功能

- 便宜的 1×1 双向履带。
- 正向/反向。
- 30 tick/格自动移动物品。
- 相邻 1×1/2×2 履带互相接货。
- 可通行、可拆除、可旋转。

## 如何使用

1. **Furniture → 双向履带**，1×1 放置。
2. 旋转到需要方向；连续放多个，形成直线。
3. 把物品丢/搬到履带上；它会每 30 tick 向出口移动。
4. 接上 1×1 转向盘后，由转向履带改变方向。
5. 选中任意履带点「反向运行」可反向。

## 常见问题

**Q：1×1 能转向吗？**  
A：不能。它只沿建筑朝向直走；转向用 1×1 转向盘。

**Q：多条双向履带会互相卡住吗？**  
A：不会。出口格有另一条履带时直接交接；目标格已有一堆时等下一轮。

**Q：为什么不用 转向盘铺直线？**  
A：2×2 成本高、占地大；直线/战斗临时传送用 1×1 更便宜。
