## 简介

`CK_ConveyorBelt` 是便宜的 **1×1 履带**：不依赖玩家摆方向，物品沿相邻履带自动找最近的立体库并逐格前进；到仓库旁边就自动入库。当前暂停开发，建造菜单里没有它。

## 描述

- 占地 **1×1**，`rotatable=true`（旋转只影响贴图/箭头基准，自动路由不依赖朝向）。
- 成本 **15 钢 + 1 零部件**；100 HP / 5 质量 / 250 工作量；`maxItemsInCell=1`；可通行（PassThroughOnly）；可拆除/可最小化搬运（`minifiedDef`）。
- 研究前置：三级立体仓库技术 `CK_StorageTier3`。
- **没有 `designationCategory`**：正常建造菜单不可见，属于暂停开发；可通过开发者/蓝图/已有存档测试。
- 不耗电。
- 移动：`Building_ConveyorBase.Tick` 每 **30 tick**（`MoveIntervalTicks`）处理一次：
  1. 当前格物品先看是否贴立体库：`TryStoreAdjacent`，贴边则 `TryStoreInNetwork` 直接入库；
  2. 否则在相邻 `Building_ConveyorBase` 网络中 BFS，找“贴仓库”的履带格，向第一步移动；
  3. 无路可走/目标格满/前方是墙时留在原地。
- 只搬 `ThingCategory.Item`；跳过尸体、最小化建筑、堆数 ≤0。
- 箭头：选中或载货时显示两枚沿路由方向移动的箭头；空闲未选中不显示。
- 检视字符串：显示“自动输送至最近的立体库 (x,z)”或“附近没有可用的立体库”。
- 没有“反向运行”Gizmo、没有端口/方向切换、没有出库；履带只负责送进仓库。

## 绘制调用逻辑图

```text
每 30 tick
  └─ Building_ConveyorBase.Tick
        └─ MoveItems
              ├─ 遍历占用格物品
              ├─ TryStoreAdjacent
              │     ├─ 扩展 1 格内有立体库 → TryStoreInNetwork
              │     └─ 四邻 `GetEdifice` 是立体库 → TryStoreInNetwork
              └─ TryFindNextCell（BFS 相邻履带）
                    ├─ 找到贴仓库的履带格 → 移动到第一步
                    └─ 否则原地等待

线路
  [履带] → [履带] → [转向盘] → [履带] → [立体库]
       每格 30 tick；任何相邻边都能入库
```

## 所含功能

- 1×1 履带，自动路由到最近立体库。
- 自动入库，任意相邻边都算连接。
- 30 tick/格移动，可拐弯（靠相邻履带/转向盘）。
- 可通行、可拆除、可最小化搬运。
- 选中/载货箭头显示。

## 如何使用

1. 当前正常建造菜单没有该建筑；测试时用开发者/蓝图/已有存档。
2. 连续铺履带到立体库任意一条边旁；不需要旋转/端口。
3. 把物品丢/搬到履带上，或让它承接上游履带。
4. 选中履带看检视字符串，确认目标仓库。
5. 取出用立体库面板/自动出库 Job，履带不负责出库。

## 常见问题

**Q：1×1 能转向吗？**  
A：能，靠相邻履带/转向盘自动路由；不需要玩家设出口方向。

**Q：需要反向 Gizmo 吗？**  
A：不需要，当前没有该 Gizmo；路由由 BFS 决定。

**Q：多条履带会互相卡住吗？**  
A：不会；目标格有另一条履带就交接，目标格已满就等下一轮。

**Q：为什么建造菜单找不到？**  
A：暂停开发，Def 没有 `designationCategory`；需要开发者/蓝图生成。

**Q：能把库内物品送出来吗？**  
A：不能；履带只入库。
