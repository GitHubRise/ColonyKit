## 简介

本地化是 ColonyKit 的第六个「模块」，但代码很少：主体是 `Languages/` 下的 Keyed 与 DefInjected、术语表、文风指南，以及一个把「源码使用的 key / Def 的 defName」和语言文件对账的脚本。

英文是唯一基准；简中必须完整；繁中是否随首版发在 M7-4 确认。目标是任何界面都不出现 `Keyed.xxx`。

## 描述

- Keyed 键规范：`ColonyKit.<Module>.<Area>.<Name>`，例如 `ColonyKit.Hygiene.Settings.WaterPerShower`。
- DefInjected：按 Def 类型分目录（`ThingDef`、`ResearchProjectDef`、`HediffDef`、`NeedDef`…），键格式 `<defName>.<field>`；自定义 Def 用类型全名目录。
- 文件按模块拆分：`Languages/<Lang>/Keyed/ColonyKit_<Module>.xml`，避免单文件冲突。
- 术语表与文风写 `docs/l10n.md`：单位（L、W、tick/天）、语气、标点、数字格式。
- `tools/check-l10n.ps1`：
  - 扫描 `Source/**/*.cs` 的 `"...".Translate` 与 `Keyed` 引用；
  - 扫描 `Defs/**/*.xml` 的 `defName`；
  - 对比 `Languages/English` 与 `Languages/ChineseSimplified`；
  - 输出缺失/多余/空值；缺简中直接失败。
- 接入 `verify.ps1`：本地化缺失 = 校验失败，不能只靠人眼。
- 中文排版：长句换行、标点挤压、字体回退；只有实测有问题才加最小补丁，并记录到 `docs/l10n.md`。
- 设置页、研究页、提示、拒绝原因、Alert 全部可翻译。

## 绘制调用逻辑图

```text
代码:
  "ColonyKit.Hygiene.Settings.WaterPerShower".Translate()
        │
        ▼
Languages/<Lang>/Keyed/*.xml
        │  缺 key → 界面显示 Keyed.xxx（不允许）
        ▼
check-l10n.ps1
  ├─ 收集源码 key
  ├─ 收集 Def defName
  ├─ 对比 English / ChineseSimplified
  └─ 缺失 → exit 1 → verify.ps1 失败 → package.ps1 中止

Def:
  Defs/Hygiene/Things.xml  <defName>CK_Shower</defName>
        │
        ▼
Languages/<Lang>/DefInjected/ThingDef/CK_Shower.xml
  <CK_Shower.label>淋浴间</CK_Shower.label>
```

## 函数清单

> 规划脚本/接口；M7 落地时以实际实现为准。

| 脚本 / 接口 | 签名（规划） | 作用 |
|---|---|---|
| `tools/check-l10n.ps1` | `pwsh -File tools/check-l10n.ps1 [-Fix]` | 对账并输出缺失/多余 |
| `check-l10n.ps1 -Strict` | `switch` | 缺简中/空值直接失败（verify 用） |
| `verify.ps1` 本地化段 | 调用 `check-l10n -Strict` | 把本地化纳入静态校验 |
| `Keyed` 键规范 | `ColonyKit.<Module>.<Area>.<Name>` | 命名约定 |
| `DefInjected` 目录规范 | `<DefType>/<defName>.xml` | 翻译 Def 字段 |

## 所含功能

- Keyed 命名与分模块文件；
- DefInjected 目录/键规范；
- 英文基准 + 简中完整；
- 术语表与文风；
- 自动对账（缺失/多余/空值）；
- 校验接入打包流程；
- 中文排版问题记录；
- 可选繁中/其他 Mod 汉化（先确认范围）。
