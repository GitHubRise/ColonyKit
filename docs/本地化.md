## 简介

模板的本地化分两类：**Keyed**（代码里 `"...".Translate()` 的字符串）和 **DefInjected**（Def 字段，如 `label` / `description`）。英文是基准，简中完整；目前中英各 50 个 Keyed 键，DefInjected 各一份。

## 描述

- Keyed 目录：`Languages/<Lang>/Keyed/ModTemplate.xml`，键名统一 `ModTemplate.*`。
- 键分组：
  - `ModTemplate.SettingsCategory`；
  - `ModTemplate.Settings.*`：页签、提示、重置、分区标题；
  - `ModTemplate.TrackSpawns*`：常规页勾选与 Tooltip；
  - `ModTemplate.Settings.Logging.VerboseSpawn*`：日志明细开关与锁定提示；
  - `ModTemplate.Settings.LogDetail.*`：日志级别枚举；
  - `ModTemplate.TechTree.*`：科技树窗口/布局/Tooltip；
  - `ModTemplate.LogLevel.*` / `ModTemplate.Settings.Diagnostics.*`：日志级别与诊断按钮；
  - `ModTemplate.Settings.Tab.Modules` / `ModTemplate.Module.*`：模块页与模块名/说明；
  - `ModTemplate.Settings.Search.*`：检索占位与无结果提示；
  - `ModTemplate.Settings.ControlMode.*` / `ModTemplate.Settings.Cycle.*` / `ModTemplate.Settings.CheckCross.*`：选项控件模式与箭头/打勾提示；
  - `ModTemplate.Settings.Notifications.*` / `ModTemplate.Notification.*`：通知页与测试消息；
  - `ModTemplate.Menu.*` / `ModTemplate.Build.*`：右键菜单与建造拒绝原因；
  - `ModTemplate.EnablePawnMenu*` / `ModTemplate.ShowTechTreeButton*`：常规页的界面开关。
- DefInjected 有两类目录：
  - `DefInjected/ModTemplate.DemoConfigDef/Default.xml`（自定义 Def 字段）；
  - `DefInjected/MainButtonDef/ModTemplate_TechTree.xml`（底部按钮 `label` / `description`）。
- 键格式 `<defName>.<field>`，目录名是 Def 类型全名。
- 新增语言：复制 `English` 目录改名为目标语言（如 `ChineseTraditional`），翻译 Keyed 与 DefInjected；`About.xml` 的 `supportedVersions` 不变。
- 键名是代码契约：`"ModTemplate.Xxx".Translate()` 与 XML 键必须完全一致；缺键会在界面显示 `Keyed.xxx`。
- 模板没有自动对账脚本；ColonyKit 计划的 `check-l10n.ps1` 可参考实现。

## 绘制调用逻辑图

```text
代码:
  "ModTemplate.Settings.Tab.Logging".Translate()
        │
        ▼
LoadedLanguage 扫描 Languages/<当前语言>/Keyed/*.xml
        └─ 命中 key → 返回译文
        └─ 未命中 → 返回 "Keyed.xxx"（界面可见）

Def 字段:
  Defs/DemoConfig.xml  <defName>Default</defName>
        │
        ▼
Languages/<Lang>/DefInjected/ModTemplate.DemoConfigDef/Default.xml
  <Default.label>演示配置</Default.label>
        └─ 在 Def 加载后注入 label/description
```

## 函数清单

| 接口 / 约定 | 形式 | 作用 |
|---|---|---|
| Keyed 键 | `"ModTemplate.<Area>.<Name>".Translate()` | 代码字符串翻译 |
| Keyed 文件 | `Languages/<Lang>/Keyed/ModTemplate.xml` | 键值表 |
| DefInjected 目录 | `Languages/<Lang>/DefInjected/<DefTypeFullName>/` | 按 Def 类型分目录 |
| DefInjected 键 | `<defName>.<field>` | 翻译 Def 字段 |
| `Translate(args)` | `"…{0}…".Translate(value)` | 带参数文案 |
| `TaggedString.ToString()` | `.ToString()` | Tooltip/日志里取纯文本 |
