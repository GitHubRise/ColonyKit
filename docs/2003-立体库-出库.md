## 简介

从立体库 ITab 选物品「取出」：生成出库 Job，把物品放到出库口或指定库存区；支持整堆/按数量。

## 描述

- 出库口是固定格；也可以指定一个库存区/格作为目标。
- 取出的物品先进入「出库中」并预约，避免重复取。
- 目标满/不允许/不可达时 Job 失败，物品留在库内，不凭空消失。
- 断电/禁用时不能出库。
- 一次取大量物品会生成多个搬运 Job。
- 原版账单能否直接取料见 2005。

## 绘制调用逻辑图

```text
ITab 选物品 → 点「取出」
      │
      ▼
JobDriver_WithdrawFromWarehouse
      ├─ 从 ThingOwner 取货（预约）
      ├─ 走到出库口 / 目标库存区
      ├─ 目标可放 → 放下
      └─ 目标不可放 → 留在身上/库内，Job 失败
      │
      ▼
ITab 数量减少；地图出现物品
```

## 所含功能

- ITab 取出（整堆/数量）。
- 出库口/目标库存区。
- 预约与重复取保护。
- 失败回滚/提示。
- 与账单取料的衔接（2005）。

## 如何使用

**前提**：库内有目标物品；有搬运工；目标可达。

1. 选中立体库，打开 ITab。
2. 选物品 →「取出」→ 整堆/数量 → 目标。
3. 搬运工接 Job；在 ITab 确认数量减少。
4. 目标出现物品后正常使用。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 点了取出没反应 | 没搬运工/目标不可达/库断电 | 看 Job 失败原因 |
| 物品取到一半停了 | 目标满了/被禁用 | 清目标或换目标 |
| 找不到出库口 | 出库口被建筑/物品占住 | 清空出库口 |
