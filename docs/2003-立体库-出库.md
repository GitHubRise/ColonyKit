## 简介

从立体库 ITab 选物品「取出」：生成出库 Job，把物品放到出库口或指定库存区；支持整堆/按数量。

## 描述

- **自动出库**：立体库默认 Low 优先级；当某个普通库存区比它优先级更高且能放下该物品时，`WorkGiver_WithdrawFromWarehouse` 生成出库 Job。
- `JobDriver_WithdrawFromWarehouse`：走到库 → 从 `ThingOwner` 取出一整堆 → 放到目标库存格。
- **手动出库**：库存 ITab 仍可逐堆「取出」，直接放到建筑旁。
- 目标格由原版 `StoreUtility.TryFindBestBetterStoreCellFor` 选择；目标满/不可达时本轮跳过。
- 出库 Job 预约仓库和目标格，避免两个小人同时操作同一仓库。
- 当前不按数量拆分、没有固定出库口、不接原版账单；账单见 2005。

## 绘制调用逻辑图

```text
普通库存区 / 账单需要物品
      │
      ▼
WorkGiver_WithdrawFromWarehouse
      ├─ 遍历库内物品
      ├─ StoreUtility.TryFindBestBetterStoreCellFor（高于仓库优先级）
      └─ 找到目标 → JobMaker(CK_WithdrawFromWarehouse, 库, 格, 物品)
                        │
                        ▼
              JobDriver_WithdrawFromWarehouse
                        ├─ 预约仓库 + 目标格
                        ├─ 走到仓库
                        ├─ Container.Take 一整堆
                        ├─ 生成到脚边 + CarryTracker
                        ├─ 走到目标格
                        └─ PlaceHauledThingInCell
      │
      ▼
仓库堆数减少；目标库存区增加
```

## 如何使用

**前提**：库内有目标物品；有搬运工；目标可达。

1. 建一个普通库存区（Normal 或更高优先级），确保它能放该物品。
2. 立体库默认 Low；搬运工会自动把物品从库内送到库存区。
3. 也可以选中立体库，在 ITab 里手动逐堆「取出」。
4. 目标不可达/满时，自动出库会跳过；检查库存区设置。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 库内物品不自动出去 | 库存区优先级不高于仓库/目标满/不可达 | 提高库存区优先级或清位置 |
| 点了取出没反应 | 没搬运工/库断电 | 看 Job/电力 |
| 物品取到一半停了 | 目标满了/被禁用 | 清目标或换目标 |
| 出库目标变成仓库自己 | 仓库优先级不低于普通库存区 | 把仓库优先级调低 |
