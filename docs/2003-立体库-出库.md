## 简介

出库有两条路：**自动出库**（送到优先级更高的库存区）和 **手动取出**（检视面板逐堆取出，放到建筑交互格附近）。

## 描述

### 自动出库

- 扫描器：`WorkGiver_WithdrawFromWarehouse`，工作类型 **Hauling**，`priorityInType=16`，需要 `Manipulation`。
- 候选建筑：`ThingRequestGroup.BuildingArtificial` 中的玩家立体库；要求建筑已生成、`Container.Count > 0`、小人能到 `InteractionCell`。
- 选物品：`FindWithdrawable` 遍历库内堆，对每一堆调用原版 `StoreUtility.TryFindBestBetterStoreCellFor(candidate, pawn, map, current=仓库优先级, faction, out cell)`；只接受**优先级严格更高**且小人可达的目标格。取第一个满足条件的堆。
- 生成 Job：`JobMaker.MakeJob(CKDefOf.CK_WithdrawFromWarehouse, warehouse, cell, stored)`；预约仓库和目标格（不预约物品本身）。
- 执行：走到仓库 → `Container.Take(item, min(stackCount, def.stackLimit))` 取一块 → 先放在小人脚边 → `carryTracker.TryStartCarry` → 搬到目标格 → `Toils_Haul.PlaceHauledThingInCell(storageMode: true)`。
- 库内超限堆按**当前全局 `stackLimit`**分块；一次 Job 只搬一块，剩余继续留在库里。
- 目标格满/不可达/物品在途中变化时本轮跳过；放置失败会把取出的块强制放回库内（`TryAddForced`）并结束 Job。

### 手动取出

- 检视面板 `ITab_VerticalWarehouse` 每行有「取出」按钮，调用 `TryWithdraw(thing)`。
- `TryWithdraw` = `TryWithdrawAt(thing, InteractionCell)`：取 `min(stackCount, def.stackLimit)` 一块，优先直接放到交互格，失败则放到附近；再失败强制放回。
- Gizmo「取出全部」循环调用 `TryWithdraw`，直到库空或某次取出失败；每次仍按全局上限分块。
- 手动取出不需要电/小人；物品直接掉到建筑旁。

### 当前范围

- 没有按数量输入框；每次「取出」= 一个全局上限块。
- 没有固定出库口/出库履带；目标是原版库存格或建筑交互格。
- 不能作为原版账单的取料来源（见 2005）。
- 自动出库只对**优先级高于仓库**的库存区生效；仓库默认 **Normal**。

## 绘制调用逻辑图

```text
自动出库
  普通库存区优先级 > 仓库优先级
        │
        ▼
WorkGiver_WithdrawFromWarehouse
        ├─ 遍历库内堆
        ├─ TryFindBestBetterStoreCellFor(current=仓库优先级)
        ├─ 目标可达
        └─ Job(CK_WithdrawFromWarehouse, 仓库, 目标格, 堆)
                  │
                  ▼
        JobDriver_WithdrawFromWarehouse
                  ├─ 预约仓库 + 目标格
                  ├─ Take(min(堆数, 全局上限))
                  ├─ 放到脚边 + TryStartCarry
                  ├─ 走到目标格
                  └─ PlaceHauledThingInCell

手动取出
  ITab「取出」/ Gizmo「取出全部」
        └─ TryWithdrawAt(thing, InteractionCell)
              ├─ Take(min(堆数, 全局上限))
              ├─ TryPlaceThing(Direct → Near)
              └─ 失败 → TryAddForced 回滚
```

## 所含功能

- 自动出库到更高优先级库存区。
- 手动逐堆取出、取出全部。
- 库内超限堆按全局上限分块。
- 仓库/目标格预约。
- 取出失败回滚。

## 如何使用

**自动出库**：

1. 建一个能放目标物品的普通库存区。
2. 把库存区优先级调到**高于**立体库（仓库默认 Normal）。
3. 搬运工会自动把库内物品搬到库存区；目标满/不可达时会跳过。

**手动取出**：

1. 选中立体库，打开检视面板。
2. 每行点「取出」取一块；或点 Gizmo「取出全部」。
3. 物品会落在交互格/建筑旁，需再搬运。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 库内物品不自动出去 | 库存区优先级不高于仓库/目标满/不可达 | 提高库存区优先级或清位置 |
| 点「取出」只掉出一小堆 | 按全局 `stackLimit` 分块，超限堆需多次取 | 多点几次或「取出全部」 |
| 自动出库只搬一堆 | 每次 Job 一块；搬完后再接下一 Job | 正常 |
| 目标格变成仓库自己 | 仓库优先级不低于库存区 | 降低仓库优先级 |
| 账单还是不取库内物品 | 库内 `ThingOwner` 对账单不可见 | 用自动出库/手动取出，见 2005 |
