## 简介

设置窗口默认是多页签形态：`SettingsController` 统一画标签栏、工具栏、滚动和重置，页面只实现 `DoContents`。数据按页拆成 `IExposable` 对象，由 `ModTemplateSettings` 用 `Scribe_Deep` 嵌套保存。

模板自带四页：常规（`general`）、日志（`logging`）、通知（`notifications`）、关于（`about`，只读）。

## 描述

- `SettingsPage` 抽象：`Id`、`TitleKey`、`Order`、`Visible`、`CanReset`、`DoContents(Listing_Standard, ModTemplateSettings)`、`Reset`。
- `SettingsController`：
  - 构造时收集页面，`Where(Visible)` + `OrderBy(Order)`；
  - `DrawTabs`：`DrawOptionBackground` + `ButtonInvisible` + 居中标题，点击播放 `SoundDefOf.Click`；
  - `DrawToolbar`：提示文字 + 「重置本页」+「全部重置」（`Dialog_MessageBox` 确认）；
  - `DrawPage`：按 `SettingsPage.Id` 缓存滚动位置和内容高度，用 `Widgets.BeginScrollView` 包裹一个 `Listing_Standard`；
  - `CanReset == false` 的页面隐藏「重置本页」。
- 持久化：`ModTemplateSettings.general` / `.logging` 两个 `Scribe_Deep` 节点；页面每次绘制都从 `settings.xxx` 取数据，避免 `Scribe_Deep` 读档替换实例后旧引用失效。
- 保存：`Dialog_ModSettings.PreClose()` 自动 `Mod.WriteSettings()`；「恢复默认」只改内存。
- 新增一页：数据类 + 页面类 + 在 `SettingsController` 页面列表注册（有独立数据时再补一行 `Scribe_Deep`）。

最小接入示例：

```csharp
// 1) Data/FooSettings.cs：IExposable + ExposeData/Reset
// 2) Pages/FooSettingsPage.cs：
public sealed class FooSettingsPage : SettingsPage
{
	public override string Id => "foo";
	public override string TitleKey => "ModTemplate.Settings.Tab.Foo";
	public override int Order => 30;

	public override void DoContents(Listing_Standard listing, ModTemplateSettings settings)
	{
		SettingsWidgets.Section(listing, "ModTemplate.Settings.Section.Foo".Translate());
		SettingsWidgets.Checkbox(listing, "ModTemplate.Foo.Enabled".Translate(),
			ref settings.foo.enabled);
	}
}

// 3) SettingsController 的 pages 列表里加：new FooSettingsPage()
```

## 绘制调用逻辑图

```text
Dialog_ModSettings.DoWindowContents(rect)
        │
        ▼
ModTemplateMod.DoSettingsWindowContents(rect)
        └─ 首次：new SettingsController(Settings)
        └─ controller.Draw(rect)
              ├─ DrawTabs：按 Order 画页签，点击切换 selectedIndex
              ├─ DrawToolbar：重置本页 / 全部重置
              └─ DrawPage：
                    ├─ 取 page.Id 的 scroll / 高度缓存
                    ├─ Widgets.BeginScrollView
                    ├─ new Listing_Standard().Begin(viewRect)
                    ├─ page.DoContents(listing, settings)
                    └─ 记录 listing.CurHeight、scroll

关窗:
  Dialog_ModSettings.PreClose() → Mod.WriteSettings()
        └─ ModTemplateSettings.ExposeData()
              ├─ Scribe_Deep(general)
              └─ Scribe_Deep(logging)
```

## 函数清单

| 类型 / 函数 | 签名 | 作用 |
|---|---|---|
| `SettingsPage.Id` | `abstract string Id { get; }` | 稳定标识（滚动缓存 key） |
| `SettingsPage.TitleKey` | `abstract string TitleKey { get; }` | 页签翻译键 |
| `SettingsPage.Order` | `abstract int Order { get; }` | 页签排序 |
| `SettingsPage.Visible` | `virtual bool Visible => true` | 条件隐藏 |
| `SettingsPage.CanReset` | `virtual bool CanReset => true` | 控制「重置本页」 |
| `SettingsPage.DoContents` | `abstract void DoContents(Listing_Standard, ModTemplateSettings)` | 页面内容 |
| `SettingsPage.Reset` | `virtual void Reset(ModTemplateSettings)` | 单页重置 |
| `SettingsController` | `SettingsController(ModTemplateSettings)` | 收集并排序页面 |
| `SettingsController.Draw` | `void Draw(Rect)` | 画整个窗口 |
| `ModTemplateSettings` | `class : ModSettings` | 设置根，嵌套两页数据 |
| `ModTemplateSettings.ExposeData` | `override void ExposeData()` | `Scribe_Deep` 两页 |
