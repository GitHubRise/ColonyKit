## 简介

每种机器人默认只做一类工作，避免「全能机器人」让殖民者失业；玩家可以在设置里决定是否解锁 Work 页自由改。

## 描述

| 型号 | 默认优先级 | 说明 |
|---|---|---|
| 搬运机器人 | `Haul` = 1，其余 0 | 只搬不清洁/不做饭 |
| 清洁机器人 | `Clean` = 1，其余 0 | 只清洁不搬运 |
| 做饭机器人 | `Cook` = 1，其余 0 | 只做饭；不种植/屠宰 |
| 医疗机器人 | `Doctor` = 1，其余 0 | 照顾病人；手术待定 |
| 战斗机器人 | 全部 0，只能 draft | 不参与日常 work |

- 工作锁默认开；设置页有「允许自定义机器人工作」开关。
- 技能按型号固定相关技能较高；是否学习/衰减 M6-2 定稿。
- 机器人没有 Food/Rest/Joy/Mood/Social 需求；不会因加班掉心情，只会耗电。
- 医疗机器人首版只照顾/治疗；手术待 M6-0。
- 机器人不参与社交/恋爱/生育，不安排社交工作。

## 绘制调用逻辑图

```text
PawnKindDef（型号）
      │ 默认工作/技能
      ▼
Pawn_WorkSettings
      ├─ 工作锁开 → 只启用型号工作
      ├─ 解锁 → 玩家可改优先级
      └─ 战斗机器人 → 全 0，只能 draft
      │
      ▼
WorkGiver（Haul/Clean/Cook/Doctor）→ Job
```

## 所含功能

- 5 型号默认工作。
- 工作锁/解锁。
- 技能/优先级。
- 医疗/做饭/清洁/搬运兼容。
- 战斗机器人不参与 work。

## 如何使用

1. 选中机器人，打开 Work 页（解锁时）或设置页（锁定时）。
2. 默认锁定；设置页可解锁。
3. 解锁后像殖民者一样调优先级。
4. 确保医疗有药、做饭有食材/灶台。
5. 战斗机器人手动 draft。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| Work 页改不了 | 工作锁开着 | 设置页解锁 |
| 机器人不干活 | 优先级 0/没材料/没目标 | 看 Work 页与 Job |
| 医疗机器人不救人 | 没药/没床/区域限制 | 检查药品与允许区域 |
