## 简介

说明三件容易踩坑的事：原版账单能不能直接取库内物品、断电会怎样、拆除/被毁时库存去哪。

## 描述

### 账单取料：仍不支持

- 立体库物品在 `WarehouseThingOwner`（`ThingOwner`）里，不在 `ListerThings`，账单/工作台的 `GenClosest`、`ListerThings` 搜索看不到它们。
- 目前**没有** `Patch_ListerThings` 或取货请求机制（2006 里写的“账单直接取库内物品”仍未做）。
- 唯一相关补丁是 `Patch_ResourceCounter`：只在 `ResourceCounter.UpdateResourceCounts` 后把库内 `CountAsResource` 且未腐烂/未雾藏的物品计入底部资源列表；它不改变账单取料。
- 变通：
  1. 用自动出库把料送到**优先级更高**的库存区（见 2003）；
  2. 手动「取出」到工作台旁；
  3. 把工作台/库存区放在立体库旁边，减少二次搬运。

### 电力

- `CompPowerTrader` 额定 **250W**，只用于 `CompTempControl` 制冷。
- 断电：温控停止（`operatingAtHighPower=false`），但**入库、出库、检视、取出、收集、拆除取出都不依赖电力**，库存不丢。
- 恢复供电后温控在下一个 `TickRare` 自动继续；中断的搬运 Job 由原版 Job 系统重排，不会由本模块补做。
- 没有备用电池/待机功耗设置；待机功耗由 `CompTempControl.lowPowerConsumptionFactor` 决定（原版属性）。

### 拆除/被毁

- `Building_VerticalWarehouse.Destroy` 在 `base.Destroy` 前调用 `WithdrawAll`：
  - 每次按全局 `stackLimit` 取一块，放到 `InteractionCell`；放不下则 `ThingPlaceMode.Near`；
  - 两次都失败时 `TryAddForced` 把物品塞回库内并返回 false，`WithdrawAll` 停止。
- 如果 `WithdrawAll` 因落点失败而停止，随后 `base.Destroy` 可能让剩余库存随建筑消失；**拆前先清空周围并点「取出全部」**。
- 被毁（DestroyMode.KillFinalize 等）也走 `Destroy`；没有单独掉落保护。
- 没有“升级保留库存”逻辑，因为当前没有容量/材料升级。

### 腐烂/防火

- 库内物品仍是 `Thing`，随容器 tick；没有额外腐烂/防火策略，也不做真空/隔绝。
- 是否腐烂取决于物品自身的 `CompRottable` 和原版规则；本模块只负责存取与温控。
- 温控会降低房间温度，从而影响腐烂速度；但温控只制冷，不能加热。

## 绘制调用逻辑图

```text
原版账单/工作台
      │ GenClosest / ListerThings
      ▼
库内 ThingOwner 不可见 ──→ 找不到料
      │
      ├─ 自动出库到更高优先级库存区（2003）
      └─ 手动取出到工作台旁

断电
  └─ CompPowerTrader.PowerOn = false
        └─ TickRare 停温控；存取/检视仍可用

拆除
  └─ Destroy
        ├─ WithdrawAll（按全局上限分块，Direct → Near）
        ├─ 失败 → TryAddForced 回滚 + 停止
        └─ base.Destroy（剩余库存可能丢失）
```

## 所含功能

- 账单限制说明与出库替代方案。
- 250W 仅温控；断电存取可用。
- 拆除前分块取出。
- 资源列表计入库内物品。
- 腐烂/防火按原版。

## 如何使用

1. **验证账单**：建一个只从立体库取料的账单，观察小人是否去库门口取货；当前应取不到。
2. **变通**：用自动出库把料送到工作台旁的更高优先级库存区，或手动取出。
3. **断电测试**：拉闸，确认温控停止、库存/取出仍可用。
4. **拆除**：先「取出全部」，清空建筑周围，再拆；拆前存档。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 账单一直缺料 | 库内物品对账单不可见 | 自动出库/手动取出 |
| 断电后库内物品会丢吗 | 不会；存取不依赖电 | 只停温控 |
| 拆了库物品少了 | 落点失败，`WithdrawAll` 停止后建筑销毁 | 先清空周围并取出全部 |
| 库内食物会腐烂吗 | 按原版物品规则，温控可减缓 | 保持低温/缩短存放 |
| 能升级容量吗 | 当前没有升级，容量用设置页统一调 | 调设置页 |
