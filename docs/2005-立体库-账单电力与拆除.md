## 简介

说明三件容易踩坑的事：原版账单能不能直接取库内物品、断电会怎样、拆除/被毁时库存去哪。

## 描述

- 立体库物品在 `ThingOwner` 里，不在 `ListerThings`；账单能否看到取决于 M3-0 选型。
- 选型 A（纯 ThingOwner + 自定义 Job）通常不能；B 可能可以；C（定向 Harmony）可以。
- **M3-0 定稿前不承诺账单自动取料**；建议先用 2003 出库到工作台旁。
- 断电：入库/出库停止，ITab 可看，库存不丢；恢复电后不自动补做中断 Job。
- 拆除/被毁：库存按规则掉到出库口/周围；具体格数/散落 M3-1 定稿。
- 防火/腐烂策略 M3-8 定稿。

## 绘制调用逻辑图

```text
原版账单（做饭/制药/锻造）
      │ 调 GenClosest / ListerThings 找料
      ▼
库内 ThingOwner 是否可见？
      ├─ 否（A）→ 找不到 → 用 2003 出库到库存区
      └─ 是（B/C）→ 直接取料

断电：CompPowerTrader → 停入库/出库，库存保留
拆除：Deconstruct → 库存掉落到出库口/周围
```

## 如何使用

1. 验证账单：建只从立体库取料的账单，看小人是否去库门口取货。
2. 不能取时用 2003 把料取到工作台旁。
3. 断电测试：拉闸，确认作业停止、库存仍在。
4. 拆除前先存档，确认掉落位置可拾取。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 账单一直缺料 | 库内物品对账单不可见 | 用出库流程，或等 M3-0 选 C |
| 断电后 Job 卡住 | Job 中断未重排 | 恢复电后重新下令 |
| 拆了库物品消失 | 掉落规则未覆盖该格 | 先清空再拆；记录 bug |
