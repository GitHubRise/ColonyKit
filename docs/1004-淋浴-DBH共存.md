## 简介

Dubs Bad Hygiene（DBH）已有完整的卫生/淋浴/给排水系统。本模块也有 `Need_Hygiene` 和淋浴器，两者同时启用会出现两条卫生需求、两套淋浴。本页定义检测与共存策略。

## 描述

三种策略（M2-7 定稿）：

| 策略 | 做法 | 适合 |
|---|---|---|
| 共存 | 不做自己的 `Need_Hygiene`，只保留清洁/心情淋浴 | 想和 DBH 一起用 |
| 软停用 | 检测到 DBH 时，本模块需求不注入、淋浴器停用/隐藏 | 以 DBH 为主 |
| 替代 | 声明 `incompatibleWith` DBH，只装本模块 | 想用完整本 Mod 卫生 |

- 当前草案默认：**软停用**。
- 检测 `dubwise.dubsbadhygiene`；检测到后设置页提示，关闭本模块需求。
- 已建淋浴器不自动删除；只是不产生需求效果，避免坏档。
- DBH 的给排水与本模块 `Core/Water` 不互通。

## 绘制调用逻辑图

```text
Bootstrap / OnDefsLoaded
        │
        ▼
ModsConfig.IsActive("dubwise.dubsbadhygiene")
        ├─ 否 → 正常注入 Need_Hygiene
        └─ 是 → 读取 HygieneSettings.DbhPolicy
                 ├─ Coexist   → 不注入需求，保留淋浴清洁/心情
                 ├─ SoftOff   → 不注入需求，淋浴器停用/提示
                 └─ Replace   → 记录 incompatibility，建议只装一个
                 │
                 ▼
         设置页显示当前策略 + 日志 [ColonyKit][Hygiene] DBH detected
```

## 所含功能

- DBH 检测与策略切换。
- 软停用：跳过需求注入、停用淋浴效果。
- 共存：只保留清洁/心情效果。
- 替代：不兼容声明与提示。
- 冲突日志与设置页说明。

## 如何使用

1. 同时启用 DBH 和 ColonyKit，进游戏看设置页「淋浴」分节。
2. 选择策略（默认软停用）。
3. 软停用：确认需求面板没有两条卫生条。
4. 替代：先卸 DBH，再开新档/读档；旧档可能留警告。
5. 看 `Player.log` 的 `[ColonyKit][Hygiene] DBH detected`。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 有两条卫生需求 | 策略没生效/没检测到 DBH | 看日志和设置页；确认 packageId |
| 关了本模块还是掉卫生 | 关的是显示，不是 DBH 需求 | 检查是哪条需求在掉 |
| 读档红字 | 需求类被移除/重复注入 | 备份存档，切回原策略 |
