## 简介

Dubs Bad Hygiene（DBH）已有完整的卫生/淋浴/给排水系统；本模块也有 `Need_Hygiene` 和淋浴器，同时启用可能出现两条卫生需求、两套淋浴。本页说明检测与三种共存策略。

## 描述

- 检测：`ModsConfig.IsActive("dubwise.dubsbadhygiene")`。
- 策略 `HygieneDbhPolicy`：

| 策略 | 行为 | 适合 |
|---|---|---|
| `SoftOff`（默认） | 检测到 DBH 时停用本模块需求/自动工作；没装 DBH 正常 | 以 DBH 为主 |
| `AlwaysOn` | 无视 DBH，始终运行本模块；两套需求并存 | 想两套一起用 |
| `Disabled` | 完全停用本模块需求/自动工作 | 只想保留建筑、不跑卫生 |

- `ShouldRunHygiene` 同时检查模块开关与策略；`ShouldInject` 还检查人形/机械体、智力、囚犯/访客/非人形开关、种族/体型/Hediff 豁免。
- 停用时不仅“不新增需求”：`HygieneModule.ResetRuntimeState` 会调用 `HygieneUtility.RefreshAllPawns`，对已有人形执行 `AddOrRemoveNeedsAsAppropriate`，移除现有 `CK_Hygiene`/`CK_Bladder`。
- 刷新范围：`PawnsFinder.AllMapsCaravansAndTravellingTransporters_Alive`，包含地图、商队、远行队。
- 自动工作与手动 Gizmo 也受 `ShouldRunHygiene` 保护；已建淋浴器/洁具不删除、不隐藏，只是不再自动产生需求/工作。
- 两套水网不互通：DBH 的给排水与本模块 `CompPipe`/`PlumbingNet` 相互独立。
- 设置页「卫生」中的 DBH 下拉修改后会立即调用 `RefreshAllPawns`；模块开关切换也会调用 `ResetRuntimeState`。

## 所含功能

- DBH 检测与三策略切换。
- 停用现有需求（不只阻止新增）。
- 始终并存模式。
- 地图/商队/远行队统一刷新。
- 不删除已建洁具，避免坏档。

## 如何使用

1. 同时启用 DBH 和 ColonyKit，进入「选项 → Mod 设置 → 卫生」。
2. 看「DBH 策略」：默认「软停用」。
3. 以 DBH 为主：保持「软停用」；两套都要：选「始终并存」；完全不要本模块需求：选「完全禁用」。
4. 修改后点「应用到现有小人」；模块开关切换会自动刷新。
5. 看 `Player.log` 的 `[ColonyKit][Hygiene] module loaded ... DBH active=...` 确认检测结果。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 有两条卫生需求 | 策略为「始终并存」，或软停用未生效 | 看设置页与日志；改软停用并应用 |
| 关了模块仍有卫生条 | 旧需求未刷新/商队小人 | 切换模块开关或点「应用到现有小人」 |
| 两套水网不互通 | 设计如此 | 分别建 DBH 与本模块的水网 |
| 读档红字 | 需求被移除/重复注入 | 备份存档，切回原策略；报告日志 |
